# 人物定妆资产规范 · v4.1

本规范用于演员完成服装、化妆、发型设计之后的定妆照。人物资产不是剧情插图，也不是人物小传。下列规范优先于旧版的简略人物模板；软件分段执行时采用相同字段和质量要求。

## 三类信息必须分开

- 原文明示的稳定外貌：年龄、肤色、身高、五官、胎记、伤疤、发色等必须保留。明确身体缺陷、病损不得为了美化消除。
- 可见但原文未细写的设计：根据时代、职业、阶层和角色定位补足，标明“设计推断”，不要冒充剧本事实。可以设计具体脸型、眉鼻唇比例和服装细节，不要每个字段都写“不详”。
- 表演和修辞：眼中闪过神光、寒光、杀意、笑意，气势爆发、青筋暴起、震惊、仇恨、泪光，全部从人物定妆描述中剔除。不能机械照抄小传中的瞬时描写。人类角色不附加眼球发光、气焰、粒子、法阵或光环；明确非人角色的永久器官特征可按设定保留。需要的施法效果另作为特效道具资产设计，不能污染基础人物图。

## 每个新人物资产的完整结构

一级仍用 `- 【人物名-服装状态】`，下列字段使用普通文字冒号，不能变成新的方括号资产名。

身份与依据：视觉年龄、性别呈现、时代地域、身份及本套服装场合；区分原文依据与设计推断。
脸型骨相：长宽比例，额头形状，颧骨高低与外扩程度，下颌转折、下巴长度宽度；明确一种主脸型，不能只写“棱角分明”。
眉眼：眉形、浓淡、眉峰位置，眼裂长度、眼距、上眼睑结构、内外眼角形态、虹膜自然颜色。写解剖特征，不写眼神情绪。
鼻唇与耳部：鼻根高度、鼻梁宽窄曲直、鼻尖鼻翼，唇峰、上下唇厚度和嘴宽，耳形或可见耳饰；避免把所有人写成高鼻梁薄唇。
肤质与辨识点：自然肤色及冷暖、皮肤纹理、符合年龄的细纹、稳定痣疤；一至两项有依据或标为设计推断的识别点即可，禁止给每个人都造伤疤。
发型与发饰：发际线、发长、分缝、发量、纹理、发色，鬓角与刘海、束发结构，冠帽材质位置；有胡须时写形制。
身形比例：身高观感、肩宽、头身比、躯干与四肢比例、适度肌肉量；不写动作姿势。儿童保持儿童比例。
妆造：底妆厚薄和肤质保留、眉部修饰、眼部与唇部自然色调，胡须或做旧；日常、职业、礼仪妆有区分，不套统一浓妆。
服装总体：剪影、松量、主辅色与面积关系，衣长、腰线、领型、袖型与裤裙结构。
服装层次：按实际穿着逐层说明内层、中层、外层、下装、足饰。每个存在的层次写颜色、剪裁、面料纹理与厚薄、接缝收边、扣合方式、垂坠或挺括、合理磨损。无中层就明确无，不能为了凑字段添衣。
配饰与随身物：数量、材质、尺度、佩戴位置；眼镜、首饰、腰带、包与职业用品须符合身份和剧本。手持动作不写入人物图。
一致性与展示：列出跨换装固定的脸型、眉眼、鼻唇、肤色和稳定识别点。完整穿戴的全身定妆资产、中性面部、均匀柔光、纯净背景，细节可读；禁止剧情表演、发光眼睛、衣服平铺和散件拼贴。

主要人物及有名有姓的重要配角通常约700–1100汉字；次要配角约450–700字，群体按主要可见差异描述。以完整可用为准，不为了长度重复形容词，不把“俊美/漂亮”当作五官结构。输出预算不足时缩小剧本片段，不能删掉脸型、眉眼鼻唇、妆发或服装层次。每项设计必须定稿，禁止“圆领或立领”等备选式描述；设计推断集中标注，服装和五官使用确定的细节。不要附带解释为何删除剧情神光的说明，不引用被剔除的剧情原句。场景补足的普通陈设不自动新增独立道具条目，独立道具以剧本实际需要为准。

## 差异化演员设计

在故事允许时，主角、男二男三、女二女三采用符合影视选角的协调、上镜外貌；高颜值和辨识度必须同时存在，反派也不默认丑化。为主要人物选择不同的脸型、骨相、眉眼距离、鼻唇比例和发型组合。例如清秀长椭圆脸与紧凑菱形脸可以都好看，不应统一成尖下巴、大双眼皮和同样高直鼻。年龄、生活经历和原文明示特征优先于美化。

同一人物从常服换运动服，是两个服装资产，但必须同脸。新服装条目完整重复固定面貌和妆发基准，再详细写本套服装；不能只写“同上，改运动服”，图片 Agent 未必能访问另一条记录。相同资产名称在后续集数可以写“复用第N集”，因为软件复用同一记录；新资产名称不得免描。

## 对照示例（仅示范结构，不可套用到所有人物）

原文：“陆宁穿深蓝运动服，眼中闪过神光。”
错误：“陆宁很帅，冷峻的眼睛闪耀神光，魔气缠身，深蓝运动服。”
正确的设计方向：“设计推断：22岁青年，窄长椭圆脸，额头饱满、颧弓收敛、下颌转折柔和；平直浓眉、偏长内双眼、适中眼距、深棕虹膜；中等高度鼻根、窄鼻翼、圆润鼻尖，上唇较薄且唇峰清晰、下唇适中；自然浅暖肤色并保留细小皮肤纹理。黑色短发侧分，鬓角整齐。深蓝哑光针织拉链运动外套，浅灰棉质圆领内搭，外套插肩袖、袖口罗纹收束；同色直筒运动裤……”。实际完整输出还须包含全部字段及本人物固定锚点，不把此例的脸复制给其他角色。

道具与人物规则不同：剧本明确的魔气缠绕宝剑可以保留受控光效，同时说明剑体结构、比例、材质和发光部位；不能将道具魔气转移到持有者的基础人物定妆图。

## 交付自检

逐条确认：有具体脸型骨相、眉眼鼻唇、肤质、发型、身形、妆造、完整穿戴层次；同人换装同脸、不同人有区别；无眼神表演和修辞光效；新资产可独立生图；人物/场景/道具三类齐全；没有遗漏原文可见资产；没有增加不存在的换装事件。没有联网工具时不能声称做过联网考据。
