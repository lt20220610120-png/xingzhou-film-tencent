# 美术清单内置服化道模块

本模块把服装、化妆造型和道具设计接到剧本美术清单的资产索引上。它服务于人物、场景和道具资产，不改写剧情，也不把人物参考图变成表演分镜。

人物资产的详细提示词字段和图像展示模式以 [人物图像提示词结构](image-prompt-structure.md) 为准；本模块负责服化道设计事实、审美理由和跨场连续性。

## 设计优先级

遵循：用户明确设定 ＞ 剧本事实 ＞ 用户参考图/角色卡 ＞ 可核查史料 ＞ 标注的合理推断 ＞ 审美提案。任何会改变年代、文化、阶层、人物身份、道具功能或连续性的未知项，标 `【待确认】`；合理补足标 `【合理推断】`，纯创意选择标 `【审美提案】`。

## 全剧服化道总纲（内部先定）

通读全剧后先锁定一套视觉语法：

- 时代、年份、地区、社会结构、现实/历史灵感/架空的可信度；
- 主色、辅助色、禁用色、轮廓、层次、面料、工艺、反光和做旧程度；
- 主角、主要角色、次要角色和群演的视觉层级；
- 每位主要人物的一到两个稳定识别点、核心色或材质；
- 妆发的时期可行性、身份/场合尺度、镜头可读性；
- 场景主色、建筑材质、灯光与人物服装的避让和呼应；
- 道具的形制、材料、功能、携带方式、文字、磨损和超自然效果边界。

“美”必须落到轮廓、比例、颜色、材质、做工、合身度和人物理由上。不能用“绝美、贵气、仙气、高级”代替设计，也不能让全员穿同一等级的华服、使用同一妆面或拥有同样的视觉重点。

## 人物服装与妆造设计

每个需要形象资产的人物先建基准造型，再建剧本真实发生的状态变体。人物卡应回答：这是何时何地的谁、穿什么层次和面料、如何妆发、有哪些固定配饰、什么细节显示身份和气质、怎样与场景和其他角色区分。

### 静态人物资产字段

人物参考图仍执行主 Skill 的中性限制。服化道字段只写静态可见内容：

1. 视觉年龄、身份/职业、体型比例和稳定气质；
2. 外层→中层→内层、领口、肩线、腰线、袖口、下摆、裤/裙、鞋履；
3. 面料、织法、颜色、反光、做旧、清洁和修补；
4. 发式、分缝、束发/盘发/冠帽、发色、底妆、眉眼、唇颊、胡须和稳定伤痕；
5. 固定配饰、衣物上的标志物和独立道具 ID；
6. 资产图的镜头尺度、三视图/全身需求和负面约束。

禁止把“正在整理衣服、戴上发簪、拿着武器、走路、奔跑、笑、皱眉、眼神变化、说话、准备战斗”等行为或表演写进人物资产。动作、光线中的运动反应和当场表演只进入内部连续性账本或导演/视频 Skill；人物生成提示词只能要求中性面部、无表情、无动作和清楚的服化道轮廓。

### 造型状态与连续性

只有剧本事件或有依据的现实变化才建新状态：明确换装、借衣、制服变化、礼仪场合、伪装、发式变化、妆面变化、雨湿、汗污、泥污、血污、破损、伤病、缺件、修复或身份转换。换机位、换景别、自然褶皱、人物心情或同一场内的轻微整理不新建资产。

状态 ID 继续使用 `【角色名-具体服装或状态】`；妆发只有在需要独立生成或复用困难时才另立 `【角色名-妆发状态】`。状态卡只写与基准不同的静态差异，并回指基准 ID；同一时间线下不会因为镜头、括号或场次切换自动重置。

## 道具设计增强

道具卡除原有外观、材质、大小感、用途和文字外，再记录：持有人/所有权、收纳与携带方式、制作工艺、磨损史、交接、损坏、复原和需要特写的结构。现代物件要匹配年份、地区和现实可得性；历史物件要匹配时期、身份和工艺。文字按剧本逐字保留，未提供的文字只写“无可读文字/不可读纹理”。

玄幻、修仙或超自然道具拆成两层：

```text
基础本体：形制、材质、尺寸重量感、佩戴/持握方式、现实或历史灵感
超自然表现：剧本已给出的能力、触发、颜色/能量、作用范围、衰减
```

只有剧本已明确的能力才能视觉化。可把魔气写成沿剑脊流动的黑雾、把灵光写成从刻痕透出的局部冷光，但不得新增神器等级、攻击结果、敌人、阵法、爆炸或环境灾害。特效不能遮住本体轮廓、握柄、刃口和状态连续性。

## 场次状态账本（内部）

每个场次记录：

```text
场次ID | 时间/地点/天气 | 出场人物 | 服装状态ID | 妆发状态ID
起始干湿/整洁/破损 | 随身及场内道具状态 | 本场变化（触发→过程→结果）
镜头可见重点 | 出口状态→下一场入口
```

重点追踪衣物穿脱、发饰掉落、妆面被雨水冲淡、道具交接、损坏、遗失和复原。将动作写在账本里用于连续性核对，不把它们回填到静态人物参考卡。人物资产名不因场景改变，场景名不塞进人物 ID，道具名不夹带持有人。

## 题材核对入口

- 现代都市：按年份、城市、职业、收入、通勤、气候和个人审美设计；不凭品牌 Logo 制造高级感。
- 青春校园：先锁国家/地区、校服制度、年龄和季节；个性体现在鞋、书包、外套、发饰和小范围配色，未成年人造型保持年龄适宜。
- 中国古装：先锁朝代/世纪、地域、身份、礼仪和阶层；男子发式、冠帽、衣襟、鞋履与女子发式、妆面必须同一时期自洽。
- 民国/近代：至少锁年份、城市/乡村、职业和阶层；旗袍、长衫、西装、学生装、工装、发式和妆面不能被一个泛化模板替代。
- 修仙/玄幻：区分历史灵感和原创规则；长发、法衣、宗门色、护具和法器为身份/功能服务，魔气和灵光只展开剧本明确效果。
- 其他国家/地区：具体到国家、时期、族群/宗教语境、场合和材料，避免用“异域风”代替考据。

需要详细时期核对时读取 [period-style-cards.md](period-style-cards.md)；需要道具真实性、文字和超自然状态控制时读取 [prop-realism.md](prop-realism.md)；需要来源与核验方法时读取 [costume-research-and-sources.md](costume-research-and-sources.md)。

## 五项审美验收

1. 缩略图轮廓能否区分角色和层级；
2. 角色与场景、同场人物是否有清楚但不刺耳的色彩关系；
3. 丝、棉、麻、皮革、金属、玉、木、玻璃等材质是否可辨；
4. 衣物、妆发和鞋履是否像这个人真实能获得、维护并适应其身份的东西；
5. 是否只有少量稳定记忆点，而不是靠堆饰品解决设计问题。
