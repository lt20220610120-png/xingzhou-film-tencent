# 服化道研究与来源

核验日期：2026-09-14。以下来源用于建立检索入口和设计判断，不是把某件藏品直接复制到所有人物身上。来源中的教育内容与本 Skill 的生成视频适配是两层：前者支持史实/行业原则，后者是为图像与视频生成设计的可执行写法。 

本文件在 `art-asset-list-v3` 中仅作为史料和行业依据使用。人物资产的最终输出仍受主 Skill 的静态中性硬约束：动作、表情、视线和剧情行为只能留在内部连续性账本或其他镜头 Skill，不得写入人物参考卡。

## 设计与行业原则

### 1. 服装把时间、地点、关系和人物带到观众眼前

[Academy of Motion Picture Arts and Sciences：Costumes: Telling the Story](https://www.oscars.org/sites/oscars/files/teachersguide-costumedesign-2015.pdf)

- 来源：奥斯卡学院教育材料，引用服装设计师 Deborah Nadoolman Landis 的教学内容。
- 可用原则：服装受时间、地点、人物关系和导演视觉意图影响；设计师通过每件衣物建立真实人物，并可比较角色开场与结尾的造型变化。
- Skill 适配：为每个角色建立基准造型和剧情状态弧线；输出状态变化的触发与连续性，不把服装当孤立海报。

[Academy：How To Create a Great Costume Design](https://www.oscars.org/news/how-create-great-costume-design)

- 可用原则：服装要表达角色的内在经验和自我形象，承担身份可信度与叙事功能。
- Skill 适配：每项“美感”必须落到剪裁、材料、颜色、整理程度、配饰或穿着行为，不能只写漂亮。

### 2. 设计师和演员、导演、视觉部门协作

[BAFTA：Talking about costume design — BAFTA sessions 2019](https://www.bafta.org/stories/talking-about-costume-design-bafta-sessions-2019/)

- 来源：BAFTA 对 Julian Day、Mary Zophres、Alexandra Byrne、Sandy Powell 的行业讨论整理。
- 可用原则：现代服装也需要细致的年代/人物判断；合身、试穿、反馈与演员进入角色很重要；设计师与导演需要视觉参考和反复协作。
- Skill 适配：设计现代都市时不套“随便的现代衣服”；记录场景、演员动作和参考图的接口，给出可执行的合身度、穿着痕迹和修改点。

[BAFTA：Costume Designer Lindy Hemming Masterclass](https://www.bafta.org/media-centre/press-releases/bafta-masterclass-with-award-winning-costume-designer-lindy-hemming-in-hong-kong/)

- 可用原则：服装设计是与导演、演员和整体制作协作的专业工作。
- Skill 适配：交付中区分剧本事实、导演视觉、演员可穿戴性和待确认项目，便于未来美术 Skill 合并。

[Costume Designers Guild：Conversations about Research](https://costumedesignersguild.com/design_details/conversations-about-research/)

- 来源：美国服装设计师协会行业文章，讨论研究、广泛参考和历史真实之间的关系。
- 可用原则：研究为设计提供基础；历史真实与让角色以预期方式被观众理解之间需要判断，不是简单复制旧图。
- Skill 适配：先查时期/地区/阶层，再做适度审美提案；把来源、推断与创作分栏，避免把影视化惯例冒充史实。

### 3. 服装、色彩、场景和光影共同讲故事

[BAFTA：Todd Haynes — A Life in Pictures transcript](https://static.bafta.org/uploads_pre_202411/transcripts/bafta_a_life_in_pictures_-_todd_haynes_transcript_0.pdf)

- 可用原则：在时期电影中，服装、布景、光线和其他部门可以共同表达人物欲望、压迫和情绪。
- Skill 适配：服化道总纲要给未来场景美术提供主色、材质、避让与呼应；不把角色衣服与场景独立设计到互相打架。

[Costume Designers Guild：Ann Roth — The Person In The Mirror](https://costumedesignersguild.com/ann-roth-the-person-in-the-mirror/)

- 可用原则：为了可信，有时需要不完美的配件、轻微色差或使用痕迹；服装也要帮助演员进入人物。
- Skill 适配：在经济、职业和时间允许的范围内加入少量非完美细节；不用全员崭新和全员无瑕制造“高级”。

[Costume Designers Guild：What Is Costume Design?](https://costumedesignersguild.com/what-is-costume-design/)

- 可用原则：服装部门从剧本、时代和技术研究开始；角色造型、试装、替身/特技版本与连续性都属于制作工作。
- Skill 适配：资产卡同时记录基准版、动作/污损版、复用场次和连续性，不只交付一张正面美图。

[Screen Ireland：Costume Department Competency Framework 2024](https://www.screenireland.ie/images/uploads/general/Booklet_5_-_Costume_Department_2024.pdf)

- 可用原则：拆剧本、分配色彩、研究时代、制作 mood board、与导演/演员协作，面料选择要兼顾银幕效果、穿着、测量、预算和进度；发型化妆共同建立人物形象。
- Skill 适配：交付增加色彩/材质板、动作与穿着限制、妆发联动、版本和制作备注，使设计可交给剧组而非只作灵感文字。

### 4. 博物馆与历史材料

[The Metropolitan Museum of Art：The Costume Institute](https://www.metmuseum.org/about-the-met/collection-areas/the-costume-institute)

- 可用原则：服装参考资源覆盖多个世纪、地域服饰、纺织品、时装与技术研究。
- Skill 适配：历史检索按时期/地区/服装类型/阶层进入，不拿一个泛化图片代表整段历史。

[The Metropolitan Museum of Art：Chinese Textiles — An Introduction](https://resources.metmuseum.org/resources/metpublications/pdf/Chinese_Textiles_An_Introduction.pdf)

- 可用原则：早期中国服饰与社会秩序、身份等级、材料和习俗相关，存世资料也有局限。
- Skill 适配：中国古装必须同时锁定时期、身份和社会角色；不只写“华丽汉服”，不把博物馆藏品当普遍日常。

[The Metropolitan Museum：Imperial Court Robe, Qing dynasty](https://www.metmuseum.org/art/collection/search/50487)

- 可用原则：单件清代宫廷袍可核对丝绸、金线、纹样、龙、云、海水与山等具体材料和装饰。
- Skill 适配：可用于宫廷/高等级角色的材料与纹样参考；不能把宫廷纹样无差别给平民角色。

[The Metropolitan Museum：Comb top, Tang dynasty](https://www.metmuseum.org/art/collection/search/44616)

- 可用原则：唐代晚期至十世纪，装饰梳背可作为发式和首饰材料/工艺的具体参考。
- Skill 适配：古装妆造写具体发饰的材料、尺寸感和佩戴位置；仍需核对角色阶层与场合。

[The Metropolitan Museum：China — Dawn of a Golden Age, 200–750 A.D.](https://www.metmuseum.org/exhibitions/listings/2004/china-dawn-of-a-golden-age)

- 可用原则：汉末至盛唐存在北亚迁徙、贸易与跨文化交流；唐代服饰和妆容并非封闭单一风格。
- Skill 适配：在唐代或跨区域世界里允许有史实支持的交流影响，但要写明来源与角色背景，不能用“异域”作为空泛装饰。

[Smithsonian National Museum of American History：Costume and Textiles Collections](https://americanhistory.si.edu/about/departments/home-community-life/collections)

- 可用原则：服装反映阶层、信仰、制度、身份、生活经历，以及文化、技术和经济因素。
- Skill 适配：现代/历史服装都要把阶层、职业、地理、技术和经济写进设计，不把美感简化为价格。

[Museum at FIT：Fashion History Timeline — 1940–1949](https://fashionhistory.fitnyc.edu/1940-1949/)

- 可用原则：20世纪40年代受战争、配给、制服、Utility clothing 与战后 New Look 等变化影响；不同国家有不同服装故事。
- Skill 适配：民国/近代或西方近代题材至少锁定年份和社会处境，不把一整个年代压缩成单一“复古风”。

[Museum at FIT：Fashion History Timeline — 1950–1959](https://fashionhistory.fitnyc.edu/1950-1959/)

- 可用原则：50年代女装轮廓、颜色与配饰和男装日常化变化并存，时尚不是整齐切换。
- Skill 适配：现代/近代角色的造型差异要按场合、性别表达和阶层分化，而不是全员一件时代制服。

### 5. 妆容与化妆道具的历史证据

[British Museum：Looking good in ancient Egypt](https://www.britishmuseum.org/sites/default/files/2020-10/Looking_good_in_anicent_Egypt_gallery_activity_Rooms_61_65_accesstagged.pdf)

- 可用原则：古埃及男女都使用化妆和首饰；材料价格与社会阶层有关，kohl 用于眼部。
- Skill 适配：妆容不能简单按现代性别刻板印象分配；化妆材料、容器和阶层要一起设计。

[British Museum：kohl-bottle, Achaemenid Persia](https://www.britishmuseum.org/collection/object/W_1959-0716-2)

- 可用原则：古代波斯化妆容和 kohl 容器有具体文化、材料与年代信息。
- Skill 适配：跨文化古装妆造需要具体到文明/时期和化妆容器，不用“异域眼线”代替历史设计。

## 研究操作规则

1. 先提出具体问题：“1930年代上海女教师日常发式和外套如何区分？”比“民国服装”可核查。
2. 优先博物馆藏品记录、官方展览/档案、大学项目、行业协会和设计师访谈；搜索结果只作入口。
3. 至少交叉检查时期、地区、阶层/场合与材料，不用单张影视剧截图证明史实。
4. 记录来源 URL、核验日期、支持的具体判断和不确定性；一手资料不能支持的内容标 `[合理推断]` 或 `[待确认]`。
5. 当用户明确要求“现在流行”“当前潮流”时再查当下可靠的设计/品牌/行业资料；不把临时趋势写入历史卡或全剧永久规则。
6. 不下载受版权限制的图集来充当资料库；优先使用公开博物馆藏品页、开放访问图像和官方教育材料。下载素材如需进入生成流程，先确认授权和用户用途。

## 补充来源：中文历史、校园与奇幻制作

[中国国家博物馆：古代车舆与服饰研究](https://en.chnmuseum.cn/research_629/research_institutions_631/nmc_institute_of_research/201911/t20191126_174466.html)

- 可用原则：古代服饰研究要结合文物、制度和长期学术积累，不能只看影视惯例。
- Skill 适配：先定朝代、身份、地域和礼制，再核对出土物、图像与文字；证据不足标 `[合理推断]` 或 `[审美提案]`。

[中国丝绸博物馆：胡汉之间——唐代丝绸服饰展](https://www.chinasilkmuseum.com/yz/info_18.aspx?itemid=28162)

- 可用原则：唐代冠服制度与胡汉交流并存，半臂、窄袖袍、裤、革带、革靴/锦靴等形制可以由文物、陶俑、壁画互证。
- Skill 适配：唐代设计区分礼服、官常服、民间服与出行/骑射服；外来元素写清身份和交流路径，不用“开放华丽”替代形制。

[故宫博物院：翠扁方](https://www.dpm.org.cn/collection/jewelry/231381.html)

- 可用原则：清代满族妇女“两把头”以扁方固定发髻，材料与装饰有具体差异，头饰兼具固定和身份功能。
- Skill 适配：清代发型与族群、阶层、场合绑定；记录固定方式、重量、行动限制与身份含义，不随意堆叠古风配件。

[香港历史博物馆：The Evergreen Classic—Transformation of the Qipao](https://hk.history.museum/en/web/mh/exhibition/2010_past_04.html)

- 可用原则：旗袍在 1920s–1960s 随社会文化变化，历史服装与现代设计不能混为固定模板。
- Skill 适配：民国/近代造型至少细分年份、城市、职业、教育和场合；旗袍只是其中一类，不代表所有女性。

[香港政府新闻公报：The Evergreen Classic—Transformation of the Qipao](https://www.info.gov.hk/gia/general/201006/22/P201006220160_print.htm)

- 可用原则：近代学生与受教育女性出现更实用的“文明新装”，1920s–1930s 的长度、袖长、滚边、修身和开衩随年代变化。
- Skill 适配：把实用/礼仪、学生/职业、城市/乡镇和战争前后落实到衣物、发妆和鞋履，不只套复古滤镜。

[英国政府：Cost of school uniforms](https://www.gov.uk/government/publications/cost-of-school-uniforms/cost-of-school-uniforms)

- 可用原则：校服同时承担共同身份、负担能力、耐用性、课堂/体育功能和平等与健康安全。
- Skill 适配：校园造型先做共同规范，再用鞋、书包、外套、袖口、发饰和旧改痕迹体现学生个体差异；未成年人保持年龄适宜。

[Lucasfilm：Costume Designer Sarah Young on Willow](https://www.lucasfilm.com/news/costume-designer-sarah-young-willow-interview-part-1/)

- 可用原则：奇幻剧需要为大量角色和群众建立世界服装语法、研究、工坊、试装和现场修改，服装要适应演员与拍摄。
- Skill 适配：玄幻先建立族群/宗门/地域的轮廓、材料、工艺、禁忌和层级，再设计主角变化；不靠服装擅自发明能力。

[美国国家档案馆：All Hands on Deck: A Sailor’s Life in 1812](https://www.archives.gov/publications/prologue/2011/fall/all-hands-on-deck-uss-constitution)

- 可用原则：历史复原可结合名册、尺寸、疤痕、服装收据、军方合同和真实劳动环境；污渍与身体状态来自生活。
- Skill 适配：历史人物的体态、磨损、污渍、修补、材料来源和经济条件要有具体原因，不能给全剧套统一做旧滤镜。

[ATF：Safety and Security for Firearm Owners](https://www.atf.gov/firearms/docs/guide/safety-and-security-firearm-owners-atf-p-530022)

- 可用原则：现实枪械处理有枪口方向、手指位置、护具和锁存等安全要求。
- Skill 适配：枪械道具卡只做影视视觉设定并写安全道具/空仓/现场武器师等制作约束，不提供制造、改装或现实攻击教程。
