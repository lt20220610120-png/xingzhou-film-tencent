# 资产描述规范

人物资产的七项基础字段（脸型五官、发型发色、身材、肤色、穿着、配饰、气质）继续保留；最终交给图像模型的 `资产生成提示词` 升级为十二段式，详见 [人物图像提示词结构](image-prompt-structure.md)。本文件规定静态人物卡的事实粒度，分段顺序、展示模式、默认高完成度审美和剧情缺陷处理以该文件为准。

## 一、人物资产：静态中性参考

人物资产是供后续服化道、图像和角色一致性使用的形象基准，不是分镜、不演戏、不表现某一集的情绪。字段建议顺序：

1. **脸型与五官结构**：脸型、眉骨、眼形、鼻梁、唇形、耳形等静态结构；避免“眉头紧锁”“眼神锐利”。
2. **发型与发色**：长度、发量、分缝、束发/盘发/冠帽等静态形制；不写“风吹散”“正在整理”。
3. **身材与体态基线**：身高范围、肩胯比例、骨架、肌肉/体脂和静态体态倾向；不写“弯腰”“挺剑”“迈步”。
4. **肤质与可识别特征**：肤色、雀斑、痣、疤痕、纹身等稳定特征；没有依据的族群或肤色不要猜。
5. **静态服装/状态**：外层、中层、内层、面料、颜色、剪裁、鞋履；只写资产本身的状态。
6. **静态配饰**：帽冠、耳饰、项链、腰带、眼镜、固定在衣物上的标志物；不要写“拿着/递给/戴上”。
7. **妆造**：静态发式/分缝/束发或冠帽、底妆质感、眉形、眼妆、唇颊、胡须和稳定伤痕；说明时代、身份和场合尺度，不写妆面正在变化。
8. **气质**：稳定的身份气质，如质朴、克制、书卷气、干练、疏朗、粗粝；不能用表情或动作替代。
9. **参考图约束**：中性面部、无表情、无动作；正面/侧面/背面或三视图，均匀光线，中性背景。

### 合格示例

```text
【姜蓝-蓝色剑道服】（首次：第1集）
脸型五官：偏长的椭圆脸，眉骨平直，眼形狭长，鼻梁挺直，唇形偏薄。
发型发色：黑色中长直发，整齐中分，发尾齐平，无现代渐变剪裁。
身材体态：身形修长，肩背匀称，骨架偏窄。
肤质：偏白肤色，鼻梁和颧骨有轻微自然纹理。
穿着：深蓝色立领剑道服，哑光棉混纺，袖口和腰部结构清楚，配黑色长裤与白底训练鞋。
妆造：黑色中长直发整齐中分，轻薄无瑕感底妆，自然眉，低饱和唇色；妆发保持时代与身份适配。
配饰：白玉圆佩固定在腰带上，无额外饰品。
气质：清冷、克制、训练有素。
人物参考图约束：中性面部、无表情、无动作；正面/侧面/背面三视图，中性浅灰背景，均匀柔光。
```

### 不合格示例与改法

```text
不合格：面容清俊，剑眉星目，眼神凌厉，嘴角微抿，站在高地持剑准备战斗。
改法：偏长椭圆脸，眉骨平直，眼形狭长，唇形偏薄；身形修长，深蓝立领剑道服，腰部固定白玉圆佩；气质清冷、克制、训练有素；中性面部、无表情、无动作。
```

“清俊”“温婉”“凌厉”可以作为审美或气质词，但“微笑、皱眉、哭泣、愤怒、惊讶、眼神、嘴角、看向、站在、走来、持有、说出”等动态/表情信息必须从人物资产文字中删除。即使剧本写了“她笑着进门”，人物资产也只记录她的静态形象；这件事不进入人物参考图。

## 二、换装/状态差异卡

```text
【姜蓝-病号服】（首次：第5集；由【姜蓝-蓝色剑道服】变化）
穿着差异：灰白竖条纹病号服，宽松直身，左袖口有固定绷带。
状态差异：左臂缠绷带，肤色较基准略显苍白；人物参考图仍为中性面部、无表情、无动作。
不变锚点：脸型五官、黑色中长直发、身材比例和白玉圆佩不变；若剧本明确遗失再另立状态。
```

状态卡不得写“虚弱地坐在轮椅上”“痛苦地皱眉”等动作和表情。可以写“轮椅版资产”或“左臂绷带状态”作为静态可见状态，但把行为留给镜头/表演 Skill。妆发变化只写静态结果，例如“发式由高束改为低束”“底妆被雨水冲淡后的可见质感”，不写变化过程。

## 三、群演资产

群演卡描述群体静态共同点，不把所有人塑造成相同的脸：

```text
【家丁-青布短褂】（群演，首次：第1集）
身份层级：宅院家丁，实际出镜；不拆成个人姓名。
静态外观：年龄段和身高体型有合理差异；青布短褂、深色长裤、布鞋，面料耐磨，颜色有轻微深浅差。
气质：朴实、利落、服从秩序。
参考图约束：中性面部、无表情、无动作；群像静态参考，不写站位、手势或剧情行为。
```

## 四、场景资产

场景卡可以有氛围，但不写人物表演：

```text
【梨园戏楼-日-内】（首次：第1集）
布局：木质戏台高约一米二，台下是数排长凳，两侧有垂落幕布，梁柱结构清楚。
陈设：台口挂“梨园”匾额，台侧有兵器架与旗牌，门窗紧闭。
时代/地域：[推断] 中国近代戏楼，待用户确认具体年代与城市。
色调与材质：暗褐木梁、褪色红绸、灰青幕布、暖黄烛光；木、布、金属材质可辨。
氛围：封闭、陈旧、具有演出前的静默感；不写观众表情和演员动作。
```

## 五、道具资产

道具卡字段顺序：外观 → 材质/工艺 → 大小感/结构 → 功能 → 文字/纹样 → 状态/连续性。写物件，不写角色动作。

```text
【婚书-完整】（首次：第2集）
外观：折叠的米白色纸张，边缘整齐，红色封套，封面留有空白书写区。
材质/工艺：手工纸与薄棉纸封套，墨线边框，纸张有自然纤维纹理。
大小感/结构：约手掌大小，单页折叠，封套可开合。
功能：婚约凭证，剧情中的关键文书。
文字/纹样：正文未提供具体字样；封面不生成可读文字，只保留不可读墨线装饰。
状态/连续性：首次为完整未展开；后续若撕裂、沾水或交接，另建对应状态，不复制第二份。
```

## 六、图像提示词模板

### 人物中性参考图

```text
角色资产【角色名-状态】；【时代/地区/身份】；静态脸型五官、发色发型、身材比例、肤质；静态服装层次、面料、颜色、鞋履、配饰；静态妆造（发式、底妆、眉眼、唇颊、胡须/稳定伤痕）；气质为【稳定气质】；正面/侧面/背面三视图或全身角色设定图；中性面部、无表情、无动作、无对白、无视线方向；中性背景，均匀柔光，材质和轮廓清晰，人物一致性参考。
禁止：微笑、皱眉、哭泣、愤怒、惊讶、锐利眼神、张嘴、姿势动作、持物动作、表演、场景行为、字幕、水印、Logo、UI、现代错误发型或错误年代服饰。
```

### 场景资产图

```text
场景资产【地点-时间-内/外】；【时代/地区】；布局、建筑结构、主要陈设、材料、色彩、光线与空间深度；无人或人物仅作尺度参照且不描述表演；中性清楚的场景设定图，禁止现代错置物件、乱码招牌、字幕、水印、Logo、UI。
```

### 道具单体图

```text
影视道具资产【道具名-状态】；【时代/地区/工艺】；外观形制、材质、尺寸感、结构、纹样、磨损、剧本规定文字；单体清晰，正面/侧面/45度或三视图，中性背景，均匀光线，比例稳定；禁止额外道具、可读乱码、无依据超自然效果、字幕、水印、Logo、UI。
```
