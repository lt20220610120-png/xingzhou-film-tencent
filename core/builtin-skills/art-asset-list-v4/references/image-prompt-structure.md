# 人物图像提示词结构（服化道整合版）

执行前阅读 [v4.1 人物定妆资产规范](actor-look-development.md)。下文十二段用于顺序参考；新规范细化的脸型骨相、眉眼、鼻唇、肤质、妆发和完整换装要求必须逐一满足。

人物提示词的目标是生成可复用的角色资产图，不是生成某场戏的表演画面。默认采用“完整人物形象图”：人物可见，面部中性、无表情、无动作，服装和妆造完整；需要单独核对服装结构时，再另生成“服装单体设定图”，不要用服装单体图替代人物资产。

## 推荐的十二段顺序

模型之间对标点、标题和负面词的处理不同，因此把每一段写成短而明确的自然语言，并保持顺序稳定：

1. **资产身份**：资产 ID、角色名、视觉年龄、性别表达（若剧本明确）、身份/职业、题材、时代/地域。
2. **脸型与五官结构**：脸型轮廓、额头/眉骨、眼形与眼距、鼻梁/鼻翼、唇形/唇厚、下颌/下巴、耳形；写结构和比例，不写神态。
3. **发型与发色**：长度、发量、分缝、束发/盘发/冠帽、发际线、发色和材质；写静态形制，不写风吹、散开或整理过程。
4. **身材与静态比例**：视觉年龄对应的身高范围、头身比、肩胯比例、骨架、肌肉/体脂、四肢比例和静态体态基线；不写姿势或动作。
5. **肤色与肤质**：肤色、日晒/年龄/职业造成的稳定质感、雀斑、痣、疤痕或纹身；没有剧本依据的族群、肤色和缺陷不得猜测。
6. **服装总轮廓与层次**：先概括整体廓形、长度、宽松度和层数，再按内层→中层→外层→下装→足饰写穿衣逻辑。
7. **分层服装细节**：每层写颜色、明度/饱和度、领口、肩线、腰线、袖口、下摆、剪裁、面料、织法、垂坠、反光、做旧、清洁、修补和行动适配。没有剧情依据的品牌、Logo 和文字不写。
8. **妆造**：底妆质感、眉形、眼线/眼影、唇色、腮红、胡须、发饰和稳定伤痕；注明日常/礼仪/舞台/战后等静态状态及镜头尺度。不得写表情、视线或妆面变化过程。
9. **配饰与随身道具**：帽冠、耳饰、项链、腰封、玉佩、眼镜、包、武器/法器等；写材质、位置、比例、固定方式和稳定 ID，动作中的拿取/交接留在连续性账本。
10. **角色审美与叙事识别点**：用一到两个稳定的轮廓、色彩、材质或物件解释角色的气质和辨识度；不写“正在表现某种情绪”。
11. **展示与生成条件**：完整穿戴、人物是否需要三视图/正面/侧面/背面、全身或半身、背景、光线、色彩、镜头/焦段、画幅和风格。默认中性背景、均匀柔光、材质清楚。
12. **一致性与负面约束**：重复资产 ID、基准造型锚点、不可改变的剧情特征，以及只针对本资产的错误排除项。

## 可直接交给图像模型的模板

```text
人物资产【角色名-状态】；完整人物形象图；【视觉年龄、身份/职业、题材、时代/地域】。
脸型与五官：……（静态结构与比例）。
发型发色：……（静态发式、长度、分缝、发色、冠帽/发饰）。
身材比例：……（身高范围、头身比、肩胯、骨架、肌肉/体脂、静态体态基线）。
肤色肤质：……（肤色、纹理和剧本明确的稳定特征）。
服装总轮廓：……（整体形状、长度、宽松度、层数、时代制式）。
【内层】……（颜色、领口/肩线/袖口、面料、织法、做旧）。
【中层】……。
【外层】……。
【下装】……。
【足饰】……（鞋履结构、材质、与下摆的穿着关系）。
妆造：……（静态发式、底妆、眉眼、唇颊、胡须/稳定伤痕；与时代、身份、场合相符）。
配饰与随身物：……（材质、位置、比例、稳定道具 ID；不写持握动作）。
气质与审美识别点：……（一到两个轮廓/色彩/材质/物件锚点，具体说明美感理由）。
展示要求：……（完整穿戴、正面/侧面/背面或三视图、全身/半身、背景、光线、画幅、风格、材质可读）。
一致性要求：保持【基准 ID】的脸型、发色、身材比例和识别点；只改变本状态明确列出的服装/妆发/状态差异。
禁止：表情、动作、姿势、视线、对白、场景行为、错误年代发式/服饰、无依据缺陷、无依据 Logo/文字、额外配饰、肢体或服装结构畸变、字幕、水印、Logo、UI。
```

## 美貌与剧情缺陷的判定

- 剧本没有明确负面外貌设定时，默认采用高完成度的影视角色形象：五官比例协调、轮廓清楚、皮肤与头发质感健康、妆造精致但符合时代和身份。这里的“高完成度”通过具体五官结构、发型、肤质、剪裁、材质和整理度实现，不直接写“顶流脸”“明星脸”。
- 剧本明确毁容、疤痕、残缺、衰老、病损、烧伤、畸形、贫困或长期劳作痕迹时，必须如实保留；可以让整体建模和材质仍然精致，但不能用美化词抹掉剧情特征。缺陷的位置、范围和状态以剧本为准，不擅自扩大。
- 不用“所有角色都漂亮”覆盖身份差异。主角可有更明确的轮廓和材质焦点，配角仍保持协调、可辨和符合人物生活条件；群演降低装饰密度并保留个体差异。
- 年龄、族群、肤色、身体特征和性别表达不能为了审美被擅自改动。没有依据的项目标 `【待确认】`，不是用默认美貌替代事实。

## 服装分层的取舍

用户提供的“内层/中层/外层/下半身/足饰/配件”结构值得保留，因为它让模型理解穿衣顺序、轮廓和材质关系；但每层只写会影响画面的信息。不要重复相同的颜色、面料和身份结论，也不要列出不会在指定景别中出现的微小纹样。把“完整穿戴、自然层层叠穿、配件位置、鞋履完整、无散件/无平铺”放在展示要求中，不混入角色五官描述。

## 提示词编排依据

Google 的官方 Imagen 文档建议使用具体、描述性的长提示，必要时补充背景、风格、镜头位置、光线、镜头类型、材质和画幅，并通过迭代或负面提示排除错误；其人物参考模板也把主体描述、风格和参考图控制分开。通用规则因此采用“主体事实 → 结构细节 → 服化道 → 展示条件 → 一致性/禁止项”的顺序，而不是把所有形容词堆在一起：

- [Google Cloud：Imagen 提示和图片属性指南](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/image/img-gen-prompt-guide?hl=zh-CN)
- [Google Cloud：Imagen 主体自定义与人物参考图](https://cloud.google.com/vertex-ai/generative-ai/docs/image/subject-customization)
- [Google Cloud：提示设计策略](https://cloud.google.com/vertex-ai/generative-ai/docs/learn/prompts/prompt-design-strategies?authuser=0)
- [Screen Ireland：Costume Department Competency Framework](https://www.screenireland.ie/images/uploads/general/Booklet_5_-_Costume_Department.pdf)（服装连续性、资产清单、发型化妆协作和制作记录）

这些资料用于提示词结构和制作连续性的方法参考，不把任何示例人物、品牌、年份或外部风格直接写入用户剧本。
