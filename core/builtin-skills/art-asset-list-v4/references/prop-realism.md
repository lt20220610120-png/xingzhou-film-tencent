# 道具真实性、审美与视觉生成

## 1. 道具卡的六个问题

每件道具必须同时有故事功能和视觉特征：

1. 谁拥有或使用它？谁能接触它？
2. 它在这个时代/地区能否存在，通常由什么材料和工艺制成？
3. 它的大小、重量、平衡、收纳与携带方式是什么？
4. 它被使用后会留下什么痕迹：磨损、污渍、折痕、余温、裂纹、缺件？
5. 它的文字/图案/符号是否由剧本规定，观众是否需要读清？
6. 它怎样在全身、手部、近景、动作和特效中保持可辨？

道具不是“漂亮的物件清单”。如果没有剧情功能，可以把它作为环境美术接口，而不要强行给角色加上。

## 2. 现实题材与历史题材

### 现代都市

写出品牌等级时谨慎：除非剧本指定品牌，否则用品类、年代、材料和使用痕迹描述。手机/电脑/相机要匹配剧本年份、系统界面与地区；不为画面填满而编造可读通知。手枪、刀具、药品、证件和车辆写外观与叙事功能，避开现实制造、改装与攻击教程。

### 历史题材

以时期、地区、身份和用途核对形制。兵器要考虑鞘、挂法、握柄、护具和磨损；文书要考虑载体、书写工具、封装和可读程度；灯具、容器、妆具、钱币、交通工具和餐具要与当时工艺相容。博物馆藏品可作为外观与材料依据，但单件藏品不等于所有阶层日常的常态。

### 校园与职业

校规、制服、课本、校牌、书包、体育器材、实验器具和办公物件都要匹配国家/地区、年份、年龄与学校等级。职业道具要有“正在使用”的痕迹和合理的携带位置，不把万能工具塞给每个人。

## 3. 玄幻、修仙与超自然道具

先拆两层：

```text
基础本体：形制、材质、重量感、握持/佩戴方式、现实或历史灵感
超自然表现：由剧本确定的能力、触发方式、颜色/能量/纹理、作用范围、衰减
```

超自然表现的安全句法：

`从道具的哪个结构产生 → 以什么形态沿什么方向流动 → 对本体/附近表面产生什么可见反应 → 在剧本给定结果后如何消散`

例如“剑身缠绕黑色魔气”可以具体成黑雾沿剑脊盘旋、边缘不规则、短暂压暗附近光线、离开剑锋后消散。若剧本只写“古剑”，不能自作主张加魔气、法阵、传送、爆炸或新能力；若剧本写明魔气，才展开它的可见形态和材质关系。所有魔法纹路不可读，不形成字幕、UI或现代界面。

### 玄幻道具的审美控制

- 只选一个主材料和一个主能量色，其他颜色服务层次；避免彩虹发光。
- 先保证武器/法器轮廓、握柄、刃口、鞘口和佩戴方式可辨，再加粒子和雾。
- 重要道具保留一个稳定符号或损伤点，避免每次生成变成新神器。
- 道具特效要受人物能力、场景光源和动作阶段约束；不能让整张图变成白光。

## 4. 文字、纹样与文化符号

- 剧本明确的文字逐字保留，放大到需要读清的镜头，并禁止模型乱补其他字。
- 未指定的包装、招牌、书信、手机屏幕和法阵纹路不要生成可读内容；用“不可读纹理/非文字装饰”约束。
- 文化、宗教、族群符号先查来源、语境和禁忌；不要把神圣纹样当万能贴纸。
- 纹样写“形状、尺度、重复规律、位置、工艺”，不要只写“传统、民族风”。

## 5. 道具连续性与状态变体

按状态变化建立 ID，不按每一镜建立：

| 状态 | 例 |
|---|---|
| 初始 | `【玉佩-完整未启用】`，温润青白玉，系在角色腰侧 |
| 使用中 | `【玉佩-灵光初起】`，仅剧本明确有灵光时使用 |
| 使用后 | `【玉佩-裂纹】`，裂纹位置和形成事件明确 |
| 交接 | 同一资产 ID，记录持有人变化，不复制成两件 |
| 损坏/遗失 | 新状态变体，记录发生场次和后续是否复原 |

状态卡要能让图像模型区分“同一个物件被使用后”与“换了一件新物件”。尺寸、颜色和关键刻痕尽量稳定；视角变化不等于形制变化。

## 6. 图像生成提示词模板

```text
影视道具资产图，【道具ID】；【时代/地区/工艺】；【本体形制与尺寸感】；
【材料与表面状态】；【关键结构与纹样】；【剧本规定的文字/不可读纹理】；
【中性背景，单体清晰，三视图或45度视图，柔和均匀光线，材质可辨】；
保持形制、比例、文字和状态一致；禁止现代替代品、额外配件、重复道具、
可读乱码、无依据的超自然效果、字幕、水印、Logo、UI。
```

需要放进场景时另写合成提示词，增加地标、使用者、光源和动作；不要用场景合成图替代资产单体图。
