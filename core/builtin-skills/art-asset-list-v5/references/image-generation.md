# 生图前置与参考图边界

美术文本分析输出只给客观资产内容。AI真人、3D动漫、2D动漫画风和四格布局由软件生图阶段添加；生图前置不属于文本分析输出，不能重复写进每条客观描述，也不能因切换画风改掉演员脸和衣服。

单人默认布局使用以下原文，不增加第五个正面全身格：
白色背景，4格统一排版，左侧1格为胸像大头特写，右侧3格为全身照三视图，所有画面中的主体完全一致，面部特征完全统一、发型完全同一、服装、完全统一，身材比例完全统一。

此处三视图为同一套妆造的正面、侧面、背面，不是三套衣服。人物基准可完整客观描写；第二套以后保留参考ID，提示词只描述妆造差异，参考图片负责锁定原面貌、形体和画面排版。衣物完整穿戴，不平铺散件，不加入剧情动作、视线、表情或台词。

同一人物后续套装默认引用该人物第一张定稿图，可手动改参考或取消；取消参考后若只有差异描述，不应伪称可用第一张脸，需提醒选参考/先建立基准，不能偷偷重写另一张脸。没有收到图时不能声称看过图。

同地点时间变化默认引用该物理场景的基准图，提示词只说明什么时候和如何改变光线；不再重写门窗、床桌、摆放、墙地材质。实际不同房间和内外不互当同一基准，除非用户明确选择额外参考。

群像不使用单人四格布局，按原数量/软件默认6人做一张完整全身群像，个体有差异，不遮挡、不复制同一脸；场景无人；道具单体背景与类别前置由软件统一添加。单张与批量生图调用同一当前已保存提示词与参考规则。
