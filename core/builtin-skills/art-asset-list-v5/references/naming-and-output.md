# 稳定命名与行舟影视输出

所有ID优先沿用已定稿名，逐字一致。人物【角色名-具体套装】、场景基准【地点-内/外】、道具【物件名-必要状态】。角色首次基准可以叫日常服/基准造型，不同时生成一个无衣基础人物和另一个日常人物。

不要把场景塞进套装名而制造每场一套；同样的“便服”“常服”“日常装”有同一衣服证据时选已有ID，不自行换同义名。不同人同称谓只有证据确认才合并。同名不同实体应加稳定必要限定避免跨类别冲突，不把名字相同视为实体相同。

固定层级和顺序：
### 第N集
人物：
- 【资产名】描述
场景：
- 【资产名】描述
道具：
- 【资产名】描述

无内容用“- 无（本集未识别到该类资产）”。标题平级，类别不缩写不变顺序；每个真正条目仅起始一次“- 【资产名】”。衣服内层、中层、外层、下装、足饰写普通描述字段，不另立资产，不拆穿戴部件。

首次基准：写完整客观描述。后集同形态：“- 【原ID】（复用自第N集）”，免重复长描写。新套装：“- 【角色名-新套装】（首次，换装；参考【角色名-基准造型】）服装差异：……；妆造差异：……”。

新场景基准：“- 【韩川出租屋-内】（首次）时间光线：凌晨；布局和陈设：……”。同一地点时间变化：“- 【韩川出租屋-清晨-内】（参考【韩川出租屋-内】）时间光线：清晨，只改变清晨自然光线。”只在确需单独光线图时保留一个差异项，同地点同时间内外反复出现只列一次。

旧项目已有【地点-时间-内/外】基准时沿用该名，不升级时强改ID或丢图；新时间差异指向首次已定稿的旧ID，也不再次完整描绘空间。

完整模式三大总览平级：“## 人物总览”“## 场景总览”“## 道具总览”。人物按主要→次要→群演，妆造归同一人物；场景按地点基准归组，时间光线差异在其下；道具按本体首次顺序。总览从实际按集清单聚合，不再解析成第二批资产。审计与未出镜说明在三总览之后，不混入生成项。
