# 道具本体、文字与必要状态

道具是原文出现且有独立视觉/叙事用途的物件：手机、武器、信件、证件、包、被操作或成为线索的实物。固定背景家具与普通合理陈设留场景，不为每个床头物件生成独立图。物件属于某人不等于人物；【苏橙橙手机】与【苏橙橙】分类必须不同。

首次道具写形制、关键结构、大小尺度感、主辅材料、工艺、颜色纹理、用途、合理磨损、剧本要求文字与状态。现代设备匹配原年份地区；历史器物匹配时期阶层工艺。没有指定品牌就描述品类，不凭Logo堆价格。

同物件跨集复用，不因换持有人、换景别、持物方式或放在另一个桌子上复制。明确本体破损、关键开合、剧情必须读清的文字变化或明确超自然状态且有独立视觉价值时才建必要差异，回指原道具。短暂亮屏和普通社交页面默认复用手机，不每到一个地点建立一部新手机。

可见系统面板若剧本明确需要视觉参考，作为道具/界面本体描述矩形比例、色材、透明度和必要图形，不套人物脸型、眉眼、服装。不生成人形资产的标记不意味着可见物件本体也必须丢失；纯系统声音、无画面提示、抽象概念则不生图。

文字按剧本逐字保留，未给的屏幕通知、信件、标签、符咒不补可读内容，注明不可读纹理。不要从金额/截图界面凭空编新剧情结果。

玄幻道具先本体后效果，只展开剧本已给的魔气、灵光和能力；效果不遮住握柄、本体和材质，不发明新等级、攻击、敌人、灾害。现实武器只做影视视觉和安全道具设定，不给制造、改装或攻击教程。
