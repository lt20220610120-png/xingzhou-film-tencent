# 场次头、物理场景基准与光线差异

场景只按剧本真正的场次头建立索引，如1-1、1-2。每个头记录原编号、地点原文、时间、内外；第一处出现的场次场景是该物理空间基准，不能从段落中的床边、角落、桌旁、手机画面或对白提及地点再拆多个场景。

## 基准与去重

以物理地点+内外为基准，同一地点只设一次完整空间。真实不同房间（出租屋客厅/卧室）和内外空间不得强行合并，只有剧本明确同一空间的别名才归并；也不因为同一房间换时间就当成新房间。

首次基准写建筑/空间尺度、可确定布局、主要陈设、材料、主辅色和原时间光线；布局补全是有标记的最低设计，不为每次生成重新换床桌摆放。固定陈设不要都单独提升为道具。

同一地点仅时间不同，用“参考【韩川出租屋-内】”，只改变清晨/凌晨/夜晚等时间光线；提示词不重复其他怎么摆放、墙地材质、门窗、建筑结构和空间描绘。必要的同地点时间版本是光线差异卡，不是另一个重新设计的地点。时间内外完全相同的重复条目去重；同一时间可多场复用原ID。

例如：1-1 韩川出租屋 凌晨 内→【韩川出租屋-内】（首次）完整空间与凌晨光线；1-2 韩川出租屋 清晨 内→复用其物理基准，若要单独清晨图，仅【韩川出租屋-清晨-内】（参考【韩川出租屋-内】）时间光线：清晨，只改变晨光。不能从这两场扩出出租屋凌晨、出租屋清晨、出租屋床头、出租屋门边、手机屏幕等多个完整场景。

旧清单已有【韩川出租屋-凌晨-内】且已定稿图片时，以该旧ID作基准，不升级时重命名丢图；新增清晨只回指该基准并改光线。名称不同但无同空间证据的“出租屋”与“出租屋客厅”不猜合并。

## 真正空间变化

剧情明确装修、搬家、烧毁或布局永久改变且需要独立参考时，才建立空间状态差异并注明依据；天气、季节的明显视觉差异按剧本和实际需要决定，不把轻微氛围变化量产。未写明时代建筑、地区或陈设风格只能最小推断，不能当原文事实。

场景图不要任何人物。后续时间图用参考保持相同构图和陈设，只改光线；用户手动选不同参考可以尊重，但默认不跨房间引用。软件单张与批量使用同一参考解析。
