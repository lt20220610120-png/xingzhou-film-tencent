# 行舟影视 COS 省费与购买清单

## 这次交付

本地 Windows 安装包版本 **2.3.1**。安装后生效，不需要购买新服务或修改后端。参与协作的其他电脑也需要更新，才能减少各自的重复下载。这次没有发布线上更新、购买资源包、修改存储桶或删除云端文件。

- 协作资产、历史图片、分镜选图器和参考图栏：可见时才加载；通过原有服务端接口检查权限后，复用本地原图。
- 图片预览、导出，以及需要在本机读取图片字节的 AI 参考图调用，共享同一缓存。同一原图更换短期签名 URL 后也可复用，同时读取会合并。
- 图片保持原始质量；缓存图片数据上限 512 MiB，单张超过 32 MiB 不持久缓存。按最近访问淘汰，30 天未使用的文件在后续缓存清理时移除。损坏文件自动重新下载；写缓存失败仍返回下载结果。
- 缓存位于软件资料目录的 `.cloud-image-cache`，按账号和对象路径区分，普通刷新不用手动清空。
- 视频/音频参考和结果列表使用按需加载；点击播放、打开作品预览后正常读取。

限制：新电脑第一次读取原图、主动播放/下载视频、第三方模型服务器读取 COS 链接，仍可能产生流量。聊天图片、外部地址和不符合原图缓存条件的旧对象仍使用原访问方式。这次没有压缩原图、开启付费图片处理，也没有改已编译的独立无限画布模块。缓存减少的是重复访问，不能保证 COS 账单归零。

**资源包规格计算：** 所有常用电脑更新后，观察 7 天外网下行 GB；用 `7 天合计 ÷ 7 × 30 × 1.2` 估算下个周期额度，再选择控制台有售且经济的规格。如有发布会、集中导出或新增成员，要额外考虑。若优化后仍平均 9.5 GB/天，30 天约需 285 GB，100 GB 大约只能支撑 10.5 天；若降到 2 GB/天，则每月约 60 GB。以上是计算示例，不是实际监控结果。

购买路径：腾讯云控制台 → 对象存储 COS → 资源包管理 → 购买资源包 → 外网下行流量包。核对适用地域、计费项、周期额度、生效时间、剩余有效期和续费规则。资源包不是无限量包月，也不能默认追溯抵扣已结算的历史扣费。[资源包介绍](https://cloud.tencent.com/document/product/436/36523)、[计费计量常见问题](https://cloud.tencent.com/document/product/436/30747)

**价格说明：** 未能从官方动态购买页取得你账号的当前可成交报价，因此没有沿用 AI 提供的“100GB 每月 16.75 元”。请以[腾讯云 COS 实时定价页](https://buy.cloud.tencent.com/price/cos)和下单页面为准。比较资源包总价与预计实际使用量的按量费用，额度买得太大也可能浪费。

CDN 的总成本同时包含 CDN 下行、COS 回源和 COS 请求费，不能只拿回源单价和直连下行单价比较。第三方 CDN 回腾讯云 COS 可能仍按外网下行计费。[官方流量计费说明](https://cloud.tencent.com/document/product/436/53863)

低频和归档有数据取回费用，且存在最短存储时长条件；更适合已完成、少访问的项目。[取回费用](https://cloud.tencent.com/document/product/436/53862)、[存储计费常见问题](https://cloud.tencent.com/document/product/436/30747)

## 不需要购买，但建议核对的控制台配置

1. **核对桶访问权限。** 软件已通过后端获取短期签名。确认桶 ACL、对象 ACL 和桶策略没有不必要的匿名读取；先检查实际配置和其他业务依赖再调整。没有直接修改你的云端权限。
2. **不要直接套用“只允许自己域名、拒绝空 Referer”。** 这是 Electron 桌面软件，Node 下载和第三方模型取图可能没有 Referer，硬套域名白名单会导致图片/参考图失败。应以私有访问和受限签名为主，Referer 规则做兼容性验证后再用。[官方防盗链配置说明](https://cloud.tencent.com/document/product/436/13319)
3. **配置余额、费用和用量告警。** 建议先设日费用达到 5 元、月费用达到 100 元的提醒，再按实际业务调整；这是建议阈值，尚未在账号中设置。告警不等于硬停机或费用封顶。
4. **检查流量来源。** 在 COS 监控/日志中按时间、对象、来源 IP 查看大流量是否集中在原图、视频或某个客户端。若要启用额外日志服务，先看该服务的存储与查询费用。没有读取你的实际访问日志，故无法归因到某个用户或确定盗刷。

## 如何验收省费效果

保持项目、参与人数和工作内容大体相同，比较安装前后各 7 天：外网下行 GB、日费用、用量峰值，以及是否有集中导出/播放视频。可先在同一电脑打开一组图片，再刷新、打开分镜选图器、导出相同图片；缓存条件满足且未被淘汰时应复用原图。以 COS 实际账单和用量为准，不能仅根据本地测试声称已节省某个金额。
