# 在行舟影视连接 Like 画布

适用：行舟影视 2.8.56 或更新版本，Windows Edge / Chrome。Like 无官方画布 API；本连接通过已登录网页工作。不要向 AI 或聊天发送 Cookie、登录密码或 API Key。

## 首次配置

1. 打开行舟并登录，在“API 接口”点击“连接 Like画布”（图视生成的接口设置也有入口）。
2. 点击“打开扩展文件夹”。在 Edge 地址栏打开 `edge://extensions`（Chrome 为 `chrome://extensions`），启用开发人员模式，点击“加载解压缩的扩展”，选择刚打开的 **1.0.0 文件夹本身**。不要移动或删除此文件夹；它位于当前用户资料中。
3. 安装后刷新已经打开的 Like 页面一次。在行舟生成8位配对码，点击浏览器工具栏中的“行舟影视 · Like画布连接”，输入配对码。配对码10分钟有效，仅用于这台电脑。
4. 在浏览器登录 Like，打开有编辑权限的项目，选中要生成视频的画布。保持该网页打开。
5. 回行舟粘贴项目网址（例如 `https://likeai.pro/projects/6ad71ee9c0858c003d446e47`），刷新连接，选中观察到的画布，点击“保存并启用这个画布”。画布名称旁显示已连接。
6. 在图视生成或项目协作的分镜中选择新保存的 **Like · 画布名称 · Seedance 2.5** 接口。提示词、图片/音频/视频参考与画幅、秒数、分辨率，在点击生成时发送到这个画布。默认480p，画幅16:9或9:16，时长4–30秒；上限30图片、10音频、10视频，仍以网站当前实际可用额度为准。

旧“本机实验”接口使用临时服务，不会自动替换；首次成功绑定后，选择新保存的接口进行后续任务。旧记录仍保留，不要把未确认任务重新生成。

## 以后使用

关机前无需重新配对。重启后打开行舟并登录，再打开保存的 Like 项目和目标画布，扩展会恢复连接（通常数秒到30秒）。Like登录过期时先在浏览器重新登录。关闭所有浏览器、关闭目标网页或停留在其他画布时无法提交；恢复连接不会自动生成任何视频。

新建项目时，在同一配置页换填新项目网址，打开那个项目的目标画布，再保存即可。旧绑定保留，在“已保存画布”点击“使用”切换。

## 遇到问题

- **尚未配对**：确认扩展已启用，然后重新生成配对码输入扩展。更换浏览器、浏览器配置或 Windows 用户后需要重新配对。
- **等待打开画布**：打开精确的项目和画布，确认登录、编辑权限及 Seedance 2.5 可用，再刷新连接。首次加载扩展后应刷新原网页。
- **本机端口被占用**：关闭重复运行的开发版连接服务，再启动行舟。新连接使用本机18764端口，与旧实验18763独立。
- **网页结构变化**：更新行舟和扩展；请勿为了恢复连接重新提交旧任务。扩展读取网站工作台，网站改版可能需要适配。
- **提交未确认**：先点击结果中的“打开原画布”检查节点和网站任务。刷新结果仅查询原任务，不会重新生成。没有可靠回执时不会声称任务成功；已经发起的任务可能仍在网站运行。
- **准备超时或退出/切换账号**：本机停止授权，尚未发起的生成不会继续。网站已接受的任务无法通过关闭行舟撤回，请在原画布核对。

## 给协助配置的 AI

仅通过软件配置界面和扩展完成安装、配对和绑定。不得提取登录 Cookie、注入开发者控制台脚本、把用户密钥写入文档、把其他项目素材自动带入当前任务，或通过生成收费视频测试连接。用连接状态核验；实际生成由用户点击。若支持全新网站域名或改动网页结构，需开发者更新适配，不能仅改 Base URL 伪称已完成。
