# 行舟影视 2.8.168

- 统一云端、飞拓、FT、自定义视频接口和素材直传使用桌面系统代理/PAC；保留写入请求单次提交，避免网络中断时重复生成或重复扣费。
- 自定义视频适配器的素材上传、任务提交、状态查询和结果下载改走统一网络层；任务状态继续落盘，断线后只查询原任务。
- 分镜单条保存改为短确认回执，不再把整部大项目正文作为保存响应传回；回执丢失时读取云端同一条分镜核对，确认一致才继续生成，避免“已保存却显示未保存”。
- 保存回执按分镜发布批次合并到当前页面，首次直接保存会建立本地独立分镜副本；账号切换期间不接受旧回执。
- LibTV 账号、模型目录和节点只读查询断线后自动重新探测一次网络路径；创建项目、上传素材、创建节点和点击生成不自动重放。

本版本重点解决跨接口的网络路径不一致、云端大项目保存回包过大及分镜保存确认丢失问题。真实付费生成仍遵循“提交一次、结果只查询”的原则。
