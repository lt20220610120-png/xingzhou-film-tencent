## 改动审查

- 原分支改动为 18 个样式文件和 3 个 JSX 视图。独立复核了构图设置、资产批量操作、音色工具、分镜参数与批量队列的事件绑定、启用条件及确认流程。发布代码改动仍限于这 21 个前端文件。云端服务、桌面 IPC、业务状态和持久化接口沿用原实现。
- 合并复核时修正视频池计数、分镜选集标签和超创模式说明的文字对比度。分镜工具栏保持视觉与 Tab 顺序一致，资产分类暴露选中状态，生成规则提示的可访问名称与屏幕一致。
- `AGENTS.md` 和 `Hermes协作进度.md` 记载四级文字色与 4.5:1、可折行操作栏、标准控件 36px 高与 8px 圆角、白色激活 Tab、唯一品牌紫主操作和 HoverInfo 约定。

## 隔离验收

- 1280、1600、1920 像素隔离 Electron 覆盖资产、音色、分镜与视频池，共 59 项实测记录。受测工具栏可折行、无横向裁切，抽查标准控件为 36px，资产规则可由键盘查看并用 Esc 收起，分镜参数与批量区对齐。音色和视频池筛选继续正常。
- 九组主题前景与背景对比度实测最低 5.42:1，抽查资产标签、三态音色和分镜摘要文字均达到 4.5:1。
- 3,367 项 Node、13 项 Python 发布测试、12 项本地 Qwen 测试与 Vite 构建通过。共享弹窗、原生下拉、窗口保活、停轮询和各工作台导航的隔离 Electron 回归通过。
- 2.8.207 弹窗和双模式删除、分镜滚动保位和切场回顶、资产无需参考图以及五类历史 Windows 加密凭据读取通过回归。
