# 云端与本地回收站衔接 / 2.8.13

日期：2026-10-09。问题依据：cloud-recycle-2.8.12-audit.md。

## 修复与范围

1. 协作项目仍活跃、处于三天恢复期或期限无法确认时，禁止删除关联导演源。支持本地 ID、云端 UUID、cloud-UUID 及历史来源标记。删除、创建、恢复继续使用同一源行锁，防止交叉操作破坏引用。
2. 旧本地协作关联仅在服务器明确返回对应项目/关联 ID 的 released 后解除。空列表、网络失败、访问权限变化不会触发解除。并行查询返回矛盾快照时，明确活跃/可恢复的关联优先。成功解除云端关联保留本地原稿与分集。
3. 界面删除/恢复按钮按当前项目 owner_id 显示，受邀的全局制片身份不能代替该项目所有者。恢复错误区分 403 权限、410 真正到期和 409 导演源不可用；异常显示在界面。

本地默认七天与云协作三天保持独立；项目协作继续使用云端回收接口，不写本地回收站。导演云端文档仍使用云端管理的永久删除流程。没有增加 COS 对象物理删除；界面准确说明到期清理项目及数据库关联记录。
