# 2.8.55 自动分段重构

用户要求：先估整场表演时长，用单条最高时长确定条数，再在固定条数内选择自然衔接。中文 4～5 字/秒只是参考；英文按词与实际表演估算，中英对照不重复计时。时长提示不能阻断 Skill 生成。保留本机 2.8.54-private.1 的提示词联动美术能力，公开发布 2.8.55。

核实根因：

- 旧 `directorTiming` 将所有文字（包括英文）按字符数除以 4，且 `recalibrateScenePlanTimings` 强制覆盖模型估时。
- 规划、打包、恢复、最终写入分别有旧时长硬门槛；仅改提示词指令不能解决。
- 英文多词说话人解析不完整，双语翻译未识别。
- 本机试用开关只在安装包 metadata 中，直接覆盖普通安装包会丢失入口。

实施：

1. 新增整场预算规划器：语言计时参考、保守识别双语对照、整场 AI 估时、固定条数、自然边界优化；结构坏包用本地可追溯计划恢复。
2. 自动模式生产链路使用新规划器；旧计划/已付费文本继续保留，已生成结果不因新估时丢失。时长与衔接问题作为核对提醒，内容身份/覆盖/权限仍严格校验。
3. 同一个原 Skill 接收完整编号场景；计划 N 条就请求 N 条，少回包继续补齐，先展示已返回内容。
4. 试用功能改为设备本地持久能力；公开包新安装仍关闭，拥有者已启用设备升级保留，不发布私人资料。
5. 用户场景与英文单语、中文、双语、50/70 秒、同人连续对白、短场景、异常模型与恢复/整本流程测试；真实 React 模拟接口与打包运行验证；独立复核；发布及本机安装验证。

不以模拟 API 宣称真实模型永不出错，不运行付费视频/图片生成。

追加需求：2026-10-20，AutoDL 提交报“临时素材额度已满”。服务器只读统计实际100个、150686074字节、0到期，命中100个数量限制而非本机磁盘不足。原上传复用缓存仅进程内，重启会重复上传；没有用户清理入口。新增内容哈希复用、持久任务租约、按当前账号列出与安全清理、到期预清理及原子额度预留，数量调整500、每账号容量仍1GB。旧版无法证明任务已结束的副本不提前清除，到期自动清理；新任务结束可手动释放副本，原文件与生成结果保留。设置与生成参考区共用管理窗口，删除前确认范围和数量，失败返回名单。云端3文件原版哈希校验、备份与回滚后部署，不修改数据库schema或真实项目。
