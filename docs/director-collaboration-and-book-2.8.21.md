# 导演多人协作与整本提示词 / 2.8.21

日期：2026-10-10。

## 运行规则

每个成员拥有自己的本地副本。编辑总稿、场景、导演构想、提示词和 AI 生成均先保存本地；“刷新云端”仅读取，不提交本地修改。“上传云端”先落盘当前完整副本和提交 ID，再上传点击时的固定快照。上传期间继续输入的新内容仍是本地修改。

共享端在项目行锁下三方合并。无冲突改动更新共享版本；同处冲突仍保存整个提案，共享当前版本不覆盖。成员可分页查看全部云端版本、查看原稿并取回自己的本地提交前版本；仅制片能采用冲突稿或恢复整份历史。采用冲突稿保留其他成员的无冲突改动；整份恢复另存恢复前内容。采用操作以读到的当前共享文档作比较，期间另一成员上传会阻止覆盖并要求刷新。上传 ID 防止断网重试产生重复提交。

版本表无定期清理，应用权限仅 SELECT/INSERT。项目被永久删除时随项目删除；活动项目的版本历史不受本地 7 天、云回收站 3 天期限影响。旧 director-project-update 返回 426，要求使用 2.8.21 的手动版本入口；成员应统一升级。

既有无同步基准项目保留本地正文、提示词、场景编辑与导演构想，不猜测哪方更新。取得远端版本后由用户选择或上传冲突提案。迟到云端列表不回退已收到的新版本。导入产生的空删除标记不算一次真实删除修改；非空删除记录保留。制片采用成员稿后，已解决的旧冲突提示清除。

## 整本生成

顶部模型选择右侧入口，开始前预览并确认。人工模式沿用当前集、场景及独占行括号编号；一场一次执行原有完整 Skill，不插入自动划分调用。没有括号按一条生成，重复或空白分段先提示整理。自动模式保留原自动划分、时长估算和核对流程。使用当前所选模型与 Skill 处理整本，设置页和已有结果在预览中列明。

并发支持 1/2/4/8/16/32/all，人工新配置默认 2。默认跳过已有提示词的场景（不宣称其完整），可明确选择全剧重新生成并保留旧结果。批次、子任务与回包持久保存；每条结果使用预分配 ID，恢复不重复追加。人工回包先存再解析/落入项目，解析异常可在任务中查看原始回包，继续不会循环重调用同一已付费回包。暂停停止接纳新场景，已启动请求保存后暂停；结束/切号/切目录取消请求并保留回包检查点。

人工与自动任务检查点隔离，切换模式不调用错误控制器。单场正在生成时，整本开始或恢复均阻止；运行中的整本任务也禁单场生成。原文、权限、账号、模型、Skill 或设定变化后，保存返回原稿但停止覆盖新内容。
