# 快速模式时长参考

本规则用于快速预演，时长是建议值，需要真人节奏和最终视频验证。动作秒数是结合用户给出的例子制定的剪辑默认值，研究资料不提供所有动作的固定秒数。

台词按用户要求以中文口播约4字/秒为快速模式初值，3字/秒用于较慢节奏参考。对白、OS、VO均计时，标点、人物标签和环境描写不计口播字。数字和字母也计入可听内容。语速不是跨语言固定常数；[Bradlow 的语速研究](https://www.isca-archive.org/interspeech_2019/bradlow19b_interspeech.html)讨论了语言和说话条件对时间组织的影响，故本软件保留估计性质。

|表演|快速默认|参考范围|重叠处理|
|---|---:|---:|---|
|眼神、皱眉、短反应|0.8秒|0.5–1秒|可随相邻对白发生|
|抬手、拉人到身后、擦泪|1.2秒|0.8–1.5秒|可随相邻对白发生|
|取出、递交、放入小道具|1.5秒|1–2秒|允许口播同步，受原文次序约束|
|短走位、起身、转身|2秒|1.5–3秒|允许口播同步，受原文次序约束|
|快速攻击与即时反应|2.5秒|1.5–3秒|可配紧邻OS；不越过中间动作|
|动作麻利的摸索搜取|2.5秒|2–3秒|可配紧邻OS，保持原文声源|
|关门、调出面板|0.8秒|0.5–1秒|关门优先完成再接后文声音|
|咬汉堡、皱眉、塞入口、转身进店|3秒|3–5秒|按一次连续表演；不额外强加空镜|

静态光线、陈设只是已有画面的背景，不自动加空镜。原文明示长距离、追逐、等待、慢动作或持续秒数时不套短动作；未知动作保留规划估计并交给模型按情节判断。复合句含明确等待时，不把等待秒数误作整句全部表演时长。

同一时间的动作和声音按重叠计算；普通切镜不占额外时间。并行必须符合原文因果和状态；不能跨越独立动作把前面打斗强行叠到后面搜取时的OS。剪辑可让声音跨画面承接，[Adobe 的 J/L cut 指引](https://helpx.adobe.com/premiere/desktop/edit-projects/trim-clips/perform-j-cuts-and-l-cuts.html)说明了这种连续方式；实际提示词仍保留人物、原台词、开始/继续/结束镜号。

镜数只作密度参考：30秒常见10–13镜甚至更多，15秒约5镜以上；长对白可少镜，不能为凑镜数补戏或增加片段。整场短于上限时只输出一条真实短片；超长场在接近上限的窗口切分，真实尾段保留余量。40秒原文在30秒上限下是30＋10，10秒原文是一条10秒。

用户反馈样例：第3-2场51口播字，加不重叠动作约16秒；第3-3场106口播字，约26.5秒口播加同步表演，约28秒一条；汉堡进店约3秒。具体生成仍须保留原文，不用加快或删台词迎合某个预期秒数。
