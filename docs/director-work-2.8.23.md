# 2.8.23 导演工作协作修复

截图的 QuotaExceededError 来自单场回包 localStorage.setItem，发生在模型已返回后、提示词拆分之前，与模型读取整本或吞吐量无关。现在单场调用与整本相同的 manualController：检查点先写项目资料目录；付费回包先落盘，再校验人工分段和提交提示词。原始回包也归入 episode.manualSceneReplies，供共享文档和版本预览使用。自动分段回包按稳定 run/response 编号归入同一记录列表。

协作CRDT此前已携带 episodes 内 quickSceneEdits、sceneVisions、prompts；当前补齐原始回包和项目级历史显示。单场快速请求仅含当前场景+项目风格/画幅+完整Skill；创造模式含当前导演构想+同样前置。初次入项目仍需原剧本素材供成员阅读，后续只传字段增量，不把未改的总剧本作为每次成果上传。

恢复回执现在以制片选择为准：保存恢复前本地副本，停止旧客户端，应用恢复内容、清除旧冲突和本机墓碑，再在相同账号/项目/目录范围重建连接。等待期间切换身份范围后不会回写其他范围。历史默认预览导演工作而非整本素材，保持有界分页。

迁移旧localStorage回包按账号/项目/集/场/完整记录摘要识别，写盘成功后且原key未变化才删除；保存失败保留旧缓存。不会以一个成员的同序号记录覆盖另一成员的回包。

验证采用模拟模型，无付费请求、不修改用户项目。三人实际App验证快速编辑、导演构想、提示词、历史恢复，原素材82965字不改；填满Storage仍能生成和共享；整本弹窗选择框与按钮下边缘相差不足1px。

追加验收：创造模式实际调用模拟Skill成功；删除提示词后恢复制片选择的历史，三个窗口的历史提示词页均可见成果。账号/项目/目录在等待旧同步停止期间切换的隔离回归通过。普通远端更新保留已脱离分集的本机历史，只有明确恢复旧版本才权威替换。
