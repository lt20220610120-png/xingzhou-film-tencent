本次按用户五项反馈直接修改、验证并发布。实现提交 `5bdcec0`，保留已有稿件、集纲版本、人物关系与原有权限保护。

## 行为变化

1. 框架工作台外层滚动容器改为裁切，不能再保留工作台之外的滚动位置。内部当前内容区仍可滚动，顶部工具栏固定；最后卡片之后只保留正常间距。
2. 本机 ChatGPT 连接打开登录窗口时复用已有后台浏览器，状态超时只重连传输；下一任务通过网站的新聊天控件切换，不再通过程序导航回首页。没有点击、求解或绕过人工验证控件，账号登录及网站验证仍由用户在原窗口完成。
3. 正文按已有场次标题提供分场查看，编号保持本集实际序号，如 1-1、1-2、2-1。全部正文继续本地编辑；查看单场景不改写原文。显示整集及所选场景字数，按 Unicode 字符统计并排除空白。
4. 写作规则要求依据确认故事设计执行细节、场景、动作与对白，不因提纲缺少对白而停止剧本化。对摘要、错误编号和缺失剧本要素自动修订，最多两轮；原始结果和每轮检查留在历史。批量中一集仍不合格时继续后续集；验证、登录、额度、网络或停止操作不进入无限重试。
5. 集纲划分按钮先打开要求窗口，选择接口并填写意见，可明确自动、准确集数或至少集数。数量要求进入模型上下文，也在采用时校验；结果先作为候选，审阅后保存新版本。
