# 2.8.9 登录窗口、场景卡片与侧栏分类

## 根因与修复

2.8.8 将已有后台浏览器直接恢复，但 Windows 后台启动器此前把浏览器放在另一个 Win32 桌面。CDP 的恢复与置前命令无法将该桌面的窗口显示到用户桌面，模拟 CDP 响应不能证明真实窗口可见。

ChatGPT 现在使用独立资料目录，在用户当前桌面以最小化状态启动。保留后台进程及其页面，点击登录时恢复同一个窗口。Windows 原生窗口控制仅作用于本次启动器拥有的浏览器进程，显示仅由用户明确打开登录窗口触发；没有切换系统桌面、点击验证码、提取网站凭据或改写浏览器身份。后台启动器的 Job 对象仍负责回收该进程树。其他独立后台浏览器的原桌面策略保留。

首次显式打开登录时等待实际浏览器连接和窗口恢复，不能仅提交启动命令就显示成功。错误进入界面提示；连接状态超时仍保留已有登录页面。

正文取消下拉选择，全部场景编号卡片直接排列在内容区上方。统一高度 42px、每行等宽，自适应换行，选中状态清晰；完整正文仍可编辑，单场阅读沿用原文，不修改或重新生成场景。保留整集、单场字数。

侧栏使用可展开分类组，成品库有果子库与 IP 库，创作剧本有洗稿与原创。悬停只展开，不导航；点击分类发出唯一导航请求，清除对应项目选择，进入项目列表。持久工作区没有为了分类切换强制重挂载，资料保留；页内分类切换也同步侧栏当前标记。键盘焦点可进入子菜单，Escape 关闭，减少动效设置受到尊重。
