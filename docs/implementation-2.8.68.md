# 2.8.68 清理修复与设置/授权界面 Implementation Plan

**Goal:** 清除结果时不残留待核对卡片，设置入口成为右侧明确按钮，授权管理形成统一浅色卡片层级。
**Architecture:** 继续复用 GenerationResults 和 generation-jobs；未知提交只归档、保留任务身份及文件，所有迟到查询继续保持归档。设置两张工具卡提取独立展示组件；授权仅调整 React 标记和局部样式。
**Tech Stack:** Electron/Node、React、Vite、Playwright 模拟接口。
**Spec:** 用户2026-10-24三张截图；AGENTS.md授权直接实现验证发布。

## 约束与复核重点
- 2.8.67授权门禁、豁免、发卡/导出/解绑/审计协议保持；绝不输出完整卡密。
- 不清理用户真实项目或调用真实收费生成。运行中任务继续保护。
- 待核对归档后刷新、重启、迟到查询不能重新显示；文件与任务身份保留，不能触发重发。
- 当前选中视频/图片类型隔离；受共享引用文件和事务回滚继续保护。
- 窄窗按钮/表单/表格可用，空表有空态，统计加载和错误不伪装为真实零。
