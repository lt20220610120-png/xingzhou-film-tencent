本轮是布局预览，正式版本保持 2.7.13，等用户选择方案后再制作和发布更新。

- 方案一：顶部切换“对标拆解／新作”，项目协作保留侧栏。
- 方案二：阅读和编辑区占满可用宽度，点击“打开项目协作”显示浮窗。
- 设定、大纲、主线、人物采用同一套切换方式；对标书逐本切换，大纲按 A／B／C 组切换。放大字体，统一白色卡片和深色正文。
- 主线按大纲小事件的稳定 ID 组织逐集提纲，A1、A2 等标签随大纲顺序变化。旧主线原文保留，用户可通过“整理为事件集纲”生成候选再确认。
- 主线支持编辑集纲、关联小事件、增加和删除组内集纲；正文分集及已有 Agent 功能保留。
- 复现并修复“原创 → 框架式创作 → 洗稿”导致洗稿列表为空的问题：原创子模式筛选错误地作用于洗稿项目，切换身份后才恢复。现在原创筛选仅用于原创项目。另修复跨库复用分组筛选，以及离开创作区时强制切换内部页面的问题。列表以规范化创作模式识别旧项目；选项目时同步记住洗稿／原创频道。
- 协作输入保留在当前会话，隐藏、切换布局、切换页面和修改模型不会清空未发送内容。

构建独立预览：先运行 `npm run build`，再运行 `node scripts/build-layout-preview.mjs`。双击生成的 `output/layout-preview/打开布局预览.cmd`。预览使用合成示例项目和模拟 Agent，独立保存至预览目录，不读取正式项目，不安装或发布版本。

验证：全套 1635 项测试通过；浏览器验证 32 项页面、编辑和持久化检查，以及 7 项模拟生成、候选编辑和浮窗运行检查；构建通过，独立 Electron 预览启动通过。验证截图与报告保存在 `output/playwright` 和 `output/layout-preview`。
