# 在行舟影视连接 LibTV

适用：Windows x64 行舟影视 2.8.37及以上（最初接入为2.8.27）。接入方式按 [官方使用指南](https://resonate.feishu.cn/wiki/RjelwT2UoidnTMka2nCc2chGnud) 和 [LibTV 官网入口](https://www.liblib.tv/plugin) 的浏览器授权/官方 CLI；没有使用旧 Access Key 接口。

## 连接

1. 登录你的行舟影视账号，进入「API 接口 → 连接 LibTV」。图视生成里的「API 设置 → 连接 LibTV」也可连接。
2. 点击「连接 LibTV 账号」。首次会下载并校验官方 1.1.3 连接器，之后打开 LibTV 官方登录页面。在浏览器完成你自己的账号授权。
3. 返回行舟影视，连接窗口会检查授权并读取图片/视频型号。需要时点击「刷新连接与模型」。可选择个人/团队空间和默认图片/视频型号；原有其他接口默认选择会保留。
4. 不用填写 API Key。登录凭据存在软件的本机专用目录，按行舟账号隔离，静态文件使用系统加密；普通 API 配置和协作项目不包含 LibTV 凭据。

## 图视生成

在「图视生成」选择「LibTV · 图片」或「LibTV · 视频」，选型号，填写本次提示词，按需添加参考。型号参数从官方 schema 读取；视频模式可自动匹配参考，也可选文生、单图、首尾帧、多图、全能参考等该型号实际支持的模式。额外设置随型号变化。

生成按 LibTV 所登录账号和当前空间规则消耗积分/额度，和官网画布生成对应能力一样；模型可用性、会员限制和审核以 LibTV 为准。没有绕过真人参考审核或上游限额。首次任务需要创建画布、上传参考、创建节点，之后在后台等待；界面可以继续使用。

每次任务创建独立的 LibTV 画布，在结果卡片点「LibTV 原画布」即可查看。只发送当前提示词和明确选定的素材；不会把整个小说或总剧本自动上传。

## 协作分镜

进入「项目协作 → 分镜 → 选择分集/场景」。在分镜的「生成接口」选择已连接的「LibTV · 视频」，按模型设置后生成。分镜提示词按既有规则保存；视频成功下载后，按该项目权限上传到共享素材中，其他成员刷新即可查看。仅生成成果上传行舟云端，协作者不会获取你的 LibTV 登录信息。

每位成员用自己的连接和积分。使用他人的本机配置会被拒绝，需重新连接自己的账号。负责人控制的是行舟项目权限，不代表可以使用别人的 LibTV 积分。

## 找回结果和断开

- 已提交任务只运行一次官方生成命令。中断、下载失败或重启后，结果列表刷新会读取原画布/节点并继续下载，不会自动再生成。
- 官方明确失败的任务显示失败；提交或等待尚未确认时，请先打开原画布核对。软件不会把新节点的默认预览图当成生成结果。
- 在美术/资产里恢复 LibTV 图片同样查询原任务。若原任务在 LibTV 官网已经被删除，软件无法重建其成果。
- 多结果 ZIP 下载会在本机解出图片/视频。当前界面主要预览第一份；其他结果文件保存在同一任务目录中。
- 运行期间不能换账号、切换个人/团队空间或迁移资料目录。旧任务恢复要求原账号/空间匹配。
- 点「断开本机连接」移除本软件的本地凭据，已有成果保留。这不等同于从 LibTV 官网删除账号或撤销其他设备会话。
