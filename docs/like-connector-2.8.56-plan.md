# Like浏览器持久连接 · 2.8.56

用户确认Like没有官方画布API，选择浏览器连接组件方案。目标：首次加载Edge/Chrome扩展并配对，在行舟配置网址/当前画布/Seedance2.5；后续重启应用/浏览器和网页刷新自动恢复，不使用开发者控制台、不存取Like登录Cookie、不自动重新付费生成。保留本机private功能及用户已有项目配置。

架构：Electron管理仅127.0.0.1:18764服务，设备配对码限时换取扩展本机令牌；扩展后台请求loopback，MAIN世界打包脚本只与自身隔离content脚本交换命令，不取得本机令牌。只支持likeai.pro，只有明确绑定的项目+画布可提交；当前画布/权限/型号每次重验。新项目在行舟绑定网页当前画布。浏览器必须已登录且目标页面打开，丢失连接显示状态。

任务：先落盘任务身份，再派发；浏览器及画布均记录任务标记，已派发但未确认不自动重发，刷新/重启只恢复查询；先完成选中素材上传与绑定，再单次生成，未知/部分上传失败不得自动付费重试。认证、来源、账号、绑定和文件访问范围均验证，原图与项目资料不修改。扩展首次安装需要浏览器用户加载，不伪造商店安装或静默更改浏览器安全设置。

实现/验证：核心绑定profile、服务配对/生命周期/账本，MV3扩展，连接配置UI、生成与原任务查询/下载；模拟接口回归覆盖多账号/多画布/断线/重复派发/重启；真实扩展加载与只读网站联通/React UI，无真实付费生成；独立复核，完整测试构建发布与本机适配。
