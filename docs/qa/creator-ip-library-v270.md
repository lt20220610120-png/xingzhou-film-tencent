# 创作空间 IP 库 2.7.0 实施与验证记录

目标：在成品库中增加小说改编 IP 库，保留既有果子流程，实现完整 Skill、章节原文对照、逐集累计回读、版本保留、总稿同步与独立收录。基础版本 `583c993ce7dd45c2324a93d4a376ab80fa5707f6`；验证日期 2026-10-04。

## 实施范围

- 成品库提供果子库、IP 库两个通道；IP 项目独立筛选，既有果子项目保留。
- 支持 TXT、DOCX 和粘贴小说；导入正文独立保存，章节区间保留原文空行与换行。目标时长为 60／120 分钟，对应正文参考目标 4 万／7 万非空白字符。
- 内置用户提供的小说转剧本 V4 和故事梗概、人物小传完整 Skill 文件。通读全部已给小说后形成规划候选，人工调整、采用后建立分集；逐集写作发送此前全部最新正文和本集完整章节，再进行原文对照修订。
- 初稿、修订稿、手动稿和来源版本保留。编辑总稿与分集使用同一份正文；收录保存独立快照，可阅读、导出并返回原 IP 项目。
- 创作模型选择只使用 API 设置中已配置的模型，默认接口优先；框架创作沿用此规则。目录字号调整为 16px。

## 审查修复

- 旧源关联：节点与版本明确保存来源 ID、章节和细纲；采用旧稿恢复关联。重新导入、改章节、重规划前保留当前稿，后续手动存档沿用其来源；旧来源稿须核对当前章节后确认或生成。
- 缩短规划：旧尾集及全部版本转入可恢复记录，排除于活动目录、总稿、字数统计和连续转写；恢复由人工明确操作。
- 取消保留：取消响应中的部分正文或已返回内容随错误传递，并保留在任务记录；不自动采用为当前正文。
- 四项新增回归先复现失败，再验证修复通过；记录见本机 `qa/ip-v270-review-red.log`、`qa/ip-v270-review-green.log`。

## 本版边界

模拟接口验证请求内容、状态保存和页面流程，不证明模型实际阅读效果、文学忠实度或成片时长。正文仍需人工逐集核对；字数是非空白字符参考口径，含场景标题与标点，不含设定和集标题。未达篇幅目标的收录标为阶段稿；完整输入超过声明的上下文容量时明确报错，不截短小说或 Skill。
