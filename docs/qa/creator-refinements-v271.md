## 长小说与输出截断

- 通读默认每段最多 3200 个原文字符，按真实偏移取完整区间，并保护 Unicode 代理对边界。先输出紧凑事实笔记；输出截断时自动将该区间进一步二分，已成功的区间继续保留。
- 请求启用 `analysisMode:true`，阅读、汇总与规划分别使用阶段输出额度。不会把模型截断的结果冒充为完整结果，也不会删除原文或 Skill 来换取完成提示。
- 使用分层事实汇总控制单次规划输入；长小说先生成主线、真实终点和故事单元，再按每批最多三集生成分集规划。小批规划截断后继续细分，必要时收紧单集规划输出。
- 辅助阶段保留完整 Skill，并追加当前阶段的系统约束；正文篇幅和分场交付要求仅用于转写／审稿，规划只把篇幅作为预算。事实汇总目标 600–1000 个非空白字符、验收上限 1500；过长成功结果先保存，最多收紧一次，再按完整笔记单元二分，不截原始材料或结果字符串。无法压缩的单个单元有界报错。
- 成功汇总立即保存到任务过程记录。缓存按来源 ID、原文与输入哈希、完整 Skill 哈希、任务和用户要求校验；仅复用通过实际长度检查的完整汇总。已经两次过长的父范围可直接拆分并续用成功子范围，避免重试父范围；取消会阻止后续调用。
- 故事单元建议不超过 12，但在章节与总集数均合法时允许最多 100 个单元；总集数仍限制 100。每批 JSON 两次返回不合法时保留原始结果，再以更小批次重新生成并完整验证；任意网络错误不触发这类二分重试。
- 读取恢复基于来源 ID 和准确字符区间，兼容旧版较大的完整阅读记录。有效区间不重复读取，缺口补读；新小说来源不混用旧阅读记录。
- 截断、取消和失败返回的部分内容，以及已成功的设定提取片段，进入任务 `diagnostics`。项目记录中的 `IPTaskHistory` 可以展开查看这些过程内容；它们不自动覆盖当前正文。
- 逐集写作仍发送对应小说原文及此前最新完整正文；事实汇总服务于结构判断，不替代逐集原文回读。容量不足仍明确报错。

## WorkBuddy 闪屏因果与验证

发现两条共同造成灰色闪屏的路径：后台管理页记忆了 WorkBuddy 标签，身份切换后隐藏后台组件重新挂载仍会初始化；Electron 的 `WebContentsView` 默认可见，附加后到目标页面加载完成前会显示临时原生表面。修复分别作用于组件可见性和原生页面显示时机，没有绕过管理员权限验证。

- 前端只有进入当前可见的 WorkBuddy 标签才初始化；离开页面时隐藏原生视图，延迟状态返回不再打开隐藏页，明确返回面板时才恢复。
- 原生视图在加入窗口前调用 `setVisible(false)`，加载完成且当前显示区域有效后才显示。打开、恢复和隐藏使用代次校验，晚到的授权或加载完成不得覆盖较新的隐藏操作。
- 原生 Electron 43.2.0 复现报告 `qa/workbuddy-flash-native-v271.json` 返回 `pass:true`：修复前附加与加载中可见均为 `true`；修复后分别为 `false`，加载完成才为 `true`；加载期间切换隐藏后即使完成也保持 `false`。测试没有触碰真实 WorkBuddy 服务。
- 浏览器模拟身份切换与异步返回验证脚本：`qa/workbuddy-role-v271.js`、`qa/workbuddy-deferred-v271.js`。覆盖隐藏后台重挂载不新增初始化、离开后迟到结果不新增原生页、明确返回时打开／恢复，以及返回同一已打开面板不重启服务。
- WorkBuddy 原生边界、服务启动参数与权限回归包含于最终完整测试。测试运行使用隔离资料，不更改用户项目或账号池数据。
