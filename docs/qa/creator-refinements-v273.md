- 60/120 分钟新规划分别至少 50/80 集；不足时模型结果与采用操作均拒绝。分批最多输出三集细纲，避免一份长 JSON 承载整个计划。既有 43 集项目仍可阅读、续写，不自动迁移集数。
- 已读区间保留精确来源及检查点；汇总采用故事梗概与人物小传 Skill，设定提取使用事实笔记与所选主线、真实停点。分集规划失败时已生成设定也能恢复，重试复用成功阶段。

- 总稿队列包含遗漏设定，已有分集不重写。缺设定、运行、失败、停止、全部生成及待核对均显示状态。
- 仅 IP 剧本展示及成稿移除行首 Markdown 标题前缀，不删除普通正文 `#`，原文导出不变。已有集标题不再重复加包装标题。无操作编辑保留源字节；逐场编辑保留其他场景和 CRLF，合并标题行不会暴露隐藏标记。

## Gemini 网页实测

- 使用用户授权的独立普通 Edge 资料目录首次登录。Google 不接受调试模式登录的旧尝试已替换为普通窗口登录后后台连接；不绕过 Google 验证，不读取主 Edge 的账号资料。
- 真实网页账号自动模型回复“连接成功”。关闭测试服务，冷启动新的后台浏览器后无需登录即可发现模型并再次回复“连接成功”，证明会话和调用可复用。
- 模型列表为实际账号返回的 3.5 Flash-Lite、3.8 Flash、3.1 Pro；列表不代表保证当前额度。指定 Pro 的小请求 HTTP 200，但测试时限内无正文，保留超时且不自动换模型。未将这一项记为成功。
- 生产桥接仅 Node.js、CDP 与浏览器内 fetch，不打包 Python 或上游库。参考协议来源及实际 AGPL 许可记于 `electron/gemini-web-protocol-notice.md`。账号令牌和 Cookie 留在本机浏览器，不进入 API 配置、Git 或报告。
- 原有用户 Edge 窗口保留，验证后台浏览器清理完成。登录会话失效、额度不足、无法访问或协议变化均会报错。
