# 行舟影视 2.8.106 验收（2026-11-01）

## 功能与数据规则

- 主模型尝试次数位于主模型参数区，不再出现在备用模型卡片中。
- 每个备用视频模型独立保存 `ratio`、`videoDuration`、`videoResolution`、`videoConcurrency` 和 `attempts`。画幅、时长及分辨率选项按当前模型能力列出；分辨率变化后的时长支持范围由开工检查再次校验。
- 旧版只有模型与尝试次数的备用配置继续继承原主模型参数，不要求用户重新配置后才能运行。
- 实际视频提交读取当前策略条目的独立参数；主模型和每个备用策略条目分别限制并发，备用顺序、失败次数、资金错误停止、未知提交恢复及成功结果归档规则保持原有状态机。
- 人物音色每条生成或上传样音均有删除按钮。删除已采用样音会清除该人物的采用状态；生成结果同时删除对应生成记录，本地上传样音只解除卡片关联，不删除用户原文件。
