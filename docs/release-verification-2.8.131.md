# 2.8.131 验收（2026-11-08）

基线 2.8.130 / 6c25241。需求为页尾滚动空白、音色层级断点、同场人物简称漏配，以及两个美术导出弹窗的加载和排版问题。用户明确现有导出功能已完善，本版沿用原导出方式。

## 修改与边界

- 音色原来只由已采用样音生成 voiceCards，未采用时在提示词层完全消失。增加仅供关联的 pendingAudio 身份，UID 在样音采用前后稳定；实际编译及带音频导出仍要求可用的已采用样音。仅图片导出不被待采用样音阻断。
- 模型读取当前提示词的对白，不再用整场原文为每条找讲话依据。严格的 Dxx 现场/正常对白声明可补回漏选人物；不从入镜名单推断讲话，不复制整场音色。原有非正常对白规则和年龄歧义校验保留。
- 给模型提供当前场景的字面身份表；仅同类别、唯一准确姓名或有限角色简称能确定纠偏。原文锚点限制在基础设定范围；不能把“助理”图片锚到另一个人物的原文片段。两位助理、多套造型不强行选一个。负项“无关键手持道具”等不作为缺失素材；“无名”等姓名不按“无”字头排除。
- 原已确认结果若漏掉明确字面身份/对白，可在补齐关联时重新核对。人工卡片锁和 cardUid:null 的“确认无需参考图”锁保留；即使模型不再返回该 missing 也保留，覆盖检查同样尊重人工选择。
- 四个导出入口始终渲染，读取时只禁用按提示词入口，使用进入美术页已读取的缓存，必要时只补本地读取；实际导出仍重新预检最新来源和选定版本。标题17px、按钮13px/38px、四列等宽；关闭位于右上角，音频选项等高等宽。说明行保留空间，加载完成弹窗不变高、不移动。
- 协作原来内外层均可滚动，限定外层裁切及主区域滚动。最小项目未复现截图中的数百像素空白，因此不将其记为原场景完整复现；全样式三宽、切换模式后实测主区在可滚动时止于页尾约18px，外层滚动范围为0。内容不足视口时保留正常背景空间。
- 纯客户端；未改账号、邀请码、卡密、云数据库。只读检查用户数据，未写用户项目，也未调用真实付费模型。
