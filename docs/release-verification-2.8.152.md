# 行舟影视 2.8.152 验收记录

日期：2026-11-12
主题：导演工作台短剧节奏梯度滑轨（紧凑 / 适中 / 正常）与自动分段整场时长精准重校准

## 用户反馈与真实根因

- **用户现象**：在导演工作台开启自动分段时，原本 25～30 秒就能拍完的短剧场景（如《神明》场景 `1-1`、`1-7`、`3-4`），预计时长普遍偏长达到 34～39 秒甚至更高，导致后续段数被拆得过多；用户要求按短剧拍摄经验重新校准时长，设立三档梯度并通过一条横线滑轮（鼠标滚轮/拖动，越往左越紧凑、往右到顶为正常）丝滑调节，且界面必须结构克制、空间利用率高、无突兀按钮。
- **真实根因定位（只读核查《神明》等真实导演项目数据）**：
  1. **说话计时偏慢且句间固定损耗过高**：原 `estimateSpokenPerformance` 按 `4.5 字/秒` + 每句固定 `+0.5 秒` + 每个标点 `+0.15 秒` 计算。短剧高频短句对话（一场 10～30 句）仅固定句间损耗就虚增了 `6～18 秒`（如 `1-1` 共 113 字对白被算成 `31.51 秒`，实际短剧 5～6 字/秒仅约 `20～25 秒`）。
  2. **无 `△` 标记动作与屏幕显示被误算进对白字数**：原 `directorDialogue.js` 未识别 `画面闪回。`、`两人转身就走。`、`电话突然挂断。`、`时江晚一噎` 及 `屏幕上显示：陈修。`，导致这些纯画面文字被拼进上一句台词按语音字数计秒。
  3. **长篇视觉描写按固定秒数累加**：原 `buildEditorialSceneFacts` 对未命中正则的视觉描述统一按 `1.5 秒` 独立累加，未区分“静态环境/衣着/道具特写/屏幕画面（镜头里仅 0.2～0.5 秒一瞥）”、“转场标记（0 秒）”与“伴随台词同步发生的表情/微动作（0 额外秒数）”。
  4. **大模型规划器（LLM）自由膨胀空间过大**：原 `createSceneDurationBudget` 允许模型返回高达 `referenceSeconds * 2.2` 的秒数，模型看到长段环境描写常自行脑补慢节奏空镜，把本已偏高的参考时长再往上推高 15%～30%。

## 架构与实现

1. **三档连续短剧节奏模型（`core/directorDurationPolicy.js`、`core/directorSceneBudget.js`）**：
   - 新增 `pace`（`0～100` 连续刻度，默认 `100` 保持既有已生成计划哈希 100% 兼容）：
     - `0～33` **紧凑**（左端 `0`：中文 `6.0 字/秒`、英文 `3.1 词/秒`，句间起口 `0.18s`、标点 `0.04s`，视觉节拍缩放 `0.58x`）
     - `34～66` **适中**（中段 `50`：中文 `5.55 字/秒`、英文 `2.75 词/秒`，句间起口 `0.28s`、标点 `0.075s`，视觉节拍缩放 `0.79x`）
     - `67～100` **正常**（右端到顶 `100`：中文 `5.1 字/秒`、英文 `2.4 词/秒`，句间起口 `0.38s`、标点 `0.11s`，视觉节拍缩放 `1.0x`）
   - 视觉节拍精细分级（`classifyEditorialBeat`）：
     - 连续性/转场词（`画面定格`、`画面闪回`、`回到现在`、`一小时前`、`接上集`）→ `0 秒`；
     - 说话前单列括号神态提示 → 与对白同步重叠，`0 额外秒数`；
     - 静态陈设/衣着/道具特写/屏幕文字一瞥 → `0.20～0.50 秒`（瞬间视觉表达，绝不按字数拖长）；
     - 跨空间进出场/跑上楼/冲出 → `1.35～2.40 秒` 独立调度节拍；
   - 收紧实时 AI 规划膨胀上限（`strictModelCap: true`）：按所选节奏梯度将模型估时约束在 `referenceSeconds * (1.05 ~ 1.15)` 以内，杜绝慢放空镜注水。
2. **对话与画面边界净化（`core/directorDialogue.js`）**：
   - 将 `(屏幕|手机|电脑|监控...)上?显示：` 归入非角色字段，补充 `UNMARKED_SCENE_CUE` 与 `一噎/一怔/挽住/跟在` 等无 `△` 动作识别，不再把画面提示算作口播台词。
3. **高空间效率横线滚轮滑轨 UI（`src/v06/DirectorQuickControls.jsx`、`DirectorBatchPanel.jsx`、`src/workspace-refresh.css`）**：
   - 新增 `DirectorPaceRail`：等高（`30px`）内嵌于场景卡片顶栏右侧，与 `分段方式`、`最高时长` 同处一行（`1520px` 宽实测 `top: 49px` 完全平齐），无突兀大按钮、无冗余徽章重复。
   - 支持**鼠标悬停直接滚轮调节**（向上/向右滚往右趋向“正常”，向下/向左滚往左趋向“紧凑”）及拖动滑块，轨道内置三档暗刻度点。
   - 将原分成三行的 `原文/自动分段稿`、`本轮已完成`、`整场预计 X 秒` 合并为单行紧凑状态条：`[原文] [自动分段稿 · N 段] | 整场预计 X 秒 · 已划分/预计 N 条 · 紧凑/适中/正常节奏 | 本轮已完成`，滚动滑轮时毫秒级实时刷新预计秒数与预计条数。
   - 同步接入“一键生成整本提示词”弹窗设置、快照指纹 `directorSettingsHash` 与完成度覆盖校验 `directorPromptCoverage`。
