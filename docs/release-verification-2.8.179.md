1. 生产只读样本 17-1-1 已保存 9 个视觉素材关联，但已发布分镜的 references 为 0。媒体采用后签名变化，本应复用旧关联；旧 decisionIdentity 对对象字段顺序敏感，PostgreSQL jsonb 调整字段顺序后，旧关联证据失效，分镜静默保留空引用。

3. 另外修复未改写原文的已发布分镜无法补入后来采用素材的情况；保护手工正文、手选参考和排除项。
4. 场景清单已发布并不证明逐条关联和媒体就绪。新增全剧、场景、逐条统一状态，区分已关联/已发布/分镜就绪/失败，支持过滤和精确跳转；队列显示实际阶段和顺序；分镜提示未就绪原因及返回入口。
5. 一键“无需参考图”仅豁免缺项。有画面且场景有视觉素材、却未分配任何视觉卡片的结果不能通过核实；逐一明确排除实际场景卡片及真正无画面场景保留。
6. 关联保存旧返回整个多 MB 快照，序列保存队列被放大。新增短回执、按 revision 条件读取关联上下文；每次仍实时核验权限/锁定/账号，清单依据以当前正文哈希校验。保存回执不确定时只读核对原 writeId，不重复写入或模型请求。旧客户端完整返回兼容。
