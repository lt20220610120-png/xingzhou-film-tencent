# 2.8.186 验收

2026-11-19。选择器、分镜参考列表与可选引用仅展示已有采用图的资产卡。缺图时保留已存卡片关联及作者原始编号，提交按实际有效图片去掉空引用并重排发送到接口的编号。单张和批量都在主进程读取卡片最新状态，采用照片或换照片后无需重建引用。

- Electron 以旧分镜引用回放采用图、切换采用图、清空与重新采用。即使选图前项目资料仍旧，实际图片接口返回空位后也会刷新列表。素材选择和分镜由四张变三张，确认选择仍保留潜伏的卡片关联。模拟 LibTV 收到四次提交、十五次上传及对应图像字节，缺图的一次只上传三张，提示词下发编号匹配实际图片，人工原文保留。零付费请求。
- 只在卡片确无采用图时跳过。权限错误和本机已采用但文件未保存的错误正常返回。兼容英文与中文图片编号，且视频任务复用沿用原始资产位和原始提示词。服务端采用图接口沿用 2.8.185。
