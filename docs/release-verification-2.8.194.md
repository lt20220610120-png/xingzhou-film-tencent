# 2.8.194 COS 流量与 Windows 交付验证

## 账单与读取链路

- 腾讯云费用中心按行舟正在使用的广州存储桶核对：2026 年 10 月外网下行 3.04436248 GB，11 月 1–22 日 8.06772810 GB。10 月、11 月的 COS 预付账单各查到一笔 167.50 元外网下行流量包。流量包购买金额和本桶当期实际用量分别由两种接口核实。生产 Bucket Logging 查询成功并显示停用，网关日志只统计网关回包，历史外网下行无法按客户端、平台、对象分别排名。
- 2.8.193 的图片链路已对续签 URL 复用原图，但 512 MiB 上限、30 天过期、取消信号直接绕开缓存、上传 PUT 未回填、项目音频与播放器直读都可能再次从 COS 下载。服务器缩略图已有内网来源，但本机刚上传后的缩略图没有优先取本机原图。
- LibTV、Like、飞拓文件模式、自定义 multipart 等由客户端读取引用，现可命中同一账号的原始字节缓存。要求公网 URL 的 9Y、AutoDL、飞拓地址模式及使用公开地址的通用视频适配器会由接收方拉取，已有本机原图时使用临时瘦身副本。首次异机冷读取、可视细节不能压缩、音频/视频公网引用、较大或繁忙时的直连、用户手动共享成片后的跨机取回仍可能产生外网下行。
- 24 GiB 原图与项目音频 LRU，最近使用时间 90 天，单件 64 MiB。缩略图 512 MiB。COS 对象完整字节才进入缓存，权限签发及账号隔离在读缓存前生效。冷缓存音频保留 HEAD 与 Range，直接传输完整且不超过 16 MiB 时顺手缓存。
- 仅对经过认证的合法项目图片和音频 GET 链接尝试中转。TLS 连接固定为存储桶域名且要求同地域私网解析。192 KiB 上限、一个并发、客户端 1.7 秒等待、全局持续出站速率低于 48 KiB/s 的平均原始载荷。忙、大、超时或异常回原 COS 读取。轻量服务器套餐仍需与其他业务共用；机器规格按用户提供的 3 Mbps/200 GiB。
- 临时参考图的 JPEG 质量 89，长边通常上限 2304 像素，首尾帧 2560。低于 256 KiB、含透明通道、动画、明显压缩收益不足的素材保留原提交行为。正式项目对象和源文件从未转码或覆盖。
- 上线后 3–7 天可按天对比广州存储桶的外网下行以及轻量机套餐用量。用相近的参考图和视频任务量比较工作日。在费用中心核对流量包抵扣和剩余量；客户端 startup.log 的 cos_media_traffic 记录本机命中、上传写入、部分直连与中转的请求和字节汇总，不含地址或账号信息。预付账单不会随日用量下降自动返还。
