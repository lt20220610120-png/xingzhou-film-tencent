- 待发布基线为 2.8.194，源代码基线 2761621。测试输入使用隔离资料、合成素材与模拟上游。正常运行环境的项目和当前本机登录记录均保持原样。

- Electron 导演页连续模拟上传两部新剧本。首次选最后的既有自定义 Skill，添加一个自定义 Skill 后第二次自动选中更新项，两份既有绑定保持一致。EP1/EP2 被分为两集。

- 源码清洁环境的受保护 Skill 默认执行器通过模拟 HTTP 请求验证，无私有正文或凭据进入客户端。发布 CLI 对已上线的 2.8.194 默认拒绝原版本覆盖，检查三份清单后退出。
