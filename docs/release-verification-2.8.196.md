# 2.8.196 第三波验收

## 控件和交互

- 以 2.8.195（8f9d8f8）为基线。主界面盘点 177 处下拉定义和 50 处原生提示或确认。主窗口与独立画布共用控件样式，当前浅色背景仍为 RGB 247/249/252。下拉沿用表单原语，选择面板由 Chromium 顶层渲染。
- 隔离 Electron 以 1280、1600 和 1920 CSS 像素验证创作、导演、协作清单、资产、分镜、音色、图视生成、API、设置和管理后台。60 项下拉从裁切容器的右下边缘向上展开，滚轮、键盘跳过禁用项、回车选择、Esc 和外部点击通过。API 弹窗内 Esc 先收起下拉，切页收起弹层。图视生成的图片标签和中文草稿可切页返回。
- 异步确认焦点先落在取消。验证 Esc 恢复原焦点，授权变动离开工作台时撤销正在等待的确认。公开网络请求观察中境外字体请求为零。

## 性能和既有能力

- 协作页切走后 12.5 秒内项目详情新增读取为零。专项 Electron 验证隐藏路由和隐藏窗口停轮询、慢请求无重叠、编辑不重启定时器及闲置美术核实无 500ms 刷新。已获授权的后台任务继续运行。
- 140 条图片历史首批渲染 48 条，按需显示后续。90 集隔离长稿实测单字保存、相邻编辑器保持挂载、编辑后立即保存整稿。制作流输出与导演进度通过局部订阅更新。普通审校回包每集最多近期 24 条，人工编辑和冲突恢复仍保留。
- 模拟多段内容审核，第一段只送审一次。登录态连读 101 次只解密一次，11 个成组鉴权请求合并成一次远端校验，八个并发存在性检查共用一次本机数据读取。续期、退出和切号均有隔离测试。
- 本机 256 MiB 合成文件由同步哈希改为流式 SHA-256，最大定时器间隔 150→17 ms，哈希相同。8 MiB 文件经真实 Electron 网络栈上传至本机模拟接收端，逐字节校验一致。视频导出并发与 Windows 无硬链接的原子移动通过。回收重复图片前核对字节，保留损坏文件的恢复记录。
- 套件共 3307 项 Node 与 12 项 Python 通过，Vite 构建通过。NSIS 提取的桌面程序启动成功，COS 原图回填、音频 Range 和缓存、参考图瘦身、内网中转回退、画布、Win AI 与管理授权边界通过。Like 扩展与私有 Skill 正文隔离通过包内检测，服务端程序和数据库没有部署改动。所有生成请求均使用隔离模拟。
