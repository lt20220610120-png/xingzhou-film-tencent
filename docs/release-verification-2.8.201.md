# 2.8.201 发布验收

2026-11-23，基线为 2.8.200 和 `4c62a68`。

## 根因与改动

- 旧版「直连」仍经过应用内 CONNECT 隧道。隧道用 HTTP 502 表示到目标建连失败，连接器再把 502 当成代理网关响应。新版强制直连直接连接目标，清除当前 LibTV 连接器进程的继承代理环境。其他模式保留受限隧道，按请求及目标记录真实故障来源，区分目标连接失败、外部代理 CONNECT 502 与官方服务 HTTP 502。
- 分镜、图视工作台和提示词工坊共用按授权、空间和网络设置隔离的 LibTV 读取。账号核验短期复用，重叠请求合并。静默刷新保留最近成功的配置，交互失败展示清理过的中文提示。设置页连接测试每次读取即时状态，可复制脱敏诊断。
- 参考素材准备跨任务共用两条上传通道，保持原素材引用顺序，首个错误会中止同批任务并清理临时文件。操作区实时显示核验、上传计数和创建任务，进入付费运行边界后关闭准备取消入口。付费运行单次提交，批量失败原因与画布手动生成继续保留。

## 隔离验收

- Windows 本机测试验证直连建连超时和重置、官方 HTTP 502、系统及自定义代理真实 CONNECT 502，覆盖 HTTP 与 SOCKS5。诊断保留故障阶段，复制内容不含代理地址、账号、Cookie 或密钥。
- 分镜在 1280、1600、1920px 验证。重复切窗口和重新进入后，项目与模型参数各读一次。静默失败仍保留上次可用配置。六图两音频显示上传进度，可取消。前置失败新增结果卡片 0 张，旧历史卡片保留，模拟已提交后失败可正常追踪。测试场景的模拟付费提交为 1 次。
- 本机模拟每次上传增加 80ms 延迟，比较同样八个素材。2.8.200 耗时 766ms，峰值 1 路。2.8.201 耗时 394ms，峰值 2 路。额外测试验证两条生成同时准备时仍共用这两路。公司网络的实际耗时待现场使用观察。
- 全量 3,273 项 Node、13 项发布 Python、12 项本地 Qwen 测试，以及 Vite 构建通过。真实付费调用为 0，使用隔离账号与项目夹具。
