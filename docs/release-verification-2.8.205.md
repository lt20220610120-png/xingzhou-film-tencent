# 2.8.205 发布验收

2026-11-25，基线为 2.8.204 与 `b0b6b2e`。

## 本轮改动

- 模型提供发声原文、读法语速、声画关系、有效动作和气口等语义。程序统一以十进制计算发声、组内并行、串行动作、尾缓冲、自然整数秒和 15/30 秒容量。
- 首轮有效估时先持久化，可识别的失败项各补试一次。请求超时、HTTP 错误、空正文、乱码和缺片段分别记录。取消、切换账号或版本、补试前编辑原文会阻止后续请求。DeepSeek 估时使用模型自身思考设置。
- 自动分段超载保留首稿。当前工作区有生成记录的自动场景可确认重分，重分成功写入后才替换当前稿。人工切点保持原样。整本结果提供超载汇总和定位。
- 三份内置 Skill 文档与原始 ZIP 逐字节一致。内置文件容器 SHA-256 为 `b7bf53a7feccbd3e5385d922e0634a83d2f46d5e00deb0d97cb4eee5357af97e`。
- 主窗及独立画布共用单行省略触发框、全称悬停提示与自适应下拉。保留原生键盘交互及多选列表语义。导演估时操作移至标题右端，显示进度、汇总与取消入口。

## 验证

- 相同语义的多种模拟回包得到完全相同的时长分项和容量结论。覆盖句式、读法、长文本阅读、并行、十进制与 15/18/30/35 秒边界。
- 1280、1600、1920 像素隔离 Electron 验证了导演模型、估时模型、协作分析模型、分镜集数的单行和全称。独立画布、边缘弹层、Esc、键盘选择和现有工作台交互通过。
- 导演真实 Electron 用三条提示词验证两条先保存、其余一条仅补试一次，气泡显示漏片段原因。逐条估时显示进度、成功汇总和取消结果。遇到自然 36 秒的超载稿，只有显式确认才发起第二轮模拟生成。首次保存失败及保存期间并发修改有独立回归。
- 对照客户端和现役云端估时校验的 46 组边界结果一致。历史估时仍可读，云端服务及数据库无需部署。真实文本与视频付费调用均为 0，模型结果的收敛验证使用模拟语义。
- 全量 3,353 项 Node、13 项发布测试和 12 项本地 Qwen 测试通过，Vite 构建通过。Windows 全量测试采用三工作进程运行，避免已知的高并行夹具清理抖动。
