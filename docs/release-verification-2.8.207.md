# 2.8.207 急修验收

2026-11-25，基线为 2.8.206 与 `a4f37b2`。

## 修复范围

- 全局样式清零默认外边距，使共用原生对话框贴到视口左上角。共用样式显式按当前视口居中，保留半透明遮罩及长内容滚动。
- 资产删图原来只发送图片 ID，本机服务按资产 ID 查找卡片，缺参后拒绝操作。确认操作现在同时携带项目、资产和图片 ID。成功后更新缩略图、主预览、采用状态和项目缓存，再刷新权威数据。删除和删除后的刷新异常分别提示。
- 本机服务校验图片归属，保留独立的旧版 URL 采用图。删除当前采用图时切换为最新余图，没有余图时回到无图状态。美术页原有清空操作只处理图片记录，保留音频等素材。可被其他流程引用的文件按原存储策略保留。
- 云端继续使用原 API 和权限校验。发布范围为桌面端，云端业务服务及数据库无需部署或迁移。

## 验证方式

- 使用隔离 Electron 和临时资料目录。云协作经实际网关路由和模拟仓储验证，资产捆绑、授权拒绝及网络失败均使用测试数据。
- 按三档窗口宽度验证选中、取消按钮与 Esc、删除非采用图和采用图、刷新失败仍保留删除结果、删完回空态、刷新重开不复活、其他卡片图片保留。共用弹窗另覆盖长内容窄窗、遮罩和独立退出登录弹窗。
- 未使用真实用户项目数据。本轮真实付费调用为 0。
