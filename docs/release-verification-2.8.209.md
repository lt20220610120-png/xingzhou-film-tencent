# 2.8.209 分镜与推荐时长验收

2026-11-26。基线 2.8.208，提交 `291387e`。

## 修复范围

- 分镜按来源提示词 ID 和原始正文提取当前导演估时。旧分镜的待复核或待估时在同源且正文仍匹配时可更新；已手动改稿的分镜继续校验，单条重估结果按时间和正文匹配保留。
- 客户端与云端按同一规则识别素材引用变化。编译、重编号、移除和恢复保留估时，真实对白与画面修改继续标为待复核。引号内的文字按正文比较。
- 批量应用跳过真正未保存的正文和手调秒数。其他分镜应用所选参数和模型合法档位，结果列出跳过项。批量队列继续检查权限、已保存内容、发布版本和模型时长。仅有效条目加入发送，异常项留有可读原因。
- 分镜标题旁的素材叹号支持鼠标、键盘和点击，可查看完整原因与素材数量并定位到清单核实中的对应分镜。

- 以上六组在当前场景、当前集与全剧逐步应用 1、2、3 条。真实主进程队列以模拟服务发送三条合格分镜，执行时长 25、15、15 秒，未保存分镜和待估项明确跳过。
- 三档 Electron 验证了叹号显示条件、全部原因、白底浮层、鼠标移入以及 Tab、Enter、Esc。点击文字在真实工作台定位到了对应清单条目。另验证历史 2.0.0/3.0.0、手调保护、显式重置、定长和连续时长模型。
