## 监控面板接入

在有服务器运维权限的 Windows 终端中用现有主机密钥和 SSH 身份打开本机转发。终端保持打开时可访问 [GlitchTip](http://127.0.0.1:4330/)。

```powershell
ssh -N -L 127.0.0.1:4330:127.0.0.1:4330 -i "$env:USERPROFILE/.ssh/xingzhou_tencent_test" -o "UserKnownHostsFile=$env:USERPROFILE/.ssh/known_hosts_xingzhou" -o StrictHostKeyChecking=yes ubuntu@106.55.41.128
```

使用提交的告警邮箱登录。首次登录凭据保存在服务器 root 专用文件 `/opt/xingzhou-runtime-monitor/operator-login`。验证事件位于「发版隔离验证」，业务事件位于「行舟影视运行故障」。
