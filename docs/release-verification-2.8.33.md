# 2.8.33 9Y 本地参考素材修复验收

日期：2026-10-12。基线为2.8.32，用户截图为sd-2.5-v2、4张本地参考图片与2段不支持的音频；图片因无公网URL在提交前被拒绝，错误却被标记为提交未确认。

## 实现范围

生成前校验 → 登录态临时素材签名 → COS直传选中本地文件 → 9Y官方视频JSON → 原任务查询/下载。本机原始参考和生成任务保留原路径，不把临时签名链接、行舟会话令牌或9Y密钥写入任务文件。已有HTTPS参考直接复用；不上传整本剧本、隐藏素材或协作项目全量数据。

服务端新增独立临时对象前缀`temporary/generation/<账户摘要>/`与持久化清理记录，不建立业务项目或修改数据库。上传签名绑定内容类型和字节数；图片20MB、音频15MB、视频100MB，单账户100个/1GiB、全服务2000个/8GiB。链接48小时，启动及每小时清理到期对象，失败删除保留记录重试；不清`projects/`业务素材。

普通COS下载/上传签名仍限定15分钟，只有受限临时前缀使用48小时下载签名。临时上传只在用户点生成时执行；准备阶段失败标记failed/submissionAttempted=false，真正生成POST结果不明仍标记uncertain且不会自动重复提交。

按[9Y官方文档](https://9yapi.shop/docs/#videos)核对：sd-2.5-v2使用resolution/aspect_ratio及图片URL；`@imageN`转换`@图片N`；官转Wan用size而非resolution，视频输入总时长≤15秒且输入+生成≤30秒；特惠Wan不要求官转duration对象。读取官网文档与官网静态前端代码，无读取账号凭据或调用付费任务。
