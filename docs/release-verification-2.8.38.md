## 原因与修复

- 云端旧资产同名不同类别会抛错并回滚整集。现在以本次人工核实分类纠正旧分类，保留资产ID、图片、提示词和其他集关联，记录纠正来源。同次名单分类矛盾保留提醒并继续建立其他资产；权限、源稿有效性和并发版本检查保持生效。
- 原始AI信息卡存在首次人物只有服化道的问题；旧ready标记掩盖缺漏。现在补齐判定检查人物基准外貌，先复用前集同名完整信息卡；人工提示词保留，可显式采用已补齐卡。分类修正后的逐场关联按项目唯一名称投影，旧道具启发式不再覆盖已核实类别。
- 参考入口始终显示，可选择项目图片或导入本机图片。人物换装、场景时段变体使用基准参考，单张与批量一致；用户可明确选择不引用。原任务恢复路径继续查询原结果。
- 真实图生图诊断发现LibTV上传成功而创建节点仍用text2image，官方拒绝参考连线；现带图任务正确发送image2image。非人形角色不套人形五格构图。
