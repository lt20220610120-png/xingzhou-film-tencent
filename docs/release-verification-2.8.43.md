# 2.8.43 验收记录

日期：2026-10-17。基线81d5973（2.8.42），分支codex/art-analysis-recovery-creatures-2.8.43。保留原未跟踪docs/security-rating-2.8.4.md与output/。未修改真实项目原稿、媒体或API配置，无真实付费生成。

## 原因与实现

- 旧的信息读取依赖用户手填genre；逐集runner每轮只尝试一次，缺映射、漏描述或接口错误即break。界面将其显示为暂停，重新点一次才能继续。
- 新增artScriptContext：全文与独立分集/设定补齐去重，按22000字符分段提取并最终汇总背景、时代地域、族群、故事风格；来源指纹及每段观察存入按账号/项目ID隔离的美术账本。不依据姓名推定族群，缺失/推断保留待核对。缓存来源改变则重读；中断从已保存分段继续。结果通过既有genre云字段同步，失败时保留本地并写分析说明，不绕过现有权限。
- 自动背景数据通过user JSON和untrustedData.artPremise传给清单/描述模型，不将模型摘要插入system指令。画风、人物构图、分析模型和工作方式仍由用户选择；背景结果只读展示，内置规则名称隐藏。
- 新增artContinuousAnalysis协调器，复用单轮runner和原有CAS/人工核实逻辑，在同一未完成集反复补缺，不跳过失败集；多次不全时缩为单卡请求。逐步退避2–60秒，运行中可停止且等待可立即唤醒；进度与修复说明落盘。指导模式和显式单集/卡片维护保持单轮，不增加隐式全剧付费重跑。
- 可解析但ok:false的清单仍是中断，不能凭已解析部分标完成；中断inventory重新读本集，映射错误保留名单重做对应。失败详情回包保留文字并重校机器卡，失败visible:false不生效，人工编辑和核实不被后台重试覆盖。本地检查点失败退出并保留错误，不继续消耗API。
- 新增creature构图与主体识别，非人描述不再被“必须含人类五官服装字段”的校验错误排除，也不因外观/材质/尺寸字段被误归道具。规则要求清单标记主体类型/物种，区分动物、人形兽人、携宠物人类和动物雕像。
- 生物前置独立于四/五格人像：白底完整正/侧/背三视图，无人物场景，保持物种解剖，不添加物种没有的肢体。旧自动四格/五格生物卡自动迁移，显式custom与自由前置逐字保留；引用生物时不再附加“同一人物/脸型五官”要求。
- 快速全集发布根因已用实际云端项目只读审计确认：40集的前端编号检查全部通过；后端把第30集的正常英文台词“Activate the Dissolution circle.”误当Act结构标题（紧接的i被当作罗马数字I），导致该集episodeNumber=0。每次核实保存都会校验全项目，故40集均被拒绝，尚未执行资产发布。不是快速核实导致模型乱序。修正英文完整词/数字边界，同号中英标签可作为同一集证据；unitHeaders保持原始数量，分析输出的重复块及异号/混排/真实重复记录仍拒绝。保留既有单章、单回、单幕标题兼容。
- 提取approveAllArtReviews/publishAllArtReviews：已读取场景即使描述未完整也能确认并发布占位资产；整集确认同时记录未关联名单决定，未读取空场景不误核实。项目级编号/权限/锁/本地检查点失败停止后续重复请求，已核实清单保留、可修复后原位重试；独立单集冲突不阻止其他有效集。旧40条相同同步错误合并为紧凑提示，完整错误仍在本地账本保留。
