## 原因与实现

- 原资产页仅有选择未生成的批量行为，浏览列表仍含所有已出图卡片。增加onlyMissing视图，复用既有assetHasImages口径（images数组或旧image_url均算有图），过滤单个妆造后再分组；左定位、妆造切换与内容均从displayAssets构造。点击可恢复全量，搜索继续保留既有不改变批量范围的语义。
- selectedIds与displayAssets求交后才进入批量计划。筛选不会抹掉用户原勾选，但隐藏已生成图不参与未生成视图的付费任务。批量运行时锁定切换，成功刷新后自动移出，失败和未开始继续可见；0项显示全部已生成。全量资产继续用于参考依赖，不因筛选丢失已有基准图。
- 创造模式旧runCreativeScene明确只构造“项目前置+导演构想”，未传左侧整场；Skill执行层本来已完整发送选中Skill及附件，无需另建Agent或替换Skill规则。
- 新增buildCreativeSceneSubmission：保留完整整场原文和导演构想，分清拍什么/怎么拍，添加项目风格画幅前置后交给原executeSkillWithAi。创造模式左侧及提交统一读取原始scene.content，绕开quickSceneEdits局部修改（快速模式编辑保留）；无场次或构想/所选模型时禁止无效提交。保留整场、构想及Skill来源字段；无输出时抛错，不记录空结果。
- 回调仍按捕获的project/episode/scene提交，并在setState最新状态基础追加至分集与历史，切场景和并发不会相互覆盖。没有修改快速模式生成器或其他历史结果。
