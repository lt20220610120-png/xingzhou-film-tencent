## 范围与实现

- 用户要求资产“只看未生成”提供批量取回原图、批量放弃旧结果和未恢复名单；本机参考图按钮收紧。沿用人物/场景/道具分类、项目权限、原结果恢复流程与原并发池，未调整上游生成协议。
- 工具栏只在“只看未生成”且非未关联历史资产视图出现；按当前分类和搜索匹配的未生成资产处理，人物含匹配妆造，与复选框生成选择无关。明确显示范围/数量，不能操作其他分类、项目或已生成图片；无旧记录自动跳过，进行中项目跳过。
- core/assetImageRecoveryBatch按asset ID去重，使用runArtImageBatch有限并发与停止机制，单项失败继续其他项目；成功挂载后清恢复绑定，挂载失败保留本机filePath以便继续保存。结果摘要含成功、失败、跳过、未开始数量，失败名单含资产名和原因并单独滚动。
- requestAssetImage新增recoveryOnly，在缺少旧结果时明确拒绝，不允许恢复入口退化成mediaGenerateImage。批量恢复始终开启；单卡恢复从点击时保留该意图，并贯穿提示词保存await到美术/资产两个回调及直接分支。
- 批量放弃先原生确认数量、分类/搜索范围、上游不取消与后续手动生成可能收费；仅解除当前范围内闲置未出图资产恢复绑定，不删除已保存图片、不调用生成接口。用户可另行使用原批量生成按钮新建任务。
- 共享“本机参考图”改Upload图标+短标签，跨控制网格整行但按钮自身仅98×30px，保持选择/取消和原参考关系行为。
