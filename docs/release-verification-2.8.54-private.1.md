# 2.8.54-private.1 本机试用验收

日期：2026-10-20。基于 `125778d` / 2.8.53，按本轮明确授权实现“提示词联动美术”，继续遵守先本机体验的范围。

## 实现与适配

- 复用导演到协作的只读提示词同步、现有逐场美术核实及发布、现有资产图片和整本图视生成。新增可选模式，默认保持原按场景整理；不改写已有导演提示词。
- `core/promptArtBinding.js` 建立提示词原文位置、类别、稳定卡片 uid、正式资产和具体图片的关系。支持基础信息/基础设定、顿号和按已知卡片补全的逗号多人列表；类别严格匹配，歧义保留，不自动挂所有同名图。
- 清单核实中的面板提供逐条规则匹配、AI 复核、人工选择、仅声音/提及/本条不用、选图、来源更新提醒及确认。AI 结果需要逐字原文位置、有效类别与本场卡片，保留人工锁定，首次失败后最多修正两轮。
- `electron/prompt-art-store.cjs` 在本机资料目录持久保存，按账号及项目隔离，写入检查 revision；出图前也能保存用途。当前实现不支持多机共享用途记录。
- 整本模式直接载入已确认图片，未就绪条目保留为 pending；当前条目可独立生成。按实际图序编译引用，关闭旧模糊追加；改词、删图、不支持必需图的模型都会阻止提交。
- 前端及主进程提交前重新读取当前来源和资产；主进程使用重新核实的图片元数据，不依赖前端残留 URL。云端核实有更新版本时使用较新记录检查，已提交任务仍保留原快照。
- 本机试用包用 package 元数据启用完整能力；普通包关闭。打包显式要求私人标记，发布脚本拒绝私人版本。

## 使用与边界

入口：项目协作 → 清单核实 → 提示词联动美术 → 选择新模式；使用原有模型选择器选文本模型，核对、确认每条用途，图片就绪后选图并重新确认；图视生成 → 整本提示词与素材 → 从联动美术项目载入。

本次仅直接项目载入贯通用途身份；旧的纯文本/图片文件夹导出导入仍使用原模式，机器可读 manifest 交换另行建设。本次未实现完整 Codex Agent 接入、批量自动提交/下载、Topaz 或剪辑。

没有实际调用付费 AI、图片或视频接口，没有修改真实用户项目或强制关闭其当前软件。真实模型的语义效果须用用户场景继续评估，不能以模拟 API 验收宣称零错绑。私人包仅在本机交付，未上传公开仓库发布资产，未更改公共更新清单。
