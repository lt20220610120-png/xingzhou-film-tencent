## 实现

- core/artModelQueue.js 按同一api实例共享请求池，总计最多6个实际模型调用，自动最多5个，人工优先使用剩余额度。背景通读、读集、场景、细节及提示词均经该池；等待队列不计为实际并发。页面展示实际请求数与排队数。
- artAnalysisPipeline的项目/账号下游controller拥有独立job/任务ID/取消域。显式信息读取启动它并提交新完成的集清单；停止信息读取只取消读集，已完成上游仍继续下游。页面挂载只订阅，不调用模型。
- 清单分发有独立开始/停止按钮。开始扫描当前已有有效清单，只调用模型完成场景与提示词未完成分发；停止禁止排队与迟到保存。同集维护请求按序执行，普通自动重复仍复用；按最终ledger变化回填后文信息，再触发真正变化场景，不重付已完成分发。
- 发布门禁保持按版本与场/集范围，不依赖全剧job状态；完整第一集可在后续集尚未完成或停止时核实发布。真实缺项、空提示词、未完成仍阻止该范围，并显示具体原因。
- 提示词header为同一水平线，保留字号，空间不足在header内部横向查看，禁止换行撑高页面。
