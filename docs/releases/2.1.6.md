# 行舟影视 2.1.6

## 本次更新

- 手动添加资产：标题关闭按钮与底部操作栏固定，仅表单和集数列表滚动。支持选择全部集数、清空选择；从美术页添加时预选当前集，从角色总览添加妆造时预填角色名。
- 美术工作区：每项资产的身份信息、提示词和图片生成同时展开为连续工作行。可搜索资产，保留跨人物、场景、道具的批量生成及单项下载、上传和删除图片。
- 资产总览：按角色归组，直接展开全部妆造的编辑与生成区域；场景、道具同样逐项展示。窄窗口自动调整列宽与排列。
- 视觉：统一暖白工作面、深墨绿导航、细边框、表单和按钮；身份页加入剧本稿纸和镜头序列预览，并保留登录、身份解锁和切换流程。
- 行舟 AI：恢复固定尺寸圆形浮动按钮；可在主导航右侧的整个内容区域自由拖动。记住位置，缩窗后自动移回可见区域，拖动不会触发打开聊天。
- 生图前置：各资产可查看、编辑、清空或恢复默认前置。人物可选单人多视图、多人群像、自由构图；既有“城中百姓”等群像自动使用多人构图，明确人数优先。单张与批量生成均读取最新前置及描述，“查看实际生图提示词”可检查发送内容。
- 前置与描述一起通过原有资产描述字段保存到云端，不需要数据库升级。AI 修改描述时保留用户设置的前置；保存失败会保留草稿并阻止该次生成，重试成功清除错误提示。
- 修正打包依赖收集：在实体暂存目录收集完整运行依赖，避免开发目录的 node_modules 联接导致漏包。

## 使用与构建

Windows 安装包位于 `release/2.1.6/Xingzhou-Film-Tencent-Setup-2.1.6.exe`。本次生成本地安装包，未更新线上发布清单。

使用 `npm run dist` 运行源码测试、构建、打包与启动验证。打包会在 `release/staging-*` 创建实体依赖副本，不修改开发依赖联接目标。现有本地 Electron runtime 可通过 `XINGZHOU_ELECTRON_DIST` 指定；未指定时优先使用 `qa/electron-runtime`，否则由 electron-builder 获取匹配版本。

`XINGZHOU_SMOKE_TEST_ROOT` 仅用于显式启动验收：将 appData、userData、documents 和 temp 指向隔离目录，禁用网络，验证后自动退出；正常启动无需设置此变量。
