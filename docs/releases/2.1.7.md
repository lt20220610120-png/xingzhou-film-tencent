# 行舟影视 2.1.7

- 全新浅色界面：淡紫品牌侧栏、淡青工作区与蓝色操作按钮，正文略微放大、文字加深，身份选择页加入剧本和镜头预览。
- 资产总览新增左侧快速定位目录，人物、场景、道具均可点击定位。每个人物只占一个编辑区，在框内选择不同服装，默认展示第一套；切换服装保留各自的未保存草稿。
- 美术页面新增本集顶部快速定位，人物按角色汇总并显示妆造数量，点击定位第一套妆造。所有本集编辑区继续展开，场景和道具也可快速定位。
- 美术与资产生图不再自动添加项目题材；画风、资产描述、自定义前置和参考设置继续生效。题材设置仍用于信息读取中的剧本分析。
- 生图前置支持查看、编辑、清空与恢复默认。群像与单人多视图分开处理；“城中百姓”等群像默认多人同框，避免套用单人四格。单张、批量生成与实际提示词预览使用一致的组合规则。
- 手动添加资产窗口固定标题、关闭按钮和底部操作栏，集数再多也能直接操作。
- 行舟 AI 恢复圆形浮动按钮，可在主导航右侧自由拖动，并在缩窗时保持可见。
- 完整收集桌面运行依赖，并增加安装包启动、界面和 DOCX 解析验证。

验证：466 项源码测试通过，生产构建成功；隔离桌面验收覆盖导航、妆造草稿隔离、单张与批量提示词、保存失败重试、70 集固定操作栏及多种窗口宽度。安装包通过运行依赖与实际启动验证。图片生成流程使用模拟接口验收，未消耗真实模型额度。

更新方式：在软件「设置」中检查更新，下载并运行新版本安装包。已有项目与原有本地资料路径继续沿用。
