# 行舟影视 2.2.0

本次更新打通导演提示词、项目分镜、参考素材和视频生成流程。

- 图视生成采用提示词编辑、模型参数、生成结果三区布局；支持预览、下载、复用和任务状态刷新。
- 接入飞拓当前文档的 24 个视频模型与 8 个图片模型。API 设置中选择飞拓，填写 Key 即可建立图片与视频接口；时长、比例、分辨率和素材数量按模型联动，支持对应模型的 30 秒视频。
- 图片、音频、视频按顺序绑定 @image、@audio、@video 引用；提交前检查素材种类、数量、引用编号和模型限制。官方通道的参考素材需使用公开链接，可先上传到项目素材库。
- 项目分镜支持持续新增，按集、场景、提示词保留稳定编号；提供角色、物品、场景、参考图、音频、视频分类选择及本地上传。
- 导演提示词自动对应分镜，生成参数和参考素材可保存，生成完成后归入项目视频结果。
- 保留刷新云端数据；合并不同位置的协作修改，同一内容发生冲突时保留本地编辑并提示核对。刷新不会清空手工分镜、已保存参数和视频结果。
- 修复项目图片链接解析与结果刷新，增加手动图片刷新；视频任务保存到本地，重新打开软件后继续查询已提交的任务。

使用：进入“API 接口”或图视生成的“接口设置”，选择飞拓并填写自己的 API Key。生成仍使用该 Key 对应的账户额度。

验证：488 项自动化检查通过；真实 PostgreSQL 临时表验证并发创建、冲突保护和导演同步；桌面界面验证模型选择、30 秒参数、连续创建分镜和实际请求中的素材绑定；安装包启动、桥接和文档导入验收通过。生成请求使用模拟接口验证，未使用用户额度执行付费生成。
