# 行舟影视 2.2.1

修复 2.2.0 的接口设置与旧项目分镜问题，精简协作工作台操作。

- 修复图视生成中“添加接口”无反应。飞拓设置改为填写一次 API Key 并保存启用，图片、视频所有已接入模型直接共用，切换模型无需重填；兼容旧接口配置与未完成任务的凭证读取。
- 修复旧项目没有集数 ID、数字 ID、重复 ID 时，创建分镜失败、切集返回列表或总进入第一集的问题。支持第 15、70 集等任意分集和场景独立连续创建。
- 兼容导演来源与早期协作副本的集数标识差异，刷新沿用已有分镜及草稿，避免重复分集。
- 移除分镜与分集列表顶部重复的刷新、关联导演项目入口，沿用创建协作时的项目关联，只保留左下角“刷新云端数据”。返回分集按钮放在集数、场景选择上方，统一视觉样式。
- 图视生成参考图片、音频、视频支持文件窗口多选后批量导入，按导入顺序编号；超出模型素材数量时明确提示。

验证：501 项自动化检查；70 集无 ID／混合 ID 的桌面交互验收；单 Key 切换 24 个视频与 8 个图片模型的模拟请求；真实 PostgreSQL 临时表并发与同步验收；安装包启动与运行依赖检查。未使用用户额度进行付费生成。
