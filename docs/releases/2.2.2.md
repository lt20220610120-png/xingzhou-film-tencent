# 行舟影视 2.2.2

优化分镜创建与云端连接，新增确认删除，更新内置剧本美术清单。

- 创建、保存分镜后直接显示服务器返回的内容，不再等待整个项目和素材重新加载；减少重复刷新及旧项目同步时的重复计算。
- 云端请求增加超时控制，读取和可安全重试的分镜操作自动重试并使用已有备用连接；异常时保留当前内容，项目列表提供“重新连接”。分镜重试沿用同一个标识，避免一次操作重复创建。
- 分镜新增“删除分镜”及二次确认；协作者已修改的内容会阻止过期删除。删除后刷新不会重新导入该分镜，保留导演原提示词及生成媒体，新增分镜沿用递增编号。
- 每个场景只在末尾保留一个固定高度的“创建分镜”按钮，空场景与已有提示词的场景保持一致。
- 内置剧本美术清单升级至提供的 art-asset-list-v4，完整包含主文件及九份参考文档；适配分层服装、复用条目、仅提及人物及空类别，兼容原有按集分析、资产读取与生成流程。

验证：507 项自动化检查；真实 PostgreSQL 临时表并发、删除与同步验收；桌面慢刷新、连续创建、确认删除及末尾按钮验收；安装包启动和运行依赖检查。未使用用户额度进行付费生成；网络完全中断时仍需恢复连接后重试。
