## 2.2.3

### 可靠的剧本美术分析

- 分集、分段保存分析结果，分析中断或云端同步失败时可以继续，已完成的请求不会重复计费。
- 每个分段使用受控上下文和输出预算，保留原始响应，截断或解析失败时可以定位并继续处理。
- 云端资产改为增量合并，保留既有图片、资产编号和人工编辑内容；并发编辑遇到版本冲突时拒绝覆盖并提示刷新。
- 内置剧本美术清单 v4 增加运行时提取规范，同时兼容旧版清单和已有资产。

### 多模型与账号资料

- 图片、视频、导演分析和行舟 AI 会话都按窗口保存模型和接口选择；不同窗口可以并行调用不同接口，不再共享一个全局默认接口。
- API 接口库中保存的接口都可以在具体窗口中直接选择使用，模型选择会同步到对应接口和凭据。
- 侧栏显示当前账号名称和头像，支持头像、昵称、简介和标签编辑，并同步到云端账号资料。
- 行舟 AI 用户消息改为高对比度黑色文字，新增会话模型选择，切换会话不会中断其他会话。
