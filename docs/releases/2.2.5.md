# 行舟影视 2.2.5

修复云端大项目传输超时、切换分集后生成状态丢失，并细化剧本美术清单的人物定妆描述。

- 云端 JSON 响应支持压缩；协作项目列表只加载摘要，进入项目时再读取完整资料。客户端支持压缩解码、合理超时和相同读取请求合并，保留 HTTPS 证书校验。
- 美术分析按段保存到本机，云端同步失败不再中断后续分析；补传已完成结果不重复调用模型。显示响应等待时长和接收进度，保留异常情况下的部分正文。
- 导演任务跨分集、场景和工作台持续运行，各分集使用各自选定的接口。分段并发中部分失败时保留其他成功结果。美术与资产页共享图片任务状态和请求锁。
- 修复浏览器缓存配额耗尽导致本地文件保存被跳过的问题；云端快照按账号隔离，七天过期清理，不清除剧本、资产草稿、付费分析检查点或生成素材。
- 内置美术清单修订为 v4.1：细化脸型骨相、眉眼鼻唇、肤质、妆发、身形及服装分层；换装资产保留同人面貌，新条目可独立生图。人物排除剧情修辞和眼部光效，剧本明确的道具光效可保留。
- 修复头像浮层被侧栏裁切、批量生图工具栏对齐和场景列表换行错位。

验证：真实账号项目摘要读取约 0.3–0.6 秒，约 583 KB 完整项目约 0.36 秒返回；真实已配置 DeepSeek 小型分析约 9 秒返回正文。隔离界面验证了两集分别使用模型 A/B 并发、切到项目协作再返回后两份结果均保存，以及头像浮层与工具栏布局。自动回归包含 75 集中断续跑、云端失败后免重复付费补传、压缩传输、流式正文及接口隔离。

边界：外部网络和模型服务仍可能故障，不能保证永不失败。已有分析检查点和人工修改不会因 Skill 修订自动重做或覆盖；更细致的规则作用于后续新分析内容。应用内切页持续运行，不等同于退出程序后未完成的文本请求继续运行。
