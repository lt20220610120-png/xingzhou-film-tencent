# 行舟影视 2.2.7

修复自定义生图接口无法使用参考图片的问题：兼容 OpenAI 图片编辑协议的接口现在会实际接收参考图片，同时沿用当前选择的模型。支持本地与云端参考图；接口返回失败时保留错误，不自动丢弃参考图重新生成。

人物后续服装、妆造默认参考该人物的第一张图片，跨集数沿用；仍可手动更换参考或选择不引用，单张与批量生成保持一致。

验证：参考图片传输、默认参考选择与手动覆盖的针对性检查，生产构建和安装包启动检查；未调用付费生图接口。

协议依据：[OpenAI 图片编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit)。
