# 行舟影视 2.2.8

## 协作美术增量

- 美术页增加“添加集数”：粘贴或导入本集剧本，只追加到当前协作项目，不回写导演工作台。
- 单集可“生成本集 / 继续”，读取此前美术资产与真实人物小传，复用已有角色、衣服和场景，再同步本集新增资产。
- 保留历史已完成分析，不因升级 Skill 自动重新付费。只有确认“重新生成本集美术”才重新调用分析。

## 内置剧本美术清单 V5

- 人物只收可见人物：手机与可见系统面板归道具；纯声音、旁白和无实体系统不生成人物。
- 换装依据剧情，不按每个场景自动换一套；小角色不扩出无必要的受伤/动作状态。
- 第一套描述人物身份和外貌；后续造型用参考图，只描述衣服、妆造及必要状态差异。
- 单张、批量和自由构图统一检查人物基准图；明确取消参考时提示一致性风险，避免无意中生成另一张脸。
- 场景依据真实场次头，不把台词/动作中提到的小空间自动扩为场景；同地点、同内外的时间变体默认参考已有图，只改时间与光线。
- 人物默认前置改为四格排版：左侧胸像大头特写，右侧全身三视图；自定义追加文案保留。
- 完整根文档与参考文件使用同一内置 V5 资源，不再存在短版运行规则冲突。

## 数据与验证

保留旧资产 ID、图片关系、历史分析及手工描述。加强协作/导演源权限校验、原文冲突与串集检查、单集发布事务及同名资产最早集数合并；补齐分镜集数归属、锁状态查询失败保护，以及导演源删除与协作关联之间的并发保护。

自动化覆盖解析、参考差异、追加与发布隔离；实际 Electron 界面使用隔离夹具验证追加第20集、本集分析、旧图/导演源不变和付费重跑取消；另以真实模型返回及真实云端只读请求核对，夹具验收不冒充用户项目数据修改。
