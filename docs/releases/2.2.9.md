# 行舟影视 2.2.9

## 修复信息读取完成后，美术和资产停在部分集数的问题

- 分离“本机分析完成”和“云端同步完成”，美术分集卡、信息读取、资产总览显示真实同步状态与错误集号。
- 同步某一集失败后，不再阻断所有后续分集；每集结果和错误独立保存，可继续补同步。
- 重启软件后恢复已保存结果的同步入口，不依赖上一次运行时内存，也不要求重新选择大语言模型。
- “同步已保存结果”只重试解析和保存，不调用模型，不重新收费；保留原始输出、历史版本和未完成内容。
- 修复同集自引用、错误复用集号，以及输出中途重复开头导致整集发布失败的问题。只按同名已保存描述和真实已有资产恢复，不猜测合并不同名称。
- 无法核实的复用条目单独显示为待核对，保留原文，不再使整集合法资产无法同步。
- 修复仅描述衣装/伤情差异、引用同一人物基准造型的条目被云端误拒绝。
- 重新分析本集时，不把该集尚未同步的旧结果当成此前资产，避免“复用自本集”。

## 保留项目与已完成工作

同步采用增量合并，保留已有资产 ID、图片关系、手工描述、导演剧本及既有分集。继续包含协作开启修复：本地导演项目可创建单向协作快照，云端项目保留权限校验。

升级后打开协作项目，点击“同步已保存结果”；如已有补同步数据，点击“刷新云端数据”即可查看。无需重新分析整部剧本。
