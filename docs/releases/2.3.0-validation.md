## 边界

模型列表通常不包含完整参数，本版接受接口返回的枚举并允许用户按服务商说明补充。语音模型可分类保存，暂无独立语音工作台。第三方服务中断、结果地址在下载前已被供应商删除，不能靠客户端保证恢复；已有下载回执会保留，不自动重发付费生成。

参考研究：[LiteLLM 模型管理](https://docs.litellm.ai/docs/proxy/model_management) 展示了按模型维护元数据的开源方案。本版未引入额外网关服务，保留现有接口调用路径。
