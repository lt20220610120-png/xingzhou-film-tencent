# 行舟影视（腾讯云版）2.3.0

- 修复项目负责人因协作成员关联查询而看到重复图片的问题，保留原图。
- 美术批量生成默认只勾选未生成资产；全选也跳过已生成及复用图片，仍可手动选择重新生成。
- 创造模式只展示该模式的提示词；创造模式与历史提示词采用双列布局，窄窗口自动单列。
- API 接口新增“拉取 / 导入模型”，同一接口可导入多个模型并选择用途；每个模型可配置时长、分辨率、画幅或图片尺寸，生成界面随模型变化。
- 图片读取与下载在瞬时网络错误时有限重试；结果已生成但下载失败时保留恢复记录，重试下载不会重新调用生图。云端保存中断保留本地结果，重试前核对已保存图片，避免重复记录。
- 项目图片预览失效后自动续签；下载及参考图提交前重新获取授权链接，兼容旧项目图片。

## 使用说明

在“设置 → 软件更新”检查并安装更新。旧版本也立即受益于云端查询去重；新的自动续签和恢复功能需要客户端升级。

模型列表能返回哪些参数取决于服务商。未返回的参数可在 API 配置的“该模型支持的参数”中按服务商文档补充，例如时长填写 `5,10,15,30`。填写参数不会增加模型本身的能力。语音模型支持分类保存，本版未增加独立语音生成工作台。自定义生成仍需符合界面说明的图片编辑或视频任务协议。

更新保留项目、图片、提示词、Skill 和 API 配置。
