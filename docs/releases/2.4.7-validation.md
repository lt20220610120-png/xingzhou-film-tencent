# 2.4.7 验证记录

本次验证使用模拟生成接口与独立临时文件，不触发付费生成，不清理用户真实资料。

## 自动检查

- `npm test`：全量源码测试。
- `npm run build`：生产前端构建。
- `electron/generation-cleanup.test.cjs`：单条与批量清理、多个图片文件、外部另存保护、仍引用文件保护、活跃与待核对状态保护、重复请求、图片/视频隔离、文件占用回滚、记录保存失败回滚、资料目录切换。

## 界面检查

使用真实 App 页面及模拟 IPC，Playwright 在 1120、1440、2048 像素窗口检查：

- 导演卡片移除首字封面，操作按钮同高、同排，主要操作等宽，长标题不溢出。
- 协作卡片与 Skill 卡片保持紧凑；长 Skill 简介不撑高整排，查看完整简介和搜索可用。
- 整本提示词上传和清除按钮同高、等宽并列。
- 清理前显示确认弹窗；取消不调用清理接口；失败结果可单独清理；清理失败仍显示弹窗并支持重试。
- 批量清理只传入当前媒体类型的已完成或失败任务；运行中、待核对和另一媒体类型的任务保留，结果刷新后显示释放空间。
- 页面无渲染异常，卡片无横向溢出。

界面报告和截图保存在本地 `output/playwright/ui-2.4.7/`，打包后的运行时检查由 `npm run release` 执行。

## 存储与流量范围

从 `electron/generation-jobs.cjs` 与 `GenerationMonitor.jsx` 确认：生成完成后媒体会下载到本机资料目录，结果列表主要读取本地记录；已完成且有本地文件的任务不会再次查询或下载媒体。视频列表使用 `preload="none"`，点击预览时才播放。绑定协作项目的完成作品会上传到云端；本次本地清理不删除云端协作媒体，也不调用服务商的删除接口。

清理仅处理所选结果记录及其位于软件媒体目录内的图片/视频文件。资料目录外的文件、其他项目/草稿和任务仍在引用的文件保留。文件删除前通过同卷硬链接保留回滚能力；文件占用或结果记录保存失败时恢复原路径。资料目录按路径缓存独立生成管理器，防止切换资料目录后扫描和清理范围不一致。
