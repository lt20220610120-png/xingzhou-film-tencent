# 行舟影视 2.7.4 验证记录

本次更新落实用户的总剧本固定操作栏、批量确认、正文字符统计、本机豆包工作文本连接及两库卡片对齐要求。

## 功能和边界

- 总剧本标题、任务状态及操作按钮固定在项目工具栏下方。工具栏实际高度通过 ResizeObserver 测量，窄窗口换行后仍保留正确偏移。
- “一键确认全部正文”与转写按钮并排。非空设定、小传和分集一次确认；空内容跳过并提示。发现关联旧小说的正文时整批拒绝，保留当前稿、历史版本与已收录快照。
- 原文和正文字符统计采用 Unicode 字符计数，含空白，换行计一次。正文统计去掉隐藏的标题格式标记；整集、当前场景、设定及所选历史版本分别展示。
- 果子库和 IP 库的创建入口与项目卡片同宽、同高；内边距和操作按钮统一。两行长标题保留省略展示及完整标题提示，底部按钮对齐；悬停不再产生位置偏移。
- 豆包工作连接使用已登录客户端的正常 Windows 辅助功能界面，新建独立文本任务并选择账号实际可用模型；默认高推理强度。接收结果同时验证新任务 ID、助手响应区域与随机起止标记，拒绝用户输入回显、其他任务正文及截断输出。
- 调用期间需保持客户端运行、登录且保留本次任务页面。客户端保存自己的登录状态；不复制 Cookie、账号令牌或私人任务资料，也不依赖远程调试端口。
- 图片、视频、语音尚未完成通过此账号的端到端生成与原始成果接收验证，因此本版仅提供豆包工作文本连接。

## 已验证界面

Playwright 使用隔离的模拟账号与项目，不改用户资料。1600、1180、1120 像素窗口验证固定栏偏移及并排操作。批量确认覆盖非空正文、空集跳过和设定同时确认；场景、整集及历史版本的显示计数与文本一致。

IP/果子卡片在 1600、1180 像素窗口等高等宽，底部按钮同一水平线；长标题验证通过。豆包工作接口表单可选择自动、Lite、Turbo、Pro，测试和保存使用高推理强度，免 API Key。

证据保存于 `qa/creator-v274-*.png` 与相应脚本、日志。原生客户端的实际调用验证另行记录，不以界面模拟替代。

## 开源资料核对

[CoreStudio 的 DoubaoWork 集成说明](https://github.com/walnut-a/CoreStudio/blob/main/excalidraw/apps/image-board-desktop/docs/agent-integration-user-guide.md)描述的是豆包 Agent 操作第三方画布，不是供第三方软件调用豆包工作的模型接口。[doubao-free-api-FIX](https://github.com/wuyichuan1/doubao-free-api-FIX)针对普通豆包网页，不能作为豆包工作客户端接通的证据。本次文本桥独立实现，没有把这些地址当成已验证 API。
