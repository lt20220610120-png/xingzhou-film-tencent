# 2.8.2 卡片创作工作区

本次依据用户第二轮十张截图调整交互。核心是直接编辑完整事件卡片，辅助功能按当前创作位置调用；保留 2.8.1 的七步流程和本地保存机制。

## 实现

- 大事件与小事件各只有一个自然语言正文编辑区，标题自动从首行提取，也可由 `frameworkCard` 任务整理。旧结构化信息收进详情，手改后标记 `analysisStale`，提示模型重新核对。
- `frameworkCard` 通过现有真实模型调用、输入指纹、候选审阅链路运行，校验目标 ID 和锁定状态。人工采用仅改目标节点，正文及其他版本不覆盖。
- 主线和组内推理使用已有 `frameworkSimulate`，工具在工作区右侧展开；审阅采用使用同一事务保存候选并写回卡片。
- `mainline.confirmAll` 是用户明确复核全部故事后的批量确认，仍拒绝缺失内容、未决设定、已删除事件引用和被锁定的未确认节点。自动建立相邻卡片衔接，无需填表。
- 手动 `plan.add` 可建立草稿版本；没有已确认故事时保持待复核状态，正式生成与终稿确认继续受原规则约束。
- 集纲和正文共用分集工作区，选集状态由父工作区保存。切换版本不改其他版本内容，批量生成在切版或离页后停止继续采用。
- 按稳定 ID 定位小事件移动序号，修复规范化后的新对象无法通过 `indexOf` 找到原列表位置的问题。

## 验证

- 核心新增覆盖：整剧确认及衔接、缺内容与锁定拒绝、无前置条件的手动草稿、版本正文隔离、未提交灵感持久化、模拟单事务采用与过期/锁定拒绝、定向卡片整理。
- Playwright 操作真实 React 页面，通过隔离的本地模拟接口验证，不使用付费生成；40 项独立断言通过，另完成手动建卡、大小事件排序、确认故事、AI 三集分集及连续生成、生成中切版的完整流程。
- 实际检查 1600×1000 和 1280×900 的空项目、已填充灵感、卡片、模拟侧栏、版本分集正文；灵感无需整页滚动，版本目录和添加集数保持可见。
- 本地测试截图和浏览器脚本位于忽略目录 `output/playwright/components/`；用户真实项目未作为测试数据修改。
