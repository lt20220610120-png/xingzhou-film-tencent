# 2.8.3 接口选择与可移动创作窗口

按用户三张截图完成：新建卡片与事件卡片等大、覆盖工作区的窗口可拖动、每个步骤和 Agent 操作旁可直接选择接口。

- `frameworkModels` 兼容旧项目的默认接口，新增按步骤保存的 `modelSelections`。模拟使用当前步骤下独立的 simulation 选择；已删除的模型依次回退到可用步骤选择、旧默认和当前可用接口。
- 各页面标题区直接显示选择项，事件卡片和正文操作旁同步显示选择项。执行任务时读取最新本地配置，将对应真实 profile 和 model 传给现有模型调用流程。
- `useMovablePanel` 共用于模拟助手、候选审阅、写作 Agent 及 CreatorDialog 弹窗。标题栏支持鼠标/触摸指针捕获和方向键移动，输入框、按钮不触发拖动。位置按项目/窗口记住，并在窗口尺寸或浏览器尺寸变化时约束到可见范围。
- 新建卡片统一为 360px 高；集纲正文容器使用剩余高度，避免接口选择让底部操作超出屏幕。

验证：核心测试覆盖步骤隔离、旧配置兼容、模拟独立选择、模型移除回退与保存恢复。Playwright 真实页面完成 35 项断言，验证卡片等大、所有页面直接选择、真实调用所选接口、五类窗口拖动、输入不误拖、保存位置、重开恢复和缩放边界；另验证 1280×900 的正文底部与增集按钮可见。模型调用使用隔离的模拟接口，未消耗付费额度。

截图和验证脚本保存在忽略目录 `output/playwright/controls/`。
