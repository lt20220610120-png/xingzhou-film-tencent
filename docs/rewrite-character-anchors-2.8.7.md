# 行舟影视 2.8.7 验收记录

本次将原创批量确认和洗稿的人物关系转换接入实际任务、候选采用、主线、版本及发布流程。用户默认“反馈后直接设计、实现、验证、发布”的偏好已保存到本目录 AGENTS.md。

## 使用路径

原创主线点击“一键确认全部”，一次确认完整大事件内容及当前顺序，留在当前页。已有小事件、完整故事稿、集纲及正文状态不受确认动作影响；空白卡片整批拒绝，固定未确认内容先解除固定。

洗稿按“设定 → 大纲 → 人物与关系 → 主线 → 细纲”使用。人物区输入新作主角和对应要求，选择接口，生成并审阅候选；采用后可修改姓名、关系称谓或来源对应，再一键确认。随后转换待处理的大小事件，审阅采用并确认大纲，再到主线展开故事。

不同书籍的来源角色由来源编号和角色编号共同定位。同名角色不会自动合并；不同来源的主角可对应同一新作人物。未命名关系人物使用明确称谓，母亲、继母等冲突需处理；自然语言续改携带上轮候选与要求。批量转换跳过固定组并显示原因，指定固定事件转换会被拒绝。

转换保留事件编号、顺序和来源引用。人物修改不会自动换掉旧正文，而是保留并标为需复核。主线可一键重新完善需复核事件，逐项记录进度；已完成且依据未变化的内容无需重复生成。版本保存人物及转换依据；升级前的旧版本没有人物结构时显示待整理，原有人物分析和稿件保留于历史。
