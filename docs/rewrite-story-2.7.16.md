# 洗稿主线：完整故事稿

用户已确认主线详细程度：完整故事稿，写清具体经过、人物行动与心理、因果和前后衔接，必要时有关键对白，不分集。来源自动带入，可人工增删多个参考，也允许无参考。本次确认替代此前“主线逐集提纲”的设计。

操作：先确认新作设定及大纲。在主线选择 A1 等小事件，可“一键完善未完成事件”或单独“完善此事件”，然后人工修改具体故事和衔接问题。全部小事件完成后“确认整部故事稿”，再由细纲按照节奏、悬念与衔接划分集数。人物若已确认且仍有效，也作为本次约束。

输入：完整新作大事件与小事件链、已确认设定和人物、当前故事稿，以及这条新作链明确绑定的对标事件及对应具体经过。未选参考事件和未采用素材不整本附入。绑定使用 sourceId、groupId、eventId，而 A1 只是显示顺序；重排、改名和跨书引用不猜编号。新版引用及模拟保留结构化来源；旧版仅有文字来源时，唯一明确对应可以沿用，其余提示人工选择参考或明确无参考。长篇结构化输入完整发送，并接受接口容量检查，避免摘要丢掉真实编号与约束。

保存：模型结果严格校验指定事件范围，只合并目标事件，草稿不自动确认全剧。人工改动、上游变化及锁定保护沿用已有历史与输入检查。旧逐集资料留在事件内归档；删除大纲事件后，其故事留在归档中，不进入当前故事或下游分集。当前大纲中修改参考会取代同事件的旧主线参考覆盖；只改标题和顺序会保留人工参考选择。

展示：大纲大小事件使用不同背景与边框，组结束标明名称。主线左侧完整新作事件导航，右侧为故事编辑与参考；协作浮窗保留。大世界模拟顶部可选全部已配置接口模型，与开始按钮水平排列。
