# 2.8.10 共用工具与快速身份切换

## 用户要求与实现

导演与内容创作者改变的是侧栏上部工作区，Skill 库、API 接口、设置、管理后台是同一账号的共用工具。用户在导演身份打开 WorkBuddy 号池内页后，切换到内容创作者再进入管理后台，需要保留原页。切换身份支持悬停浮窗，点击目标身份一步完成。

旧实现把 `role` 设为 `null` 后从 App 提前返回身份选择页，导致已有工作区卸载。管理后台仅能从本地存储恢复顶层标签，无法保留已销毁原生页面的路由、输入和滚动。浏览器红测试确认同一操作会调用 WorkBuddy 关闭和再次打开，页面宿主节点不相同。

新实现中，已登录账号的工作区保持挂载。身份选择页只隐藏工作区、关闭原生页面显示，不销毁页面；快捷切换不经过身份选择页。共用工具第一次访问后保留组件实例；身份切换在共用工具上保持当前导航，在身份工作区上恢复目标身份最近的功能。

共用工具与身份导航在侧栏分开显示。浮窗显示当前身份和目标身份，支持 hover、click、键盘、Escape 和减少动效设置；未解锁身份走现有解锁流程。导航纯函数验证合法角色与已开通权限，不允许非管理员保留管理后台路由。

隐藏共用页时，通用 Dialog 和 DeleteConfirm 的 portal 同步隐藏、停止焦点与键盘处理，保留表单草稿。打开身份浮窗时原生号池暂时隐藏，防止 Electron 原生页面遮住菜单；菜单关闭后恢复。账号切换按账号键重新创建工作区，注销销毁原生页面，不能把一个登录的管理员页面交给另一个登录。

## 验证证据

- 导航模块测试 4 项，覆盖共用页保留、身份最近页、无权限/非法目标阻止、非管理员路由回退。
- 真实 App 浏览器测试：管理后台宿主节点保持相同、额外 WorkBuddy 打开次数为 0；快速切换和旧身份选择页均保留页面。Skill 搜索、API 分类搜索、设置数据不重新载入。
- 真实 Electron + `WebContentsView` 本地 fixture：快捷切换、离开管理后台再返回、旧身份选择页三条路径，WebContents ID、页面 URL `/accounts`、`performance.timeOrigin`、页面标记、输入内容均保持原值。全页 `scrollY=700` 保留；`height:100vh` 内部列表 `scrollTop=600` 保留。注销后原生视图数为 0。
- 浮窗打开时原生显示区域隐藏，Escape 关闭后恢复；键盘能够直接切换，只有内容创作者权限的账号选择导演时出现解锁对话框。
- 原生验证使用隔离临时资料目录与本地 HTTP 测试页面，账号响应为测试 fixture；没有访问用户真实 WorkBuddy 账号池或云端用户管理资料。
- 独立只读复核未发现可确认的阻断缺陷，建议的内部滚动关注点已通过真实 Electron 验证。

- 最终 `npm test`：1804 项通过，0 失败。`npm run build` 通过，保留已有大包体积提示。
- 追加真实页面验收：各身份上次功能恢复；隐藏页面的 API 编辑 portal 不遮挡新页面，草稿再次进入时仍保留。1920、1120、820 宽度下浮窗完全处于视口内；截图已检查。
- 移除旧测试对管理后台私有 JSX 包装结构的限定，挂载/隐藏/卸载契约由真实 App 与原生视图测试验证；原管理员权限限定仍检查。修正既有网络错误分类测试的 1ms 时限，避免全套测试并行时连检查分支都未执行就超时，产品时限未改动。
