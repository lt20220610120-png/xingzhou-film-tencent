# 提示词关联下游贯通 Implementation Plan

**Goal:** 场景卡片固定紧凑结构；美术显示提示词级去向；分镜加载已审核本条素材。
**Architecture:** 美术和分镜通过只读 hook 获取现有 promptArt 版本快照及决策；核心函数校验条目身份、原文、签名和图片，旧项目无关联记录时才回退场景。分镜界面展示编译关联但保存时保留导演原始提示词，避免反写别名使来源失效。
**Tech Stack:** React、现有 bridge、Node tests、Playwright。
**Spec:** 用户本轮三张截图及文字。
