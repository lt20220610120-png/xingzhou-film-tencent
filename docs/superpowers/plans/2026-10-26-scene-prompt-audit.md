# 场景到提示词关联与紧凑审核 Implementation Plan

**Goal:** 在场景清单维护提示词关联，在提示词页紧凑审核同一份结果，图视生成同步。
**Architecture:** 关联仍保存到现有 promptArt 版本记录，以卡片 uid 和提示词 id 为身份；不向场景资产复制第二份关联数据。场景操作与提示词审核共用保存事件及 CAS，避免不同页面出现不同结果。
**Tech Stack:** React、现有 Electron bridge、Node tests、Playwright。
**Spec:** 用户 2026-10-26 最新五张截图及文字要求。

## Global Constraints
- 保留集→场景→提示词层级与历史提示词版本。
- 提示词右侧默认只显示已关联对象；人工关联入口在场景卡片及可展开本场景资产清单。
- 基础设定按字段和分号读取；属性不能作为实体。保持现有人工锁定、失败三次限制、来源变化检查。
- 发布 2.8.77，交付公开及本地安装包链接。

## Review Focus
- 多场景共享同一资产时不能串场关联。
- 手工关联跨切换、重开及 AI 复读后保留。
- 同一场景多个提示词版本相互隔离。
- AI 缺项不得静默创建人物；缺场景需提示回场景补齐。
- 两个布局等高、内部滚动、窄屏不溢出。
