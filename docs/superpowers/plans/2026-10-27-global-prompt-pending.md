# 全剧提示词待处理实现计划

**Goal:** 全剧缺项统一折叠汇总，可一键确认所选项或全部项无需参考图，当前提示词缺项操作同行靠右。

**Architecture:** 沿用按版本保存的模型分发结果，汇总当前所选版本的全剧 pendingMissing；批量确认以一次 service.mutate 原子保存，保留未选项、人工锁定和核实发布门禁。复用原 React/CSS。

**Design:** 两个顶部按钮分别为“一键确认所选无需参考图”“一键确认全部无需参考图”，避免不明确的同名操作；details 默认收起并显示全剧数量。移除解释副文案；返回补充跳至目标集场。无新模型调用，不自动发布。用户与 tencent/AGENTS.md 已授权直接执行发布，无需设计确认。

## Review Focus

- 按钮只确认当前展示过的目标，不吞并稍后新增缺项。
