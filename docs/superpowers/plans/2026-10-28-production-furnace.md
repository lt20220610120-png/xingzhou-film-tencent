# 制作工作流与视频池实施计划

依据：用户 2026-10-28 的 15 张截图与明确发布指令，基线 b1b8965 / 2.8.87。用户已授权直接实现、验证和发布，不另设方案审批。

## 产品与执行约束

- 管理员制作控制台：一次设置，上传完整剧本或选择现有导演项目；自动模式由剧本起步，半自动保留人工已核对结果。
- 设置：制作 Agent、导演风格/画幅/最高时长/提示词模型与 Skill；美术画风/人物构图/分析模型；生图主备模型、各模型尝试次数、画幅/并发；视频接口模型/画幅/时长/分辨率；项目目录；Topaz 路径及 2/4 倍；OpenFilm 路径、剪辑 Agent/模型/指令、可选音乐和音效目录。
- 运行流程复用既有导演、协作、清单分发和生成业务，成功结果保留；无效关联、未知付费结果不得自动重复提交。明确失败有限重试；内容拒绝与网络/额度/参数错误分开，不把 HTTP400 推断为儿童拒绝，不以措辞伪装绕过内容限制，不擅改已选画风。
- 原片、超分按项目/集归档。整集预期片段校验完成才进入下一环节。Topaz 单集串行；后集生成/超分与前集剪辑可并行。以实际产物校验为完成条件。
- 视频池开放给具有分镜权限的协作成员，位于分镜与邀请协作之间；全剧/分集/场景筛选，自然数序号排序，5秒无重叠轮询，批量下载对应范围成功视频，显示失败及运行任务。生成与下载按钮分开，不混淆收费行为。
- 自动化入口保持管理员限定；不改卡密方案。检测真实可用连接/模型后才允许启动，不能把路径、交接清单或 Agent 回复当执行成功。

## 实施顺序

- [ ] 视频池：纯数据合并与自然排序、角色导航、状态轮询、批量归档 IPC、界面与回归。
- [ ] 制作运行数据与控制台：持久化配置/分集阶段，上传入口、设置表单、预检、开始暂停继续、异常详情。
- [ ] 本机 Agent 连接：实际协议握手、模型发现、受限任务执行、取消与进度；不复制登录凭据。
- [ ] 导演/美术/视频适配：复用现有函数与存储事务，补缺、按条绑定、有限失败恢复，记录上游 ID。
- [ ] Topaz/OpenFilm：检测已安装版本支持，接入实际执行能力，逐集清单/产物验证，未就绪时明确阻塞。
- [ ] 聚焦测试、真实 React 界面验收、全量测试及构建、独立复核、2.8.88 打包发布和公开下载核验。

## 验收重点

账号/项目切换隔离；重启/暂停不重复付费；相同场景多条正确排序；目录存在不等于视频齐全；过期关联不生成；Agent 断开不假报完成；旧人工流程与既有工作流任务保留。
