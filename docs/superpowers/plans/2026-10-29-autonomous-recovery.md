# Agent 自主修复与持续接续实施计划

目标：自动化遇到未发布、缺描述、缺关联、签名变化及可恢复生成错误时，自主设定子目标并调用所连Agent实际处理、验证后接续；完成项保留。余额不足明确显示并释放任务等待续费。

设计：在原制作控制器加入持续恢复循环与退避，按目标保存尝试、下一次时间和验收结果。新增管理员联网IPC `production-work` 调用本机Agent完成结构化制作子任务；程序执行已授权且范围明确的工具操作，不授予任意脚本/任意路径修改能力。原清单核实/发布接口及CAS保持，自动模式只补缺项。成功做法保存为结构化制作经验，后续Agent读取，不能把未经验证的计划当成功。

实际根因（本机只读）：当前60集、96场、212条提示词，93场发布、3场缺发布但描述就绪；136张图记录服务商quota不足，旧attempts使继续时不再调用；视频关联来源签名失效，没有修复。不要靠删除业务数据重置。

- [x] 新增恢复目标与可验证关联修复函数；补原问题失败测试。
- [x] 自主发布：先发布已有合法场景，不以全部提示词通过新审核为前提；描述、绑定、缺卡由Agent定向修复/补齐。
- [x] 接入本机Agent实际工作IPC、有限输入字段、校验结果及进度；保留暂停和鉴权。
- [x] 生图余额与生成失败次数分离、主备渠道余额熔断、恢复旧耗尽项；非余额失败交Agent修订本次生成提示词，原资产保留。
- [x] 制作控制器持续接续，临时失败退避、目标与成功经验持久化；界面展示目标、处理状态、实际原因。
- [x] 模拟接口回归/三宽UI、独立复核、全量测试/构建验证；2.8.95 真实付费联合试跑仍待管理员验收。

边界：用户已选模型/风格/画幅是硬约束。不得伪造发布、跳过必需图片或把不确定已提交任务作为新任务再付费。外部权限、服务不可用等无法凭空改变，保持待恢复并说明原因；不静默丢弃目标或谎报完成。相同错误频繁出现需退避，不能无上限高速消耗Agent额度。
