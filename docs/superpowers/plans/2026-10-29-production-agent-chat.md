# 制作 Agent 对话与项目接续

目标：修复回收站项目导致重复关联阻断；复用已发布清单；提供能实际纠正任务的 Agent 对话，并保存用户确认的默认规则。

授权：用户要求直接完善发布，沿用 tencent/AGENTS.md 的当前会话实施流程。界面沿用项目 React/Lucide，不加第三方 UI 执行插件。

- 协作选择：排除 deleted_at/purge_after 回收项目。优先 run/config 明确 ID，其次导演关联 ID；多个正常项目时按更新顺序选并记录，界面允许明确改选。无项目才创建，读取后验证导演关联；不靠同名串项目。
- 已有清单：读取本地/云端 ledger，已有资产/发布记录不重新整本分析。已有提示词分发读取原版本，对就绪未发布场景继续核实发布；图片复用成功项。
- 对话：模型选择+滚动消息+输入框，后台只读 Agent 返回结构化答复/有限动作（继续、暂停、重新读取、选择同源项目、保存经验）。由受权限约束的控制器执行，未知动作拒绝，执行后记录结果。聊天响应不得回写整份旧任务覆盖后台进度。
- 默认流程：用户明确保存的一段纠正规则按账号持久化，下次创建注入 config；生产/剪辑 Agent 读取。对话历史/阶段错误可恢复展示；不伪造可用工具或任意执行脚本。
- 测试：回收站+正常项目、零项目自动创建、两正常项目、已发布清单不重分析；对话成功/失败/重复点击/运行中修改守卫；三宽UI、全量测试/构建/独立复核/安装包/公开签名清单。
