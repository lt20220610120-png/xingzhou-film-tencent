# 制作总控交互改版计划

目标：按用户截图反馈，把长表单改成分步工作台；目录、软件和模型通过点击选择，连接信息集中展示，控件同高对齐。沿用现有权限、任务执行与预检，不新增付费调用。

设计选择：采用项目现有 React / Lucide / Electron 原生对话框，避免为展示引入另一个 Agent 执行插件。五步导航减少页面长度；模型/项目用可搜索弹窗；小型参数保留下拉或数字控件；路径用整块按钮。制作与剪辑连接卡片独立，明确未连接/连接中/已连接/失败。文件夹窗口支持选择或新建；音乐音效允许清空。用户已明确授权直接实施发布，按 tencent/AGENTS.md 不另行等待设计批准。
