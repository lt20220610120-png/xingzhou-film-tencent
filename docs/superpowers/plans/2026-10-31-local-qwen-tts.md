# 本地 Qwen3-TTS 接入实施计划

> 采用 superpowers:executing-plans，由当前会话直接实施，结束前独立复核。依据 tencent/AGENTS.md 的持续授权，无需再次确认架构或实施计划。

**Goal:** 在 D 盘部署官方 Qwen3-TTS-12Hz-1.7B-VoiceDesign，配置行舟影视并实际生成可试听、保存的语音。

**Architecture:** 官方 Python 推理 + 仅监听 127.0.0.1 的 OpenAI speech 兼容服务；Electron 主进程请求并保存音频，API 语音页提供模型配置及文本/音色说明/语言/生成/试听/导出。

**Tech Stack:** Python 3.12、PyTorch CUDA、qwen-tts、FastAPI；Electron、React。

## 约束与决定

- 官方更新清单和当前源码均为 2.8.96；audio 仅存配置，无生成调用，需要更新。
- 优先独立本地服务而非将数 GB 模型打进安装包；比只有 Gradio 页面更方便行舟调用。
- D:/AI/Qwen3-TTS 存环境、源码、权重、缓存、日志、启动脚本；本机 RTX5060 8GB，先 BF16 SDPA 验证。
- 允许无 Key 本地 HTTP；公网兼容接口仍保留 Key 设置；错误和无效音频不得作为成功。
- 保留当前 checkout 及其他未提交工作，仅提交本次明确文件；遵从用户现有偏好直接实施、验证、发布。
- 语音生成显式点击触发；不自动重试生成；本机服务一次处理一条，避免显存溢出。
