# 可选人物音色、并发及工作区布局

按用户明确规格和 AGENTS.md 的直接实施偏好，在当前发布工作区完成，不另建实施审批。

1. 音色为可选阶段：新任务及旧版未设置开关的任务默认关闭，开工前/运行页可切换。关闭只停止后续音色工作，保留已有音色和视频成果；关闭不要求音色模型，不触发音色修复。运行中开启先暂停新派发；用户点击继续后先补跑音色，再接续原任务。
2. 并发数是正整数输入，无固定型号上限。音色批处理共享 worker pool，取消后不再派发，单卡失败不阻断其他人物，已有候选采用第一条，保留已确认音色。当前本地模型双请求探测并报告部署的有效并发，不宣称理论显卡上限。
3. 管理页移除固定最大宽度，随窗口伸缩。音色页统一控件高度、底部基线及标签行；定位按钮用小号文字和浅色实体卡片。
4. 美术卡片生图前置/人物构图/保存及修改动作同排，窄容器自动换行。参考选择与本机参考图按钮并排且各占半行。
5. 先写行为回归：开关关闭、运行中切换、并发上限、取消及已有样音恢复。再修改对应实现。布局以实际 DOM bounding boxes 和截图检查，覆盖宽/窄及反复 resize。
6. 全套测试、构建、打包运行时、发布签名清单及安装包核验后发布新版本，更新交接和软件更新记忆；如安装器未成功，不替换其他实例、仅报告实际情况。

重点复核：关闭音色不产生 voiceWarnings；旧任务不会卡在音色；运行中切换不重提视频；并发写入账本不丢候选；已有样音正确采用而非跳过；窄容器不溢出。

执行记录：回归测试先失败后修复。额外发现并修复音色型号选择ID误配、候选未采用、暂停后误判完成和关闭时空并发校验问题。独立复核42/42通过，无剩余重要发现。布局DOM验收覆盖750到2560宽度与往返resize；本地2请求探测一条200（6.047s）、另一条409（0.11s）。
