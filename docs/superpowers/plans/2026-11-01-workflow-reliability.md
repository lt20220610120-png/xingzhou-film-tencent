# 行舟影视 2.8.108 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. 当前会话直接实施，结束前独立复核。

**Goal:** 点击人物音色即可按需启动本机服务生成样音，自动制作有序接力模型，七步设置与真实模型参数一致。
**Architecture:** 复用 Electron 音频 IPC、信息读取持久化及现有生产流水线。新增共享有序模型策略，保留旧单备用配置。语音生成前检查就绪状态，本地已部署 Qwen 按需启动；远程仅使用用户显式配置的启动端点，不猜测云账号或重投不明生成。
**Tech Stack:** Electron / React / JavaScript / Node test / Python / PowerShell。
**Spec:** 用户本次六张截图及文字要求；AGENTS.md 授权直接实施验证发布，不另求方案确认。

## Global Constraints
- 保留用户数据、人工修改、已生成成果、账号/许可门禁。
- 七步：项目与智能体、剧本与提示词、信息读取、人物音色、美术资产、视频生成、超分与剪辑。
- 备用模型用户自由添加、排序、移除；各项尝试次数独立；生图数量独立。
- 音色补全保留原对白开头，仅补充短句以约3–5秒为目标，标记扩写与原文证据，不伪造逐字依据，不改剧本。
- 视频优先使用所选模型声明的画幅、时长、分辨率；未声明分辨率提供480p、720p、1080p、2K、4K。
- 付费生成用模拟接口；本机免费模型做真实联调。

## Review Focus
- 多个并发音色请求遇服务关闭时只启动一次，取消/账号切换不继续提交。
- 补全期间人工修改不被迟到模型结果覆盖；重复补全不反复扩写。
- 提示词批次部分完成或抛错后只补缺场，重启不把已耗尽主模型无限重试。
- 备用生图模型独立数量与次数实际出站；未知任务保留原模型查询。
- 同接口多视频型号不混淆能力；页面内下拉可滚动、键盘关闭、无全屏模态。
