# 制作智能体持续执行（2.8.119）

用户与AGENTS已授权当前会话直接设计、实施、验证、发布。

目标：聊天微调不停止调度；制作智能体始终知道身份、开工流程、主备生成策略与当前任务；后台首屏紧凑。

架构：继续复用唯一production controller与原视频状态机，聊天只改变当前任务安排，不另建制作执行器。明确暂停与范围调整为独立动作。身份持久化，实时任务契约每轮刷新（含运行中追加），默认配置不被临时指令改写。

取舍：不以关键词正则代替Agent理解，也不让Agent独立重复提交付费任务；采用结构化工具修改范围并唤醒既有状态机。

- [x] 控制器回归：聊天等待时继续派发；运行中set_scope不暂停且默认接续；旧暂停可通过新范围安排继续；已有任务/备用策略不变；明确暂停仍有效。
- [x] 身份模块与原生/ACP每轮及steer注入：配置只取白名单，当前安排及有界指令，持续执行指南；inspect与界面显示同一身份。
- [x] 实时范围修订唤醒恢复等待和视频调度；run_stage运行中接续总流程，禁止为了单独工序先暂停。
- [x] 管理后台标题与四入口同排，移除冗余说明、制作标题；实际后台容器高度计算，状态与输入框首屏可见。
- [x] 全量测试/构建、模拟生成失败切备用到超分剪辑、三宽后台UI、独立复核、打包运行验收、发布并校验公开清单。

风险复核：明确暂停不能被排队继续覆盖；范围改变时不得重复提交在途任务；范围外已提交保留；重复调用continue不启动并行执行器；重新连接身份与当前配置一致。

复核裁定：恢复请求按controlEpoch排队并在执行前去重，不能将整个执行Promise留在scheduled中；pause后新continue覆盖旧epoch。新增门闩测试确认peak executor=1。
