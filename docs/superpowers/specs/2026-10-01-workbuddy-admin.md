# WorkBuddy 管理后台集成

管理后台保留默认的用户、邀请码和制片身份管理，新增“WorkBuddy 号池”页签。新页签在行舟窗口内显示本机已有的正式 WorkBuddy Manager，自动发现桌面快捷方式，支持选择部署目录和自动启动服务。使用独立 WebContentsView 和内存 session，避免上游禁止 iframe 的限制。

进入、配置和更新必须由主进程向行舟云端验证当前管理员身份，同时拒绝被停用账户。面板不接收行舟 token 或 preload；主进程读取本机既存管理员配置，签发短期上游 Cookie，不要求再次输入面板密码。退出行舟、切换页面、身份失效时销毁独立页面与 Cookie；面板请求持续受身份门禁保护。腾讯账号的微信/QQ授权仍使用上游原功能。

GitHub 更新仅使用 ithtelab/workbuddy-manager 的正式发布和受信任 Ed25519 签名 tar.gz。安装前验证签名与路径，备份代码，保留 .env、data、upstream/auths/config.json/data 和现有 Windows 可执行文件；失败回滚。面板内提供检查、确认安装、进度和失败说明。上游自己的 Windows 网页更新入口保持原行为，行舟提供可用的原生更新入口。

发布行舟 2.4.9，完成权限、会话退出竞态、服务身份、签名拒绝、路径逃逸和回滚测试，验证真实页面内嵌与旧后台功能，发布安装包并核对公开清单。
