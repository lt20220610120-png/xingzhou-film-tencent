# 原创框架式创作正式接入

用户已于 2026-10-07 明确批准第二版事件工作区设计并要求应用到正式软件。按现有 AGENTS.md 完成测试、构建、提交、制作和发布新版安装包。

设计依据：工作区 `visual-prototypes/framework-creation-20261007/design-brief-v2.md` 和 `workspace-v2.js`、`workspace-v2.css`。正式版沿用预览的事件创作模型、层级、布局及操作意图，所有 Agent 功能接真实已有接口，不携带演示剧情或预设回复。

1. 七个主页面：灵感、设定、事件骨架、主线与衔接、人物与人物线、集纲版本、剧本正文；辅助页：对标组件库、大世界模拟、项目版本。
2. 原始灵感与整理摘要分开，用户决定哪些灵感供 Agent 读取。设定包括背景、脑洞、世界规则、个人金手指。补充设定经检查成为候选，冲突必须明确选择保留旧条、替换或合并。未决设定阻止正式事件/主线/正文生成与采用。
3. 任意数量的大事件 A/B/C，可选中事件分组，组内小事件 A1/A2。稳定 ID 为关联依据，显示编号随排序改变。大/中/小事件增删改、移动、固定；小事件可先独立保存，再归组。固定事件不可被编辑、重排、删除或模型候选覆盖。
4. 主线先组织完整事件故事稿，不提前分集。显示实际时间、叙事顺序、前置状态、行动结果、动机、伏笔；新连接与相关内容变化需复核。人工确认主线后才生成集纲。
5. 对标上传剧本/小说，通过真实 Agent 提取大/小事件；保留原文、出处和改稿。人工确认组件，再按本剧设定、人物与连接适配并插入。不把来源设定当正式故事事实。
6. 模拟分排列组合、向后推理；读取确认设定、固定事件及选定组件，给独立候选版本。模型输出必须结构校验、锁定约束校验、运行时输入指纹复核，人工采用。
7. 集纲独立多版本，支持生成、查看、采用、手改、删除、恢复。一事件跨多集、一集含多个事件。正文属于所采用版本；切换不覆盖其他版本正文，删除版本保留恢复资料。
8. 正文支持按集生成、依次补齐未完成集、停止、编辑、确认、衔接检查和导出收录。读取当前确认规则、全剧骨架、当前版集纲、此前正文；真实错误提示、任务历史、输入变化后保留候选。
9. 原有框架项目、自由原创、洗稿、IP、果子库均兼容。旧框架内容完整保留；结构化资料能可靠迁移，非结构化资料放旧资料区供整理，不凭空改写用户故事。数据归入原有持久化流程，禁止并行维护本地演示状态。
10. UI 沿用正式浅紫侧栏、白色工作区与可拖动 Agent 浮窗，禁止使用 frontend-design 技能。浏览器验证使用模拟接口，不调用付费模型。

验收：数据与任务测试通过，实际界面验证覆盖关键操作、失败和刷新保存，生产构建与安装包运行时验证通过，公开更新清单与实际安装包版本、大小、SHA256 一致。
