# LibTV 账号连接设计

目标：用户在行舟影视授权自己的 LibTV 账号，选择实时模型，在图视生成生图/视频，并在协作分镜生成后共享视频。

官方依据：用户提供的飞书《LibTV CLI 使用指南》及其 1.1.3 官方命令包。当前入口是浏览器回调登录，不是旧 Access Key HTTP 接口。连接器采用官方 CLI，避免自行复制未公开鉴权接口。

连接：API 接口新增「连接 LibTV」，首次从固定官方 HTTPS 下载并按固定 SHA256 校验 CLI，不执行下载的安装脚本。登录打开官方页面；软件只显示连接状态、账号名称和空间。按行舟账号隔离本机凭据；凭据不进入项目状态/云协作，静态存放使用系统加密，运行期间仅 CLI 工作目录临时解密。退出/账号切换关闭本软件子进程并封存凭据。

生成：图视生成与协作分镜复用 GenerationComposer/generationJobs；LibTV 图片及视频均进入既有任务记录。读取 image/video 模型目录、按选中模型读取 schema，支持模式、通用参数与额外设置。参考按原顺序上传并连到本次节点，仅上传当前提示词和用户选定参考，不上传整本剧本。固定账号/空间和每次任务身份，任务保留对应 LibTV 画布链接。

任务：先创建独立画布和节点并保存定位，随后只触发一次官方 --run；主界面立即返回提交态，进程在后台等官方终态，不重复启动付费任务。结果下载到当前资料目录；失败保留节点定位，恢复只查询/下载。退出中断本地等待后，重启可读取节点找回已完成结果；提交未确认需用户查看官方画布，禁止自动重跑。协作成功按既有流程上传生成媒体，其他成员无权获取生成者的登录凭据。

兼容：普通 API 配置和既有图片名单保持原行为；LibTV 连接配置仅保存 provider/model/catalog/非秘密参数。账号注销可保留已有成果。切换 LibTV 账号/空间时有运行任务则阻止切换，旧结果恢复须身份与空间匹配。

验证：纯函数参数/模式测试、CLI 模拟命令链与恢复、凭据隔离/加密/生命周期、图视与分镜界面验收、原协议回归、全量测试与包内运行。禁止付费生成测试。按工作区约定直接实施、独立复核后发布并更新安装包记忆。
