# Win AI 独立浏览器入口

用户要求网站优先：任何普通浏览器可进入、注册及登录，其次才是行舟软件内嵌；品牌确认沿用 Win AI。基线网站0.2.1、客户端2.8.47。已有内嵌交接有效，独立浏览器账号入口遗漏，不能称网站完整。

继续使用同一 app_users 身份和 UUID OAuth 关联。网页已有账号登录复用行舟密码验证，新用户邮箱验证注册不需行舟邀请码，roles为空、非管理员/制片人，不自动获得影视工作权限。新增服务端限制无工作角色的账号使用影视功能，仍允许 session/logout/profile/unlock/win-ai-entry。密码不复制到原生网关。网页登录只发 Secure HttpOnly 身份 Cookie，来源 token 不进入页面存储、URL或响应。退出撤销本次来源 session，保持其他设备。

新增登录/注册/找回页及同源 JSON 端点，接已有 SMTP。原生管理登录保留 /sign-in?admin=1；普通 /sign-in 转 /login。明确零额度、没有上游时不能调用。源站/商户价格不覆盖。输入大小、Origin、频率受限；注册及验证码消费必须原子提交。

公网连接与账号功能分别验收：本机直连域名 TLS 当前失败、服务器内部正常。备案当前未核实，用户先答未完成后更正可能完成；腾讯云控制台要求登录，工信部页面未成功返回。禁止将连接失败当备案结果，或将拥有者 SSH 通道当公网验收。不能擅自迁云、购资源或替用户提交备案。未通过外网验收前，继续明确限制。

本次只更新网站/云后端，不改桌面安装包。页面及真实临时用户验证、完整测试、独立复核后发布网站0.3.0，并更新交接及软件更新记忆中的网站状态。网站更新无需软件重装。
