# 2.4.19 美术清单核实

## 数据与生成

- 保留完整内置美术清单 v5 Skill；在正常按集清单之后增加逐场名称对应表，不改变清单中的详细描述。
- 候选清单、场次原文、人工修改、移除记录、核实签名和发布快照独立保存。历史清单只有集级关系时先列入未定位条目，避免把一集的全部造型错误挂到所有场景。
- 全剧初次分析继续处理后续分集，不等待人工确认。补齐指定集时只读取前集已核实清单、当前集正文和人工改动，不带入前集正文或未来集。
- 新候选结果不调用旧资产自动发布接口。发布以明确的人工核实为前提；旧卡片、ID、图片和人工描述保留，替换时更新场景与集级关联。
- 共用 `analysis_progress[集号].review` 保存云端版本；新检查点使用独立目录 `art-review-checkpoints`，按账号和项目隔离。保存与发布使用版本检查及请求编号；离线修改先落盘，重试同步不调用模型。
- 场景绑定参与分镜自动参考选择。历史未核实集仍可使用旧资产；已移出全部场景的资产从活动资产总览移到历史查看入口。

## 使用

1. 信息读取中运行分析，随后打开美术清单核实。
2. 选择分集，向下滚动逐场核实名称与状态。改名、补充后，按修改重新生成本集补齐完整描述；也可直接沿用已有条目。
3. 核实本场或整集，再发布到美术和资产；也可一次发布全部已核实部分。未定位条目需要安排到场景或移除。
4. 候选保存和云端同步不会自动生成图片；图片仍从美术与资产原有入口生成。

最终全量测试、安装包运行时与发布清单核验在发布完成后追加。
