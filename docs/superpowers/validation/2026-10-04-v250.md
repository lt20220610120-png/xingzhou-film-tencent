# 行舟影视 2.5.0 验证记录

## 实现范围

- 每集持续名单、逐场多对多关联；首次输出缺对应时自动补齐，历史当前集自动定位。
- 手工名单与单条细节生成、换模型只补缺；第一版描述与人工核实优先，后续版本留供美术选择。
- 单向发布，场景补充进入名单，下游新增不回流。
- 场景目录导出与导入、当前场景视频/分镜挂载、当前条目删除保留、旧集目录兼容。

## 已运行验证

- 基线 1150 项测试通过；本次中间全量 1161 项测试、13 suites 通过。
- 最新功能联合测试 58 项通过：名单复用、删除撤销、首次描述保留、补单卡并定位、显式关联优先、缺对应/无效对应自动修复、云端名单验证、真实临时目录导出导入、共享图片、多场去重、未关联隔离、旧目录兼容、当前条目排除、上传媒体按场。
- 正式前端构建成功。保留既有 chunk 大小提示，无构建错误。
- 真实 Edge 浏览器使用模拟 API 验收：持续名单、多场选择、名单移除撤销、单卡补齐定位、改服装、场景补道具、换模型式补缺流程、核实整集/批量发布、刷新持久化、美术卡片、场景导出桥接参数、历史卡片隔离。
- 1280×900 页面无横向溢出，剧本自然高度 572/466 像素，外层页面可滚动。
- 视频/分镜真实 React 页面验收：整部场景目录导入、换场素材隔离、音频场号过滤、单条移除及重开、分镜按场首次挂载、手工分镜保存。无 pageerror。

## 实现裁定

- 在现有 schema 1 追加 roster、manualSceneIds 和备选描述，旧版记录仍兼容，避免迁移现有图片和资产 ID。
- 手工在美术/资产增加且没有核实关联的图片按「未关联素材」导出，不猜测场号；分镜可手工选择。
- 模型第一次定位只允许名单中的名称，未知名称或缺 assets 数组不能算作完整对应；自动短请求补齐，保留原稿与已返回结果。
