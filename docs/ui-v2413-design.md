# 2.4.13 制片与导演工作台视觉方案

本次改动服务于两个真实工作动作：在导演工作台比较场景原文与提示词，在项目协作中设定画风并提取美术资产。保留行舟的清爽冷色基调，让配置、文本和保存状态各有固定位置。

## 视觉参数

- 墨蓝 `#20364D`：标题和正文；青蓝 `#247E94`：分析操作和焦点。
- 冷白 `#FFFFFF`：文本纸面；雾蓝 `#F2F6FA`：配置背景。
- 蓝灰 `#DCE5EE`：结构分隔；灰蓝 `#66798E`：次级说明。
- 界面使用本机 Microsoft YaHei / PingFang SC，标题 16px、标签 12px、说明 12px；剧本文字 15px，行高 1.85。长中文文字保持左对齐，不加载网络字体。

## 布局

导演页的整本操作栏独立保存最高时长和并发数量；下方场景导航不占据正文两栏的高度。原文与提示词始终共享同一行高，工具栏固定在栏内，正文各自滚动。

```
整本提示词说明             最高时长 | 场景并发 | 一键生成
场景 1-1   场景 1-2   场景 1-3
┌ 原文 / 分段设置 ────────┬ 提示词 / 定位 ──────────┐
│ 原文与分段进度          │ 已保存结果               │
│ 独立滚动                │ 独立滚动                 │
└ 自动保存说明 ───────────┴ 已保存说明 ──────────────┘
```

协作信息页将左侧改为完整的“美术配置”架：画风、题材、分析模型为一组；内置 Skill 用简洁的规则签章；开始/停止与导出为一组；同步和核对状态在末尾。右侧完整剧本有独立的保存栏。

```
┌ 美术配置 ───────────────┐ ┌ 完整剧本       保存剧本 ┐
│ AI真人 | 3D动漫 | 2D动漫│ │                         │
│ 题材                    │ │ 原文编辑纸面            │
│ 分析模型                │ │                         │
│ 内置美术清单规则        │ │                         │
│ 分析 / 导出 / 进度      │ │                         │
└────────────────────────┘ └─────────────────────────┘
```

## 对照需求后的修订

放弃通用的多张圆角卡片与装饰渐变，配置区仅保留一个外框，用分隔线表达设置、规则和执行三个不同职责。放弃原来的米黄虚线 Skill 提示框；它是稳定规则，采用紧凑签章。导演页不再由原文长度决定外框高度，空结果、错误、草稿和完成状态都使用相同的两栏尺寸。

界面不对时长或成功率作保证；建议时长仍来自生成规则。整本并发默认“全部场景”，实际请求量和恢复记录以任务快照为准。

## 验证要求

检查桌面宽屏与窄屏、空提示词、生成进度、错误、长草稿、长提示词的两栏底部；检查整本与单场时长可以分别修改，并发数量进入任务预览及保存快照；检查协作配置的完整中文、键盘焦点、模型名称和所有原有按钮仍可操作。
