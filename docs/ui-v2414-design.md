# 导演工作台顶部视觉方案 2.4.14

## 方案

页面的主任务是选择场景并制作提示词。采用片场工作台的配置秩序：模式、项目拍摄设定、整本调度、场景导航各占一行；编辑双栏保持等高，配置区不夺走剧本阅读面积。

- 色彩：纸白 `#ffffff`、冷灰底 `#f5f8fc`、墨蓝文字 `#20364d`、青蓝选中态 `#247e94`、细边线 `#dce5ee`、琥珀错误提示 `#9a5b16`。
- 字体：已有 Microsoft YaHei / PingFang SC；正文 13–15 px，配置说明 11–12 px，按钮 13 px。避免增加字体下载及装饰性标题。
- 模式栏：集名独立小标题；左侧三个等高模式按钮，右侧刷新云端和添加到 AI 对话均为 40 px 高，单行不折字。
- 云端通知：独立横向区域。同步冲突用中文说明、琥珀提示，原始调用错误放可展开技术详情；保留本地草稿、权限与原有冲突解决流程。
- 拍摄设定：模型与项目设定组成同一白色配置框；风格、画幅为分段矩形选择组，选中态青蓝底。信息按左右对齐，说明在配置框底部，不混入按钮行。
- 整本调度：标题说明左对齐，时长、并发、生成按钮同基线，控件 40 px；窄屏切整组行，避免逐字折行。
- 场景导航：使用能直接识别片场的横向标签带，编号加单行内容概要；长列表横滚，减少单场景也出现宽大空白框的情况。

```text
导演项目 · 第 1 集
[创造模式][快速模式][历史提示词]         [刷新云端][添加到 AI 对话]
（需要时：中文云端通知 / 技术详情）
┌ 本集提示词模型 [模型] ─ 项目设定 [风格组] [画幅组] ┐
└ 运行 Skill 时优先读取项目风格和画幅。              ┘
整本提示词 / 保存与继续说明    时长[30秒] 并发[全部] [一键生成]
本集场景  [1-1 / 简介] [1-2 / 简介] ...
┌ 场景剧本与控制 ┐              ┌ 提示词结果 ┐
└───────────────┘              └────────────┘
```

## 实施前审视

原方案沿用大圆角卡片和胶囊按钮，使短配置也像独立大面板，错误混入模式组挤压按钮。改为工作台的操作行、配置框及横向场景带，保留已有冷白色与青蓝色以接续 2.4.13；仅选中控件使用强调色。标题不加宣传语，导航编号来自实际集场编号。所有按钮保持明确功能，不添加无用统计与渐变。

旧风格值“真人电影集”只在显示和新的生成前置声明中映射为“真人电影级”，不批量改存储，避免旧付费草稿哈希失效。

## 验收

使用隔离 Electron 模拟项目验证宽屏、窄屏、长云端错误：顶部同一操作行按钮高度一致，错误独立且可以查看原始详情；时长与并发控件等高；无横向页面溢出；左右编辑栏底部保持一致；旧电影风格选中状态保留。模拟调用不发起真实整本付费生成。
