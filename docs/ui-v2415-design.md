# 2.4.15 白色工作面与紫色交互视觉方案

用户最终确认以 2.4.12 截图的通透白底、清晰黑体正文为基准。紫色仅用于卡片选中、按钮和少量标记，不把工作区、正文和全部灰色染成薰衣草紫。

## 规范

- 工作背景 `#f7f9fc`，内容表面 `#ffffff`：保留通透白色阅读体验。
- 正文 `#232b38`，辅助文字 `#647084`：清晰的深色黑体与中性灰。
- 线条 `#e1e6ee`，次级表面 `#f7f8fb`：以灰白区分区域。
- 品牌紫 `#7563bf`，强调字 `#5c4a96`：用于操作和选中标记。
- 主要动作渐变 `#705bbd → #7965b9`；普通选择渐变 `#e9e2f8 → #f6f3fc`；选中场景 `#f0eafa → #ffffff`，配细紫色边线。
- 主导航保持用户认可的浅紫至近白渐变，分集栏保持原有更浅的灰白底。主要白色工作面不加紫色渐变。

采用 Segoe UI / Microsoft YaHei / PingFang SC。正文保持原来 15px 与 1.8 行高，不增加轻细字重。标题左对齐、成组按钮同高，编辑区与结果区维持等高布局。白色卡片用细边线、轻阴影建立层次，不做重色底。成功/错误/警告保留语义区分。

```
浅紫主导航 | 浅灰白分集 | 轻紫选项                  白色辅助按钮
           |            | 白色模型配置区
           |            | 白色整本设置 / 白色场景卡片
           |            | 白色剧本区       白色提示词区
```

第一版将背景、正文和滚动条都改成紫灰，用户明确指出不符合原有白底阅读体验，已撤回该方向。最终以用户的新截图约束视觉设计：紫色是交互强调，白色与深色黑体是整个软件的基础。

统一导演工作台、项目协作、图视生成、Skill 库、API、设置、管理后台外壳、聊天与登录/角色选择的交互色。用户图片、视频、画布内容与独立 WorkBuddy 服务页面不重着色。通过隔离副本检查页面、选中/悬停/焦点和窄屏；本次不发起付费生成。
