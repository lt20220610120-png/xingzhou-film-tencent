## 根因与处理

添加集数原来拼接“第 22 集”后重新解析，旧规则不匹配带空格的编号；显式括号标题模式还会忽略追加的普通标题。新操作直接追加固定 ID 的分集，保留旧分集对象与成果，同时写入兼容的总剧本标题。磁盘保存失败后重试复用已添加 ID，仅再次保存，不重复追加；期间新增的成果也保留。序章不计入下一集编号。保存完成校验账号和项目作用域。

生成弹窗原来一直等待整本异步任务结束。现在确认后立即收起，原控制器继续运行，入口跟随任务状态，重新打开读取正在执行的进度。

截图中的工作区错误是 localStorage 的 QuotaExceededError，报错键为面板偏好 xz-director-pane，而不是剧本本身。启动时仅为明确允许的小型界面偏好安装容量错误防护，最多 64 Ki 字符，在本次运行内保存；生成回包、草稿、运行检查点等数据键不吞掉保存错误。保留 2.8.23 的生成回包文件落盘与旧数据迁移，不清空用户 Local Storage 或备份。存储已满时本次偏好可能无法跨重启记忆。

登录浏览器原来允许加载扩展，连接失败回退可能附着任意页面，包括第三方欢迎页。现禁用独立浏览器扩展，仅选择服务或明确的官方认证来源；保留原认证目标，刷新传输不重载或关闭用户验证页。本机只读检查独立 ChatGPT Profile 的扩展列表为 0，因此不能仅凭截图宣称已经确证用户那次 AdGuard 跳转的唯一根因。测试覆盖模拟第三方标签、官方认证标签与重新连接；未替用户实际完成网站人工验证。

更新缓存整理只处理 updates 根目录内匹配软件命名的普通文件；不递归、不跟随符号链接。保留最新两份完整安装包及指定活动安装包，旧碎片七天后清理，其他项目文件与备份保留。
