# 已有提示词与图片独立关联

2026-10-21 · 2.8.57-private.2 本机试用。修正上一版难退出、字色不清和逐条操作负担。

适用：已经生成好的整本提示词，以及已经按集/场景导出的美术图片。无需重新生成提示词、重做美术清单或重新出图。

## 操作

1. 打开图视生成的“整本提示词与素材”，点击“上传提示词并先关联图片”。已有导入项目可点“先关联现有提示词与图片”。
2. 上传包含 `【集数-场景-条目】` 编号的 TXT 或 DOCX。选择“导入整部素材文件夹”“导入本集文件夹”，或者“上传本集图片”。
3. 选择关联模型，点击 **“AI 自动整理整本”**。AI 先按场景整理素材身份，同一图片在本轮只处理一次，再连续处理每条提示词。默认不需要逐场或逐条点确认。
4. AI 明确且通过原文、类别、图片和引用校验的条目自动就绪；处理结束自动回到生成页。缺图片、身份不清或 AI 不确定的项目保留在“待处理”，不会自动生成视频。
5. 需要时点“查看待处理项”，再点具体条目展开处理。正常条目不要求打开长表单；详细素材、原提示词和手动调整默认折叠。
6. **随时可点“返回原编辑模式”**，立即关闭整理面板，恢复原提示词编辑框和素材。AI 正在运行时会停止，保留已完成进度；晚到结果不会把页面再切回去。不删除提示词或图片。
7. 要继续整理可从原编辑页重新打开。已经就绪且来源没有变化的条目跳过，修改过的提示词重新核对。生成接口、模型、时长等仍在原生成页设置，付费视频仍由用户点击生成。

详细区保留旧的本场身份核对、本条 AI、人工确认等工具，作为有疑问时的处理方式。

建议目录：

```text
剧名/
  第1集/
    场景1-1/
      人物/
      场景/
      道具/
    场景1-2/
  第2集/
```

“人物/角色、场景、道具”子目录可提供分类线索；没有分类目录的旧导出也可导入。只有集级目录时，该集图片作为候选，需人工核对使用范围。无法识别的集目录、集号冲突场景目录、未关联素材目录会提示跳过，不应把提示当作导入完成无遗漏。

## 文字判断与看图判断

关联模型可选行舟已连接的文字 API 或本机 Codex。现有本机 Codex 桥接执行文字判断：会读提示词和素材身份描述，不把图片内容已核验当作事实。

勾选“发送本场图片给支持看图的 API”时，使用支持图片输入的 Chat Completions 接口。每场最多 24 张；发送缩略图并用素材 ID 标记，参与身份与逐条关联两次任务。接口是否支持看图由所选服务商和模型决定；当前不将图片输入转接到 Responses、Anthropic 或网页账号连接。

AI 返回结构化选择及“明确/不确定”的判断。系统检查原文依据、类别、候选 ID、完整性和人工锁定；明确且校验通过的关联自动就绪，不能把格式有效等同于语义一定准确。收到不合格答案后最多修正两次；网络错误不自动重复该请求。整本处理中，疑问条目保留，其他条目继续；可停止，已完成进度保存。测试使用模拟接口，没有代表用户调用付费 AI 或视频模型。

## “张三的杯子”如何处理

- 类别：道具。
- 主体名称：杯子，或者“杯子（张三所有）”。
- 说明：所有者张三、外观、当前持有者等。
- 人物张三保持独立图片身份。

分类与图片身份是决定关联的字段，不能仅因为文件名包含“张三”就把杯子当作人物。多套妆造各自保留，名称相同不会自动全选。

## 为后续自动化保留什么

本机项目保留素材身份、AI 建议、人工锁定后的最终选择、原文范围、用途、理由、确认时间、来源签名，以及是否在该次 AI 判断中发送了图片。进入生成时另保存按账号隔离的确认快照；生成前重新核对，并验证本地图片文件内容与导入时的 SHA256 一致。

生图前清单联动和生图后独立关联共用 `promptArtBinding` 的需求提取、AI 答案验证、确认检查与引用编译。因此，锁定保留、错误分类阻止、依据完整性等改进可同时用于两条路线。

这些是可复盘的项目经验记录，不是自动训练完成的模型，也不会自动推广成其他剧目的规则。跨项目经验库、评估集、完整全自动队列、Topaz 超分和剪辑联动仍是后续工作。

## 当前边界

- 仅本机试用，保留旧导入方式，不发布到公共更新通道。
- 视频引用聚焦图片；导入音频和视频仍保留在旧流程，但不会由此独立图片关联步骤自动选取。
- 图片关联准确性仍需用户实际剧目验证，不能承诺模型生成的视频一定遵循参考图。
- 旧编辑模式的名称匹配也改为保守处理：无类别图片不再把“刘娜-杯子”“刘娜-文件夹”的后缀截掉后当作人物。已经存在的手工引用不会擅自清除；可用 AI 整理或手动纠正。
- 同编号重复提示词、已有手工 `@` 引用、多图歧义及缺失素材需处理后才能确认；可在关联页查看和修正原提示词。
- 已确认只说明该条可以进入生成，并不自动提交付费任务。
