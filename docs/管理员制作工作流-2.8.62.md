# 管理员制作工作流 2.8.62

管理后台的“制作工作流总控”现在可以直接导入剧本。已经带有 `【集数-场景-条目】` 编号的提示词会立即建立整本提示词项目；普通剧本会交给当前选定的 AI 生成同样格式的提示词，再保存回图视生成的数据，保留原始文件名和自动生成标记。管理员仍可打开导演工作台检查分集、场景和条目数量。

创建工作流时可以选择半自动或全自动、视频模型、画幅、默认时长、分辨率、配乐/字幕/尾帧/导出规则，并填写本机 Topaz 与 OpenFilm/CodeDance 入口。视频任务仍按条目持久化、下载校验并按“项目/原始素材/第 N 集”归档；一集齐全时生成 `本集处理清单.json`，同时建立 `超分素材/第 N 集` 和 `成片` 目录。清单会记录超分与剪辑适配器路径，供后续规则模板消费。

当前版本已经把剧本导入和后期交接信息纳入总控，但 Topaz 实际命令参数、OpenFilm/CodeDance 的剪辑模板、音乐情绪切换、字幕和尾帧规则仍需按本机软件版本补充后接入执行器。没有配置适配器时，系统只归档并生成清单，不会猜测或启动外部程序。
