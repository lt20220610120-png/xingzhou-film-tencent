# 管理员制作工作流 2.8.63

2.8.63 将总控面板改为启动前配置与预跑模式。管理员在开始任务前选择 Agent、项目范围、视觉风格、画幅、单条时长、视频渠道与模型、生图优先/回退渠道、输出目录、超分目标和 OpenFilm/CodeDance 模板；未完成预跑检查时不能启动。

预跑只检查配置和依赖，不提交图片或视频任务。保存预设与开始执行分开，开始后仍可暂停、继续、重试受影响条目。Agent 按用户锁定的规则处理提示词、素材关联、生成、下载和分集交接；人物、道具、场景的主体分类与每条提示词的实际使用范围属于自动检查内容。

本版仍不宣称 Topaz 和 OpenFilm 已经接入实际命令。需要这些软件真正自动执行时，应在适配器规则确定后增加执行器和模拟接口测试。视频生成渠道必须由管理员在面板中选择，不能用默认渠道代替。
