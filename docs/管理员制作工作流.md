# 管理员制作工作流

2026-10-22，2.8.61。按用户要求取消私有版本号，使用普通安装包；新增能力通过管理员权限控制。

## 使用入口

管理后台 → 制作工作流总控。先在导演台准备提示词、项目协作生成美术，或直接在图视生成导入已有提示词与图片。原编辑模式与逐条 AI 关联保留。

选择项目和模式、AI / Agent 接口、已配置的视频模型、默认参数与输出目录，展开后期交接规则可填写配乐、字幕、尾帧、导出版本。半自动须核对提示词与图片选择后勾选。创建只是保存项目快照；点击开始后会调用 AI 和视频接口、可能产生费用。

- 半自动：保留人工选图，AI 按名称与提示词检查，明确项进入生成。疑问最多返回修正两次，仍未通过则只拦截该条。
- 全自动接续：对已备提示词按条整理本场图片身份、选图与确认，明确项进入生成。当前使用文字判断；需要视觉检查时回关联页面选择支持看图的 API。
- 工作流以创建时项目快照运行。生成模型配置按 ID 读取当前配置，API 密钥不复制进任务清单。源文/素材需要调整时，先暂停；当前版不自动合并原项目后来编辑，不能把重查当作重新导入。
- 切换页面继续运行。退出/切换账号、管理员身份失效或资料目录变化暂停；关闭软件后重新启动不会自动开始付费任务，需要继续。
- 已提交项只查询原任务。失败或提交不明不自动重发；生成前拦截的条目可重新检查。该按钮不会重新提交未知付费任务。

## 目录与逐集交接

输出根目录/剧名-工作流短编号/原始素材/第N集/序号-集场条-身份.mp4；保留原扩展名。超分素材/第N集与成片目录同时准备，避免覆盖另一轮输出。

每集所有预期条目均下载、文件非空、复制 SHA256 一致，才写出“本集处理清单.json”。清单按顺序记录 entryId、集场条、文件路径、摘要、输出目录与后期规则。不会用文件数量或临时 .partial 文件判断集完成。第一集完成即交接，不等后面各集。

后期目标是横屏1920×1080或竖屏1080×1920，不用固定2倍/4倍冒充1080。Topaz与剪辑执行器目前未接入，目录存在不表示超分或剪辑完成。

## 上层架构与接入边界

1. 管理员控制面板：配置、创建快照、控制运行、查看集/条状态，保持传统工作台入口。
2. 主进程工作流引擎：按账号持久化、逐条状态机、有限 AI 修正、任务日志与原结果恢复。付费提交前持久化 submitting，已有任务按 workflowRunId/itemId 重新关联。
3. 复用现有 AI 和视频适配：既有 Codex/文字 API 通过 text-provider，视频通过 generation-jobs，保留原引用核对/账号验证/上游状态查询。不会另建盲点按钮机器人。
4. 逐集产物交接：原片→1080素材→剪辑成片。当前接通原片，后续适配必须以清单中的预期条目和输出验收回执确认，不按“文件夹非空”跳步。
5. 后续 Topaz 执行器须确认安装版本、可用调用方式、分辨率检测、失败重试和资源限制；剪辑执行器须接 OpenFilm 实际接口、情绪配乐、字幕与尾帧模板、多版本输出规则。未验证接口前不运行猜测命令。
6. 从整份剧本全自动生成提示词/美术的前置执行器尚未接入总控；现有工作台已有能力可手动完成，再接续本版队列。界面不宣称这部分已自动化。

## 权限与状态

前端管理员导航/面板限制；主进程每个工作流入口、AI关联读写/图片输入及后台任务执行都检查服务器返回的当前管理员身份与令牌稳定性。旧设备 private 标记不能授予权限。输出与运行记录按账号隔离。

后续可增加受控的执行适配接口与管理员授权范围；不得只靠隐藏按钮对全用户放开功能。当前没有自动发布作品。
