## 软件中做什么，会用到什么费用

| 使用动作 | 实际经过的服务 | 费用和本次处理 |
|---|---|---|
| 在本机编辑剧本、提示词、切换本地文件夹 | 本机磁盘与内存 | 本身不产生腾讯云流量；需要同步到云端时才访问服务器 |
| 登录、查看协作项目、聊天、刷新剧本与分集 | 轻量服务器上的接口和数据库 | 消耗服务器套餐流量。未修改文档现在只返回简短确认，仍检查权限 |
| 浏览协作素材图片、图片历史、参考图选择器 | 原先常常直接加载 COS 原图 | 新版优先从服务器获取 640 像素以内预览；服务器通过同地域内网读取 COS，缓存后复用 |
| 点开素材大图、下载/导出原图 | COS 原图、本机原图缓存 | 保持原画质；命中本机缓存可复用。首次或缓存失效后的公网原图读取仍可能产生 COS 下行费用 |
| 上传图片等素材到云端 | COS 上传、存储、写请求 | 普通上传流量不收费；存储和请求属于独立计费项，是否抵扣看额度。并不是“上传永远完全免费” |
| 点击 AI 分析、生图、视频生成 | 所配置的模型服务商 | 模型服务商按其规则收生成费用，与腾讯云 COS 账单分开；模型从 COS 读取参考原图还可能产生 COS 下行 |
| 查看已下载到本机的生成结果 | 本机文件 | 本地读取不产生 COS 下行；从远程服务商重新下载时按该服务规则处理 |
| 软件内下载更新安装包 | GitHub 更新仓库 | 当前安装包未存放在这个 COS 桶，此桶的图片流量不应算作更新包下载费用 |

腾讯云区分公网下行、内网传输、存储、请求等计费项。同地域内网传输不收 COS 流量费，仍可能有请求费；这是本次方案使用已有服务器的依据。[腾讯云 COS 流量说明](https://intl.cloud.tencent.com/zh/document/product/436/33776)

## 已执行的优化

1. **云端轻量预览**：服务器 DNS 实测将 COS 桶域名解析到内网地址 `169.254.0.47`。用内网预生成当前引用的 367 张图片的预览，成功 367 张、失败 0 张。原图约 481.34 MiB，预览约 9.26 MiB，预览文件体积减少约 **98.08%**。原图没有覆盖、降质或删除。
2. **分离预览与原图**：列表用预览；点击大图、下载和 AI 引用走原图。预览不被写回模型参考地址。预览生成失败或过于繁忙时回退原图，优先保证可用性。
3. **取消无效的图片重复加载**：COS 临时签名变化不再被当成新图片；真正替换图片时会重新加载。仍保留可见区域加载和本机原图缓存。
   同时新增本机预览缓存（128 MiB、30 天未使用可清理），重启软件也可复用；每次先检查账号及项目权限，命中缓存后不再传预览内容。缓存按账号和对象区分，损坏时重新获取。它与原图缓存分开，不会用缩略图代替导出或模型参考。
4. **减少重复的剧本传输**：本地导演源内容没改时不再定时重复提交整份文档。项目读取每次仍访问后端验证权限和最新内容；内容没变时只传确认，有变动就传完整新内容。
5. **本地流量诊断**：启用服务器每分钟接口请求数及字节数汇总，方便后续追踪接口流量；不记录提示词、用户内容或密钥，不购买额外日志服务。
6. **部署和回滚准备**：原后端文件、环境配置和依赖均有服务器端备份；新预览只存可再生缓存，默认上限约 256 MiB。未修改业务数据库结构。

这不是把所有原图强行转发到 3 Mbps 的服务器。原图生成参考和下载路径保留，避免为了省 COS 钱而拖慢大文件处理。小预览会消耗服务器已有流量包；超出服务器套餐依然可能收费。

## 为什么其他网站能运营

访问和下载确实会消耗资源，但“小网页浏览一次”和“多次下载几 MB 原图”用量差别很大。网站通常通过浏览器缓存、缩略图、服务器流量套餐、CDN 合约等降低每次访问的成本，再以付费用户、广告或主营业务收入覆盖成本。免费访问只是访问者没有单独付钱，并不是运营者没有成本。

本次处理的核心就是减少重复搬运，先使用已付费的套餐能力。**不能承诺从此零日结费用**：原图读取、云存储和请求仍可能计费，AI 生成也有独立成本。截图中的 8.11 元是过去一天的结算，新版不能撤销；更新当天次日仍可能结算更新前产生的流量。预览文件缩小 98% 也不能直接换算成整张账单降低 98%。

建议所有正在使用的客户端更新到 2.4.1，随后看 9 月 22 日起完整使用日对应的 COS 下行用量（通常次日账单显示），并同时看服务器套餐剩余额度。无需停掉协作、生图、视频或下载功能。
