# 超创制作工作流 · 2.8.88 管理员试用

入口：管理后台 → 制作工作流总控 → 开工设置。全自动上传完整剧本或接续导演项目；半自动接续已经核对并发布关联的导演/协作项目。

## 开工时必须选定

| 范围 | 设置 |
| --- | --- |
| 总控 | 制作 Agent 连接组件、协议、模型；项目输出目录；最终交付到原片、超分或成片 |
| 导演 | 风格、画幅、最高分段时长、提示词模型、导演 Skill |
| 美术 | 画风、人物构图、分析模型、生图主备模型、每模型最多尝试次数、画幅、并发 |
| 视频 | 渠道/模型、画幅、每条时长、分辨率、并发 |
| 超分 | Topaz 路径、2 倍或 4 倍；默认 Proteus；保持实际倍率，不把 480p×4 等同 1080p |
| 剪辑 | OpenFilm 路径、剪辑 Agent/模型、逐集通用剪辑指令；音乐和音效目录可选 |

半自动跳过导演和美术生成，必须勾选人工核对。每条视频提交前仍由制作 Agent 检查提示词和参考素材名称；这不等同对图片像素内容的视觉验收。

## 系统自行执行

1. 复用导演快速模式的整本任务、自动分段、原有成功结果与检查点；按场检查覆盖。
2. 找到/创建协作项目，同步最新导演源；连续分析、描述、场景关联、提示词分发；Agent 逐场审核并发布符合条件的整场。
3. 复用已生成图片；未完成资产按主备模型有限重试。超时/提交未知、内容拒绝、额度/凭据问题保留待处理。不会仅凭“涉及儿童”的猜测改变年龄或风格。
4. 从联动版本编译每条实际引用，保留人物/场景/道具身份；提交前再检查模型支持的参考数、时长等；未知任务先核对，不重复付费。
5. 下载的视频经过 ffprobe 验证后，按项目 → 原始素材 → 第 N 集归档；以完整预期提示词清单判断该集是否齐全。
6. Topaz 单队列按集超分，核对实际尺寸、时长与文件校验值；下一集超分可与前一集 OpenFilm 剪辑重叠。剪辑保持单队列。
7. OpenFilm 使用本机手册及独立集工作目录，Agent 实际产出 film.html 后调用原软件渲染。完成回执持久化。中断后发现已提交但未验收工程时转待核对，防止重复调用改写。

目录例：`项目名-运行编号/原始素材/第1集/1-1-1.mp4`、`超分素材/第1集/`、`剪辑工程/第1集/`、`成片/第1集.mp4`。运行编号用于隔离重复制作；集内按集场条编号组织。

## 视频池

项目协作 → 分镜下方的视频池。默认全剧，可按集和场筛选；每 5 秒监测，成功结果可按当前范围一键下载。下载会保留已有不同内容文件，错误逐条报告。美术身份不开放视频池；制片、协作及兼任身份可访问。

## 本版验证范围

- 单元/模拟测试覆盖双集交接、防重复开始、未知提交、缺场阻断、部分阶段续跑及按范围导出。
- 本机 Codex app-server 握手、模型列表和极小只读执行已验证；Topaz/OpenFilm 路径及组件预检已验证。
- 尚未完成真实整剧付费生成、Topaz 实际增强和 OpenFilm 实际成片的联合验收。ACP 适配仅提供协议入口，WorkBuddy 等产品须有相应兼容组件并另行实测。
- 软件关闭后自动任务暂停，重新打开后检查并继续；外部软件授权、模型下载、磁盘不足、Agent 交互授权等仍可能要求处理。
