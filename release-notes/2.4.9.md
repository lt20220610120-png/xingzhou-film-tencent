# 行舟影视 2.4.9

- 管理后台新增独立的“WorkBuddy 号池”页签，默认保留用户、邀请码与制片身份管理。
- 控制面板直接显示在行舟窗口内，自动发现本机部署并启动服务，可选择其他部署目录。
- 验证当前行舟管理员身份后直接进入面板，无需再次输入面板用户名与密码；普通用户及被停用管理员无法接入。退出、离开页面或身份失效后清理独立会话。
- 新增控制面板的 GitHub 更新入口：检查正式发布、确认安装、校验签名、显示进度，失败自动恢复旧代码。
- 更新保留账号、数据库、配置与现有 Windows Go 引擎；使用发布包内的预构建网页，无需手动构建前端。资料目录与代码目录冲突时拒绝更新并说明原因。
- 加强更新与页面打开的并发保护，避免重复更新和安装期间关闭软件；断连时显示原因并提供重试。
