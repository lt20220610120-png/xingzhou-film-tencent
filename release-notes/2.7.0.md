# 行舟影视 2.7.0

- 创作者空间的“果子库”入口更名为“成品库”，内设果子库与 IP 库。已有果子项目和处理流程继续保留，小说改编项目独立管理。
- 新增小说改编工作区：支持 TXT、Word（DOCX）及粘贴原文，识别章节；内置完整小说转剧本 V4 和故事梗概、人物小传 Skill，支持 60／120 分钟目标。
- 通读小说后生成可调整的主线、真实终点与分集规划。每集左侧显示对应章节完整原文，右侧编辑剧本；逐集转写前完整回读此前最新正文，再对照原文修订。
- Skill 初稿、修订稿、旧稿和手动编辑稿分别保留，支持查看、采用与明确删除。重新导入或调整章节保留旧来源关联；缩短规划时，旧尾集转入项目记录，可查看和恢复。
- 总稿与分集同步编辑；收录剧本库保存独立版本，后续修改不改变收录内容，可导出 Word／TXT，并从剧本库返回对应 IP 项目。未达到篇幅目标的收录版本标为阶段稿。
- 创作窗口优先使用 API 接口中配置的默认模型，直接选择已接入模型；增大目录文字，改善阅读。停止或失败保留已有稿件及可恢复的返回内容，修复中文 TXT 编码兼容问题。
- 缩小工作页黑色标题，保留清晰的目录层级；统一紫色渐变按钮、选中标记、圆角卡片、柔和阴影和悬停反馈，改善宽屏与较窄窗口的排版。
