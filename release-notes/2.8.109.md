## 制作工作流总控与 Agent 边界

- 全自动和半自动共用七项开工设置；半自动读取持久化成果，从实际缺项接续，不再要求先勾选“人工已核对”才能运行。
- 导演提示词下游只核对集、场、分段数量和生成缺项，按主模型尝试次数及有序备用模型补齐。提示词内容、台词时序、剧情、镜头连续性和文案质量不再由素材分发 Agent 重审。备用模型接续保留原分段计划和已付费提示词编号。
- 清单核实按每条提示词验证人物、场景、道具及启用时的音色关联；允许补卡、补描述、重新分发和发布。关闭音色时不读取或阻塞音色关联。
- 全部人物音色卡参与自动补全和样音生成；短样音会继续扩写试听台词，保留真实对白依据，优先采用达到三秒的第一条样音。
- 美术按人物、场景、道具顺序接续图片；单条参考素材齐备即可提交视频。视频下载后立即进入 Proteus 逐片超分，整集超分凭据齐备后进入剪辑。未知提交、暂停、重启和人工成果继续使用原有持久化保护。
- Codex 制作 Agent 任务统一附加固定职责边界，历史默认规则不能扩大审查范围。

验证：`npm test` 2656/2656；工作流、运行页、音色、音频和视频备用模型界面验证通过。
