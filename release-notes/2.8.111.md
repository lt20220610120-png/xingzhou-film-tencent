# 2.8.111

- 美术主备模型按设置尝试，耗尽后 Agent 只修复重试一轮；仍失败的图片记录为已跳过，后续自动化不再重复尝试。未知提交保留原任务查询，余额不足保留充值状态。
- 已跳过的缺图不阻塞视频，保留原提示词文字及其他人物、场景和道具参考图；实际发送和主进程校验共用跳过凭据。
- 模型参考图名额不足时，人物和场景全部能容纳则由程序直接优先保留，道具只使用剩余名额；人物场景自身超限时仍按镜头重点选图。舍弃图片后重新编号引用，保留对象文字。
- 生成任务列表支持完整备份后恢复有效数组末尾的损坏残留，避免 JSON 解析故障阻断原任务查询、下载和自动化；不把损坏记录当空表。

验证：2666 项测试和生产构建通过；生成验证使用模拟接口。
