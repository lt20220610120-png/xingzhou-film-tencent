# 2.8.112

- 管理员对话指令作为当前工作要求保存，优先于默认流程与历史经验，并传入制作及剪辑Agent。不能只口头承诺而不执行动作。
- 支持只做指定集到归档、超分或剪辑交付后暂停；执行范围持久化，继续或重启仍沿用，明确取消限制后恢复全剧。
- 并发队列及付费提交前重新核对最新范围；素材准备期间改变指令也可拦截尚未付费的提交。已提交任务保留，范围外任务由独立后台继续查询下载。
- 制作Agent连接、模型及目标可收起。运行页模型选择移到账号区域，从本机Agent读取，与开工设置共用任务中的制作模型；剪辑模型保留独立配置。

验证：2671项测试、生产构建及1280/1700/2232三宽界面验证通过。付费提交使用模拟接口验证。
