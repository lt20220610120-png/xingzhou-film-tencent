# 2.8.113

- 移除“第一集”的专门解析和固定范围展示，不再从旧对话自动提取测试指令作为制作范围。临时要求只作用当前任务，不写入以后任务的默认流程。
- 制作对话接通本机 Codex 的真实后端工具调用：读取项目/素材/关联/视频任务，原任务查询下载归档，暂停/继续，动态调整或解除本次范围，修改当前任务设置，运行制作工序。Agent按最新用户要求调用工具并获得执行回执。
- 固定流程和历史经验作为默认工作方法；最新用户指令优先。前若干集、任意集数组或其他安排由Agent动态理解，用户可随时改变，明确保存默认流程时才变为默认经验。
- 暂停状态仍可归档已成功视频；已完成任务收到新的制作安排可重开接续，保留原付费记录。未知操作不假报已完成。

验证：2675项测试、三宽UI、生产构建。真实本机Codex一次只读动态工具探针成功，付费视频动作0。
