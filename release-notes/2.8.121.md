# 行舟影视 2.8.121

本版修复制作工作流中的 Agent 模型发现，让行舟影视读取与本机 Agent 当前实际配置一致的模型目录。

- Hermes 连接会跟随 Hermes Desktop 当前启用的资料档，不再继承错误的默认 `HERMES_HOME`。本机实测进入 `w` 资料档，读取到 WorkBuddy 的 61 个模型，包括 `auto`、`hy4-preview`、`glm-5.3`、`kimi-k3-1` 和当前默认的 `deepseek-v4.1-flash`。
- Codex 会分页读取完整模型目录并包含隐藏模型。本机实测读取到 10 个模型，包括更新后的 `gpt-6.1-sol`、`gpt-6-astra`、`gpt-6.1-terra` 和 `gpt-reserve`。
- 已保存的 Codex 安装路径如果属于行舟管理的旧版本目录，会自动切换到本机最新 Codex 二进制；用户手动选择的其他 Codex 路径仍保持原样。
- 重新连接 Agent 时，只要原模型仍在目录中就保留原选择，避免刷新连接后擅自切回默认模型。
