# 行舟影视 2.8.123

- 每个制作项目可打开独立原生窗口，同项目再次打开自动聚焦，关闭项目窗口后自动化继续运行。
- 对话支持模型与推理强度选择、标准权限/完全访问设置、图片视频和其他文件附件。
- 发送后原位显示方块，随时停止当前对话及排队指令。顶部暂停停止整个项目及本机 Agent、超分和渲染进程树。
- 无额外指令时自动推进默认全剧；优先某集的安排完成后自动接续未完成部分，已完成和取消的旧安排不会重新限制任务。
- Topaz 授权或模型错误交给所选协作 Agent 诊断，保留原片并退避自动复查，自动化保持运行。余额等待同样自动定时接续。
- 修复停止后快速继续时旧连接复活，以及执行范围改变后仍派发已排队剪辑的问题。
