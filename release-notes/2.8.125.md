# 行舟影视 2.8.125

本版修复本机现有 Topaz 视频界面无法被自动化正式调用的问题，并补齐真实出片与停止验收。

- 默认通过本机 Topaz 图形界面执行超分，自动创建只含当前原片的独立工程。兼容的 CLI 路径保留为可选项，产品不再要求更换官方版软件。
- 固定使用普罗透斯（Proteus）`prob-4`。开工设置可选择放大 2 倍或 4 倍，测试与正式任务使用同一套工程和参数构造。
- 每次输出必须核对目标尺寸、时长、原片音轨以及 Topaz `videoai` 中的 `Enhanced using prob-4` 元数据；缺少任何证据都不会登记为完成。
- Topaz 测试和正式任务使用项目隔离的取消请求。停止会结束本次 Topaz 进程树、删除未验收半成品并保留原片；主动停止测试按正常取消提示返回。
- Topaz 授权或模型错误继续交给当前协作 Agent 判断。需要用户处理登录、授权或模型时，自动化保持运行并低频复查，处理后从原片接续。
