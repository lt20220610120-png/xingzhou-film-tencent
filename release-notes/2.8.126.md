# 行舟影视 2.8.126

- API 接口页新增“连接 / 刷新 Codex”。直接读取当前电脑 Codex 已登录的 ChatGPT 账号、额度窗口和完整模型目录，勾选后导入接口配置，无需 API Key。
- Codex 模型不再固定为旧选项。每次打开连接或点击刷新，重新读取本机最新 Codex 组件的模型目录，支持搜索、批量导入，以及各模型实际支持的推理档位。
- 已有 Codex 配置及默认模型保留；重复导入不会覆盖原有名称和推理设置。刷新失败时显示连接提示，已有配置继续保留。
- 重新设计账号入口、密码登录、注册和卡密激活界面，统一浅紫白视觉、表单层级和操作反馈。
- 重新设计软件更新提示，清晰展示新旧版本、更新内容、下载进度及安装状态，支持失败后重新检查。
- 点击“退出登录”先提示“是否确定退出登录？”。点击“确定退出”后才执行退出；取消或按 Esc 保持登录。
