# 行舟影视 2.8.127

- 启动卡密页改为独立的小窗口，只保留一个卡密输入框和“验证并激活”按钮；验证失败留在原处显示提示，不显示身份选择、账号切换或其他入口。
- 首次使用先通过设备卡密验证，再进入原有账号密码登录/注册。已激活电脑仍按原有设备授权规则校验；卡密、有效期、续期、单机绑定及管理员发卡规则保留。
- 导演或内容创作者权限由注册邀请码决定。通用注册入口不预设身份，同时兼容旧版明确选择身份的注册流程。
- 更新提示独立弹窗展示，支持右上角关闭、“下次再说”和“不再提醒此版本”；新版本仍可提醒，也可以在设置中手动检查更新。
- 更新下载可在关闭弹窗后继续，重新查看时可直接安装已下载的更新。
