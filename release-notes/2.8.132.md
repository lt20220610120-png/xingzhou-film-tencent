# 行舟影视 2.8.132

- 清单核实的分集、模型选择紧凑居中，已关联数量移到同一行，去掉重复流程说明；隐藏导演项目设定下的重复说明，保留设定与实际生成逻辑。
- 恢复清晰的场景清单 / 逐条提示词切换。有提示词时默认查看提示词，点击当前场景编号可返回场景核实；无提示词时按场景查看。
- 修复旧清单缺少对白读取结果时，未生成、未采用音色无法分发的问题。正常讲话人物依据原文先保留音色身份，按集、场景及本条对白关联，不把全场音色复制给每条提示词。
- 采用或更换样音直接补入已有身份，无需重新分发；分发过程中采用样音也不再误报人工修改。真实人物变更、正文变更与人工选择仍保留原校验。
- 将精简前端文案、保留必要标签、可访问性及操作后果提示写入长期开发约定。

升级后可点一次“补齐素材关联”修复旧的漏配。已有音色身份采用后自动接入；实际带音频生成、导出仍需已采用样音。
