# 2.8.135

- 音色改为单组具名卡片，移除重复“对白音色”区块；场景清单中的姓名不再被“待采用”状态挤掉。未生成或采用音频仍保留身份座位，采用后同一卡片可播放。
- 场景翻页移到中间，“场景清单 / 逐条提示词”靠右，增加图标和明确选中状态。
- 修复自动关联已完成却无法批量核实的问题：每条提示词只需核对实际使用的素材，不再要求覆盖整场所有卡片。已核实的完整场景可先发布，其余待处理项继续保留。
- 场景后续的门框、墙面、家具等补充描述不再误报成新场景；修复带逗号的括号说明截断道具名称，支持明确所有者与数量并列道具。明确缺卡或多造型歧义仍进入待处理，不强行匹配。
- 分镜先展示已经就绪的图片与音频，不再因另一条音色待采用而清空全部参考；采用后自动补入。保存待完成素材的预览保留原提示词。无导演提示词的场景与手工分镜沿用本场已就绪素材；实际提交继续核对来源与必要素材。
- LibTV 图片、视频及各生成入口共用当前项目，不再每次新建画布。当前项目按账号/个人团队空间分别保存，重启后继续复用；支持新建命名、连接官网画布链接或编号、切回已连接项目和打开画布。旧任务始终在原画布查询，换项目不重复提交旧生成。

更新后重启软件；已有清单打开核实分发会自动补关联，可再点“补齐素材关联”调用模型校准，处理待补项后批量核实并发布。LibTV 在生成参数或 API 设置中选择项目；新建画布本身不提交生成，生成按官网规则消耗积分。
