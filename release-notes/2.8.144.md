# 2.8.144

- 视频生成结果改为紧凑缩略卡片，中等窗口每行至少3个，大窗口显示更多结果。
- 视频池每条提示词只占一张等高卡片，显示已有结果数量；点击后查看多次生成记录。
- 下载默认选择每条提示词最新成功结果。支持全剧/本集/本场一键全选所有成功结果、恢复最新、同条结果单独勾选与批量下载；一次选择目录，按项目和集数归档。
- 长参数接口自动增加左侧提示词编辑高度，素材区底部与生成按钮对齐；保留手动拉高，避免重叠和素材框内大块空白。

- 分镜顶部拆分“应用到全场景”和“应用到全剧”，参数真实保存到所选范围所有分镜，切集、切场景、重开均保留。
- 生成中、待核对、失败与已完成的视频结果统一卡片尺寸。
- 视频池与分镜结果支持单条、当前筛选范围全部删除；所有删除都先确认。生成中的记录移除后原任务不重复提交，已提交任务不能在此撤回；确认框明确说明，保留本机文件。
