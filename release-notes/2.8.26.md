行舟影视 2.8.26

- 视频模型改为动态目录：拉取/刷新或手填的新型号保存后直接进入图视生成，不再仅认软件内置名单。支持批量导入时保存协议与完整能力；飞拓未内置的新型号可直接提交。
- API 编辑增加视频协议、参数与模型目录刷新。提供飞拓标准、火山方舟、Videos JSON/表单预设；特殊 HTTP JSON/multipart 上游可自行配置路径、鉴权和字段映射，不自动试探付费生成。
- 参数随型号读取；未声明的时长、分辨率可手填。手工覆盖与实际提交一致，切换型号重新选择参数；保留原有接口配置和图片功能。
- 通用视频任务保存 ID 后异步查询，重启可恢复。下载失败只重试下载/查询，支持直返地址恢复；更换服务商地址时保护旧任务密钥，复用历史不继承旧任务编号。
- 操作说明见 docs/video-self-service-2.8.26.md。专用 SDK、动态签名等非常规协议仍需额外适配。
