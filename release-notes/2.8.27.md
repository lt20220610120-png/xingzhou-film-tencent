行舟影视 2.8.27

- 接入 LibTV 官方账号授权：在 API 接口或图视生成的 API 设置中点击「连接 LibTV」，浏览器完成登录后读取可用图片和视频型号，无需填写旧 Access Key。
- 图视生成、协作分镜共用 LibTV 连接。按当前型号实时读取参数、生成模式及参考限制；仅提交当前提示词和选定素材。成功分镜视频按既有项目权限共享。
- 官方 CLI 首次按需下载并校验；登录凭据按行舟账号在本机隔离，系统加密封存。启动保护异常退出残留；更换账号/空间、资料目录迁移保护运行任务。
- LibTV 后台任务只触发一次生成，保留官方画布入口；下载失败或重启后查询/下载原节点，不自动重复扣积分。支持首帧、多参考、多结果 ZIP 下载与失败状态识别。
- 保留普通视频 API、自主接入和原有图片接口。操作说明见 docs/libtv-connection-2.8.27.md。
