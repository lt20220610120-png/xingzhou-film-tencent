# 行舟影视 2.8.34

- 新增AutoDL H3视频快捷接入，预置“多图多音频·升级画质”和“高速版”两个工作流。用户填写AutoDL官网ComfyUI分组Token即可在图视生成、项目协作分镜中选择使用。
- 按AutoDL官方协议原样Token鉴权、提交并保存任务ID，异步查询原任务并尽快下载视频结果；不会转发Token到视频结果域名，不以重复生成恢复网络或下载失败。
- 支持1–15秒、480p/768p、横屏/竖屏/方形画幅，最多9张参考图、3段参考音频，至少1张图，可选随机种子。参数、素材数量在上传和提交前验证。
- 本地参考沿用48小时临时上传和到期清理，补充FLAC、MP4音频导入与临时上传；只上传当前选中的素材，原文件保留。两个已核对工作流可直接载入，无需猜测模型目录接口。

本版视频生成验证采用模拟接口，未调用真实付费视频生成。
