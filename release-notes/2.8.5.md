# 行舟影视 2.8.5

- 大事件、小事件卡片底部的固定、移动、确认、删除、接口选择和 Agent 整理合并为同一排；卡片仍保持等高，长内容在卡片内滚动。
- 卡片标题可独立编辑，正文输入不再自动改写标题；主动调用 Agent 整理时仍可生成短标题。
- 设定改为左右布局：左侧按类别折叠现有内容，右侧固定保留补充编辑区。兼容 background、premise、rule、ability 等英文分类，去掉没有内容的空类别面板。
- 已采用设定可以删除；删除前的内容保存在设定历史。存在未处理冲突时先处理对应候选，避免留下失效引用。
- 新增“整段内容划分”：粘贴一段故事或多件事，由选定 Agent 拆成多张大事件卡片。结果先预览，采用后追加到已有卡片，不覆盖原稿。
- “从对标剧本添加”在当前页面打开多选窗口，支持搜索、全选和连续批量加入，可选择连同小事件导入；不再来回跳转页面。
- 候选审阅、导出、来源选择和创作表单的内容单独滚动，采用、确认、保存等操作留在固定底栏；浮窗保持可拖动。
- 灵感整理摘要已有内容时，左侧灵感步骤显示完成勾选；移除大事件页底部重复的主线跳转按钮。
- 小事件空白状态改为紧凑入口，检查接口与全剧检查按钮同行排列。
- 编辑器输入先在当前字段更新，草稿短暂缓冲后保存本地，取消每个编辑框的定时轮询；输入法组合输入结束后再提交。补充设定和整段故事草稿同时保存在本地项目文件。
- 保留 2.8.4 的会话加密、IPC 鉴权和签名更新验证。
