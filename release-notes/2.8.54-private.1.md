# 2.8.54-private.1 · 本机试用更新

- 清单核实新增可选“提示词联动美术”，读取已有导演提示词，提前确认逐条人物、场景、道具卡片用途；原按场景模式保留。
- AI 按本条原文与同场上下文核对，校验类别、卡片身份与原文依据；最多两轮修正，保留人工选择。
- 生图前可保存卡片用途，生图后选定具体图片；同一资产可供多条提示词使用。
- 图视生成的整本模式新增“从联动美术项目载入”，只发送本条已确认素材，按实际顺序编译引用。
- 提交前复核来源和选图；改词、换图、账号切换、尚未发布或未选图均不会沿用旧确认直接生成。
- 关联保存于本机资料目录，按账号和项目隔离。仅私人试用包启用，不更新公共下载或软件更新清单。

使用：项目协作 → 清单核实 → 提示词联动美术 → 选择新模式 → 核对并确认各条用途与图片；再进入图视生成 → 整本提示词与素材 → 从联动美术项目载入。

首版用已有 API 模型进行 AI 核对。完整 Codex Agent 连接、全自动视频队列、Topaz 和剪辑流水线仍属于后续阶段。
