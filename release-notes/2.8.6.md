# 行舟影视 2.8.6

- 小事件页的大事件分组按钮按可用宽度均匀铺满，每行自动调整列数，保持等宽、等高和统一间距，减少右侧空白。
- 事件卡片的“整理”先打开可拖动的要求窗口，可选择接口、使用默认整理或输入人物映射与其他要求。默认围绕本作主角整理，其他来源人名按明确关系称谓呈现；对应关系不明时提示核对，避免擅自混入对标人名。
- 整理结果仍先预览，采用后才修改卡片；候选可以交给 Agent 按补充要求重新整理，保留历史结果。
- 主线明确区分当前排列与已确认顺序；A、B、C 只是位置编号，进入页面不会自动调用模型或确认因果。手动调整或采用模拟排序后，再确认顺序。
- 新增“一键分析全部小事件”及“分析当前大事件”。根据灵感、已确认设定、全部大事件内容与顺序，推演具体小事件、前后因果、动机、相对时间和伏笔，数量由情节决定，不提前分集。
- 小事件分析先形成候选。采用时保留大事件顺序、已有小事件稳定编号、父节点与正文；可补全未确认的空白草稿，并插入新的事件。固定大事件只作为参考，固定小事件不能被挤动；遗漏、重复、错归组或过期候选会被拒绝。
- 整段划分与整理窗口的底栏采用横向布局，接口标签、选择框与操作按钮同行对齐，内容独立滚动；调整创作区尺寸与滚动约束，保留顶部工具栏，减少无内容的额外滚动。
- 继续保留本地稿件编辑和草稿保存，以及 2.8.4 的会话加密、IPC 校验与签名更新保护。
