# 行舟影视 2.8.78

- 清单核实中的资产卡片统一高度，名称与操作分行；窄窗自动调整列数。提示词关联只预览前两个编号和剩余数量，点击即可查看、修改完整关联，避免卡片被撑大或姓名竖排。
- 美术和资产页的“对应提示词”展示该资产已关联的具体提示词编号，同时保留所属场景；没有提示词关联的旧项目继续按场景查看。
- 分镜自动读取清单核实中已保存的提示词关联，只在本条下展示它实际使用的图片。不同提示词分别加载自己的素材，保留人工选择和生成参数。
- 分镜保存时区分原始正文和带图片编号的生成正文，避免保存后关联失效；关联过期、缺图或正文变动时显示具体原因，可重新载入本条素材。手工修改的正文保留，不冒用其他提示词或整场素材。
