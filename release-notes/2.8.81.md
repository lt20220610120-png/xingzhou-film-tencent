# 行舟影视 2.8.81

- 美术模型请求改为统一队列，实际最多 6 路；自动任务最多 5 路，保留 1 路给人工重分发。信息读取、场景关联、细节补齐与提示词分发共用额度，其他条目排队，界面分别展示实际请求数和排队数。
- 信息读取的“停止分析”只停止读取后续分集及其当前请求；已经得到清单的场景、提示词继续分发。清单核实提供独立“开始清单分发 / 停止清单分发”，可扫描所有已有上游信息并继续未完成工作，无需重新读取全集；打开页面不触发请求。
- 已完成且无缺项的场景、分集可独立核实发布，不必等待全剧。停止信息读取不影响已完成范围的核实按钮；未完成或缺项明确显示具体原因，保留发布校验。
- 提示词分发工具栏在窄窗与大窗都保持标题、模型及按钮同一水平线，超出可用宽度时在工具栏内部横向查看，不再换行增加高度。
- 保留完整提示词与基础设定的模型判断、人工关联、版本、人审记录、已生成图片与后文回填机制，停止分发后迟到回包不会覆盖保存结果。
