# 2.8.90

- 移除管理后台中的旧版接续任务界面与入口，制作工作流统一使用新版炉子。
- 剪辑设置新增默认剪辑设定：自动附带项目剧本、镜头顺序、粗剪、音效、每集至少两首情绪配乐、字幕、人名条、尾帧和交付检查规则。
- 新增国内剧／海外剧选择：国内剧使用竖条人名条和中文单行字幕（每行不超过 8 字）；海外剧使用横条人名条和最多两行字幕。人名条只在前 3 集人物首次出场时添加。
- 新增默认伪帧：每集结尾定格并保留 2 秒；支持选择指定尾帧图片或视频。
- 新增音色目录；背景音乐、音效、音色、尾帧与项目剧本都会写入 OpenFilm 的制作任务文件，供剪辑 Agent 实际读取。
- 选择自定义剪辑指令时仍可完全覆盖默认指令。

自动化仍限管理员本机试用；完整真实剧集成片仍需本机验收。
