# Win AI 站长操作

2026-10-18。此说明供站长使用，用户界面不新增管理入口。地址保密不能替代账号权限验证。

1. 本机双击 `win-ai/打开WinAI管理后台.cmd`。助手使用当前 Windows 账户的加密凭据，将密码复制到剪贴板并打开独立管理浏览器；账号 `WinAIAdmin`，粘贴密码登录。不要把这个助手、SSH 密钥或凭据缓存发给用户。
2. 独立地址：`https://winai.xingzhoufilm.cn/sign-in?admin=1`。行舟管理员与 Win AI 站长是不同权限；普通用户即使知道地址也不能管理站点。域名外部连接尚待备案审核及跨网络验收，本机助手使用拥有者已有的安全连接。
3. “渠道” `/channels` 添加你获得授权的上游，填写协议、上游 Base URL、密钥和允许模型。兼容 OpenAI 协议的中转可作渠道，其他网站需有正式 API 及适配协议；不能保证任意网页或任意接口直接可用。密钥仅填后台。
4. “模型” `/models` 管理展示；“系统设置→计费与支付→模型定价” `/system-settings/billing/model-pricing` 设置模型输入/输出/缓存等计价，“分组定价” `/system-settings/billing/group-pricing` 设置分组倍率。先根据实际成本核对计价单位，再设置售价。充值价格和模型售价分别配置。
5. “用户” `/users` 查看已建立 Win AI 账本的用户及消费、额度，编辑指定用户额度。统一账号在第一次进入 Win AI 时建立账本，因此不应将这里的数量当成所有尚未使用中转站的行舟注册人数。充值由支付回调增加额度；手动改额应留下处理依据，避免与已到账订单重复加款。
6. “使用日志” `/usage-logs` 查看请求及消耗；“任务日志” `/usage-logs/task` 查看网关已支持的异步任务状态、进行中/成功/失败与用量。需要汇总数时双击本机 `win-ai/查看WinAI运行状态.cmd`，只读统计进行中、等待中和各状态数量，不显示密钥或用户资料。它反映中转站接入的任务，不等同于所有行舟本地任务或任意上游内部并发数；同步请求也不是持久任务队列。没有上游时没有真实任务数据。
7. “系统设置→计费与支付→支付网关” `/system-settings/billing/payment` 配置自己的商户。按 [收款配置](payment-setup.md) 接入商户网关、商户号、密钥及实际开通的支付宝/微信，阅读并由站长本人确认模板声明。普通个人收款码不提供订单回调，不能据此自动加额。
8. 开通前用支付沙箱验证未支付不加额、验签/金额校验及重复回调不重复入账；再由本人做一笔小额付款，核对商户到账、本站订单及额度。必须验证外部支付平台能访问通知地址；软件内成功不能证明公网回调可达。

浏览器用户入口 `/login`、`/register`、`/recover`；已有行舟账户可直接登录，软件内免再次登录。新用户初始额度0，无站长权限。当前未配置真实上游与商户，没有开放真实模型调用或在线收款。
