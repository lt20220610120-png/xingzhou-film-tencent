# Win AI Implementation Plan

> 执行方式：superpowers:executing-plans，当前会话直接实施；结束前独立复核。

**Goal:** 在现有腾讯云服务器提供可访问的 Win AI 中转站首版。
**Architecture:** 官方 New API 不修改二进制，配置品牌；独立域名和服务，Nginx 直接提供本站首页与文档。
**Tech Stack:** Go 官方制品、SQLite、Python 3 部署脚本、Nginx、systemd、静态 HTML/CSS/JS。
**Spec:** design.md

## Global Constraints

- 不覆盖行舟影视现有服务、数据、凭据和用户资料。
- 不配置真实上游或调用付费模型；不显示虚构业务数据。
- 所有接入示例使用 Win AI 当前网址；充值和公开注册关闭。
- 官方制品版本固定 v1.0.0-rc.45，下载后与官方 checksums-linux.txt 校验。
- 保留原项目许可证、署名和准确源码链接。

## Review Focus

- 无上游时页面明确待配置，令牌和渠道 API 仍需身份鉴权。
- 初始化仅在未完成时执行；重跑不得重置管理员或现有渠道。
- DNS 记录已存在但地址不同必须拒绝覆盖。
- 首页复制地址和文档 SDK 示例保持同一个 origin，手机无横向溢出。
- Nginx 验证失败不 reload；原站点健康状态部署前后对比。

## Tasks

- [ ] 1. 部署脚本和配置：官方校验、私有服务目录、幂等 DNS、服务与 TLS；运行静态检查并在隔离服务启动验证。
- [ ] 2. 品牌与页面：先编写端到端验收检查，观察未配置/页面不存在失败；实现 Win AI 首页、Logo、文档和原生后台设置；运行检查通过。
- [ ] 3. 上线与验证：独立虚拟主机发布，检查真实管理员页面、移动端、拒绝注册/未鉴权；独立 mock 上游端到端转发；独立复核修复问题。
- [ ] 4. 打包交接：独立版本、操作说明、验证结果、源码包链接和服务器入口；提交仅本次文件，不发布行舟客户端更新。
